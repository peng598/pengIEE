# LDO 通用设计、计算与调试经验手册

> 适用范围：固定输出、可调输出、低压差、低噪声、超低静态电流和高 PSRR LDO 的方案选型、计算、原理图、PCB、测试与故障定位。  
> 文档版本：V1.0  
> 更新日期：2026-07-22

---

## 1. LDO 适合解决什么问题

LDO 是线性稳压器，本质上用功率管把多余的输入电压转换为热量。它不负责升压，只能在输入高于输出时工作。

LDO 常见用途：

- 将 Buck 的电源纹波进一步降低。
- 给运放、ADC、DAC、PLL、射频和传感器提供较干净的电源。
- 生成低电流、低噪声、精密的模拟电源。
- 在低功耗设备中提供低静态电流电源。
- 作为数字电源的后级稳压或负载隔离。

LDO 不适合：

- 输入电压长期远高于输出、电流较大且效率要求高的场景。
- 需要升压的场景。
- 输入输出压差变化很大且无法接受发热的场景。

最重要的一点：LDO 的输出电压不是“输入减去固定压降”，而是只有在输入电压高于输出电压加上所需 dropout 时，才能保持稳压。

## 2. 先明确 LDO 设计输入

| 项目 | 符号 | 需要填写的内容 |
|---|---:|---|
| 输入最低电压 | VIN,min | 包含输入容差、纹波谷值和线损 |
| 输入标称电压 | VIN,typ | 常态工作点 |
| 输入最高电压 | VIN,max | 包含浪涌、热插拔和容差 |
| 输出电压 | VOUT | 固定值或可调目标 |
| 输出最大电流 | IOUT,max | 包括瞬态和外部驱动电流 |
| 输出平均电流 | IOUT,avg | 用于平均功耗和温升 |
| 允许输出误差 | ΔVOUT | 直流误差、纹波和瞬态分别定义 |
| 输入纹波 | ΔVIN | 频率、幅值和波形 |
| 目标噪声 | VNOISE | RMS、峰峰值或噪声密度 |
| 环境温度 | TA | 最低、常态、最高 |
| 上电/掉电时序 | — | EN、PG、预偏置、放电要求 |

特别要记录负载的动态特性：

- 运放静态电流与输出驱动电流不同。
- ADC 数字接口活动时，瞬时电源电流可能远高于平均值。
- 射频、PLL 和高速数字电路可能具有周期性脉冲负载。

## 3. 规格书阅读：哪些参数决定什么性能

### 3.1 参数性质先分清

| 标注 | 含义 | 用法 |
|---|---|---|
| Typical / Typ | 典型值，不保证每颗都达到 | 初步估算和方案比较 |
| Min | 最小保证值 | 最坏下限计算 |
| Max | 最大保证值 | 最坏上限计算 |
| Recommended Operating | 推荐工作范围 | 正常功能和长期可靠性边界 |
| Absolute Maximum | 绝对最大额定值 | 只能检查是否可能损坏 |
| Test Condition | 测试条件 | 不看条件不能比较两个参数 |

### 3.2 关键参数映射

| 参数 | 主要体现的性能 |
|---|---|
| 输入电压范围 | 能否启动和正常稳压 |
| Dropout Voltage | 接近输出电压时还能否稳压 |
| 输出电流 | 连续带载、瞬态和温升能力 |
| 负载调整率 | 负载变化造成的 DC 误差 |
| 线性调整率 | 输入变化造成的 DC 误差 |
| PSRR | 输入纹波传到输出的衰减 |
| 输出噪声 | LDO 自身产生的噪声 |
| 静态电流 | 空载功耗和电池续航 |
| 输入/输出电容范围 | 稳定性、瞬态和启动行为 |
| ESR 要求 | 环路阻尼和稳定性 |
| 反向电流能力 | 输入掉电、预偏置和多路电源安全 |
| 软启动 | 上电冲击和输出过冲 |
| 热关断 | 过热保护行为 |
| θJA / θJC | 散热和结温能力 |
| FB 基准精度 | 可调输出的 DC 精度 |

## 4. 第一项计算：压差是否足够

### 4.1 稳压条件

通用最坏条件为：

```text
VIN,pin,min ≥ VOUT,max + Vdropout,max
                  + Vripple,margin + Vtrace,drop
```

其中：

- `VIN,pin,min`：LDO 输入引脚处的最低瞬时电压。
- `VOUT,max`：考虑输出精度后的最高输出电压。
- `Vdropout,max`：目标负载、温度和工艺下的最大 dropout。
- `Vripple,margin`：输入纹波谷值和额外裕量。
- `Vtrace,drop`：走线和过孔压降。

### 4.2 输入输出只差 100 mV 能不能工作

不能只看标称值。例如输入 `3.4 V`、输出 `3.3 V`，标称压差只有 `100 mV`。是否能用取决于：

- 实际输出电流。
- LDO 在该电流下的最大 dropout。
- 最高温度。
- 输入纹波谷值。
- 输出容差上限。
- 线路压降。

低电流时可能稳定，高电流时可能掉压；即使直流输出看起来正常，接近 dropout 时 PSRR 也会明显变差。

### 4.3 Dropout 的定义

不同厂家可能使用不同定义：

- 输出下降到标称值的某个百分比。
- 输入输出差值达到某个固定值。
- 在某个负载、温度和输出电压下测试。

因此比较不同 LDO 时必须同时比较测试条件。典型 dropout 不能代替最大 dropout。

### 4.4 什么样的压差裕量算好

没有统一绝对值，但可按下面的工程经验初判：

| 额外压差裕量 | 判断 |
|---:|---|
| <50 mV | 很紧，容易受纹波、温度和容差影响 |
| 50~150 mV | 低电流可能可用，需验证 PSRR 和瞬态 |
| 150~300 mV | 常见较稳妥范围 |
| 300~500 mV | 稳压裕量好，但发热增加 |
| >500 mV | 需要重点检查效率和热损耗 |

对于低噪声 LDO，不能只追求压差小，还要看目标开关频率处的 PSRR。

## 5. 功耗、效率与温升

### 5.1 LDO 功耗

```text
PLDO = (VIN - VOUT) × IOUT
```

输入静态电流也产生少量功耗：

```text
Piq ≈ VIN × IQ
```

总功耗粗估：

```text
Ptotal ≈ (VIN - VOUT) × IOUT + VIN × IQ
```

### 5.2 LDO 效率

忽略静态电流时：

```text
ηLDO ≈ VOUT / VIN
```

输入 `5 V`、输出 `3.3 V` 时，理论效率只有约 `66%`；输入 `3.5 V`、输出 `3.3 V` 时约 `94%`，但压差裕量会变小。

### 5.3 结温

```text
TJ ≈ TA + PLDO × θJA
```

如果使用 θJC 和外部散热条件：

```text
TJ ≈ TC + PLDO × θJC
```

实际设计应使用数据手册指定 PCB 的热阻，并用样机测量。

### 5.4 功耗快速判断

| 功耗 | 小型 SOT-23 / SC70 封装的经验判断 |
|---:|---|
| <50 mW | 通常容易处理 |
| 50~150 mW | 一般可用，检查 PCB 铜面积 |
| 150~300 mW | 需要认真核算结温和环境温度 |
| 300~500 mW | 小封装通常偏紧，需热测试 |
| >500 mW | 通常应改用更大封装、散热铜或前级降压 |

这些数值不是厂家保证值，只用于早期筛选。

### 5.5 LDO 后级功耗预算

如果 LDO 前面是 DC-DC，推荐先把 DC-DC 输出设到略高于 LDO 输出，再让 LDO 处理纹波：

```text
P_LDO = (VDC-DC - VLDO) × ILOAD
```

前级电压过高会增加热量；前级电压过低则可能使 LDO 掉出稳压。最佳点通常是满足最坏 dropout 后再留适量纹波裕量。

## 6. 输出电流与负载瞬态

### 6.1 最大输出电流不是所有条件都成立

数据手册的最大电流通常带有测试条件，例如：

- 输入输出压差。
- 输出电压。
- 输入/输出电容。
- 环境温度。
- 封装和评估板。

如果功耗已经把芯片推到热限制，最大电流必须按热计算重新降低。

### 6.2 负载瞬态的三个阶段

负载突然增加时，输出电压变化可拆成三部分：

1. ESR 造成的瞬时电压台阶。
2. 电容在控制环路响应前提供电流造成的斜坡跌落。
3. 环路恢复后的剩余过冲和振铃。

初始台阶：

```text
ΔVESR = ΔILOAD × ESR
```

电容储能造成的跌落：

```text
ΔVC = ΔILOAD × Δtresponse / COUT
```

### 6.3 输出电容估算

```text
COUT ≥ ΔILOAD × Δtresponse / ΔVallow
```

工程单位版本：

```text
COUT(µF) ≥ 1000 × ΔILOAD(A) × Δt(µs) / ΔVallow(mV)
```

例如负载阶跃 `20 mA`、环路响应时间 `10 µs`、允许跌落 `20 mV`：

```text
COUT ≥ 1000 × 0.02 × 10 / 20 = 10 µF
```

但实际还要满足芯片规定的稳定电容和 ESR 范围。

### 6.4 运放供电不能只看静态电流

运放的平均静态电流可能只有几 mA，但以下情况会增加瞬时电流：

- 输出驱动低阻负载。
- 驱动较大电容。
- 输出接近电源轨。
- 多颗运放同时发生输出跳变。

应在最差输出波形下测量 LDO 电源电流和电源跌落。

## 7. 输入电容与输入纹波

### 7.1 输入电容的作用

- 降低输入引脚高频阻抗。
- 给瞬态负载提供局部电流。
- 降低输入线缆上的脉冲电流。
- 减少输入纹波传递。
- 帮助 LDO 控制环路稳定。

### 7.2 常见输入配置

```text
VIN ── 1 µF ～ 10 µF ── LDO IN
```

如果输入来自开关电源、长线或连接器，建议在接口处增加储能电容，但不要忘记输入浪涌和热插拔。

### 7.3 输入电容过大

优点：

- 输入纹波更低。
- 输入瞬态更小。

代价：

- 热插拔浪涌更大。
- 启动时间可能变长。
- 可能使输入端 LC 产生振铃。
- 多路电源掉电时储能和反灌增加。

输入电容必须放在芯片输入引脚附近，而不是只放在电源接口旁。

## 8. 输出电容、ESR 与稳定性

### 8.1 先看数据手册允许范围

LDO 的稳定性和输出电容关系很大。数据手册可能规定：

- 最小有效容量。
- 最大有效容量。
- ESR 最小值。
- ESR 最大值。
- 推荐电容类型。
- 是否允许陶瓷电容。

不能把所有 LDO 都当作“电容越大越稳定”。

### 8.2 陶瓷电容的优缺点

优点：

- ESR 低。
- 高频滤波好。
- 体积小。
- 温度特性较好（选择 X7R/X5R 时）。

风险：

- 直流偏压掉容。
- ESR 过低导致某些旧 LDO 不稳定。
- 过大有效容量导致启动慢或环路响应变化。

### 8.3 输出电容过大

输出电容变大通常会降低高频纹波和负载跌落，但可能造成：

- 启动充电电流增加。
- 软启动时间变长。
- LDO 环路带宽下降。
- 负载释放时恢复变慢。
- 输入掉电时输出向输入反灌能量增加。

输出电容启动电流：

```text
ICOUT,start = COUT × VOUT / tSS
```

如果没有软启动，不能假设芯片能无限快地给大电容充电。

### 8.4 输出电容过小

可能造成：

- 环路振荡。
- 负载阶跃跌落大。
- 输出噪声和纹波增加。
- 启动过冲。

## 9. PSRR：不要只看 1 kHz

### 9.1 PSRR 定义

```text
PSRR(dB) = 20 × log10(ΔVIN / ΔVOUT)
```

PSRR 越大，表示输入纹波传到输出后的比例越小。

例如输入有 `100 mV` 纹波：

- PSRR = 40 dB：输出约 `1 mV`。
- PSRR = 60 dB：输出约 `0.1 mV`。

### 9.2 PSRR 与频率

LDO 的 PSRR 通常随频率升高而下降。必须看：

- DC-DC 开关频率。
- 开关频率的二次、三次谐波。
- 负载瞬态频谱。
- 低频电源纹波。

如果前级开关频率为 `1 MHz`，只看 LDO 在 `1 kHz` 的 PSRR 没有意义。

### 9.3 影响 PSRR 的因素

- 输入输出压差。
- 负载电流。
- 输出电容及其 ESR。
- 芯片内部控制架构。
- PCB 输入回路和地阻抗。
- 输入纹波频率。

### 9.4 什么 PSRR 算好

不能脱离频率判断。可作为早期参考：

| 目标频率 | PSRR 经验判断 |
|---:|---|
| 低频 100 Hz~1 kHz | >60 dB 通常较好 |
| 10 kHz~100 kHz | >40~60 dB 较好 |
| 1 MHz 附近 | >20~40 dB 已有帮助，需结合前级纹波 |
| 高频尖峰 | 单靠 LDO 通常不够，需要布局和无源滤波 |

如果接近 dropout，PSRR 可能显著下降。

## 10. 输出噪声与模拟性能

### 10.1 噪声指标的常见表达

- RMS 噪声：某一频带内的积分噪声。
- 峰峰值噪声：示波器带宽和观察时间相关。
- 噪声密度：
V/√Hz`。
- 低频噪声：通常包含 1/f 噪声。
- 输出纹波：常指输入开关频率传递后的周期成分。

不同指标不能直接比较。必须记录积分频带和测量带宽。

### 10.2 什么噪声算好

| 应用 | 选择重点 |
|---|---|
| 普通数字电源 | 噪声不是第一优先，先看效率和瞬态 |
| 运放电源 | 看运放 PSRR、输出摆幅和电源噪声耦合 |
| ADC/DAC 模拟电源 | 常需要 µV 级到几十 µV 级，需看频带 |
| ADC/DAC 参考 | 使用专用基准，不能只看 LDO 输出噪声 |
| PLL/射频 | 看噪声频谱、PSRR 和开关谐波位置 |

低噪声 LDO 可能需要特定输出电容、旁路电容或噪声旁路引脚。不要脱离推荐应用电路单独比较一个“输出噪声数字”。

### 10.3 噪声测量注意

- 探头地线要短。
- 限定示波器带宽。
- 测量点应在输出电容两端和实际负载端分别记录。
- 区分 LDO 自身噪声与前级 Buck 传入的纹波。
- 使用频谱分析或低噪声放大测量时，记录仪器噪声底。

## 11. 可调 LDO 的反馈分压

### 11.1 通用公式

```text
VOUT = VFB × (1 + RUP / RDOWN)
```

```text
RUP = RDOWN × (VOUT / VFB - 1)
```

连接关系：

```text
OUT ── RUP ──┬── FB
             |
           RDOWN
             |
            GND
```

### 11.2 分压电流选择

```text
Idivider = VOUT / (RUP + RDOWN)
```

分压电流太小：

- FB 偏置电流误差变大。
- 板面污染和漏电更容易造成误差。
- FB 更容易受噪声耦合。

分压电流太大：

- 静态功耗增加。
- 低功耗优势下降。

经验上可从 `5~50 µA` 评估，最终以数据手册的 FB 偏置电流和低功耗要求为准。

### 11.3 最坏输出误差

```text
VOUT,max = VFB,max × [1 + RUP,max / RDOWN,min]
VOUT,min = VFB,min × [1 + RUP,min / RDOWN,max]
```

### 11.4 反馈电阻布局

- 靠近 FB 引脚。
- 从输出电容正端 Kelvin 取样。
- 下拉电阻接安静地。
- 远离负载大电流回流、时钟和开关节点。
- 不要在 FB 上随意加电容，除非数据手册明确给出计算方法。

## 12. 低噪声 LDO 的旁路和噪声优化

一些低噪声 LDO 带有 NR、BYP、SS 或噪声旁路引脚。这些引脚常用电容降低内部参考噪声，但会影响：

- 启动时间。
- 关断放电。
- 负载瞬态。
- 低频噪声。

必须按数据手册设置容量和耐压。

通用优化顺序：

1. 选择正确的 LDO 架构和输出电流等级。
2. 保证输入输出压差。
3. 使用推荐的输入/输出电容。
4. 在目标开关频率处检查 PSRR。
5. 优化输入、输出和地回路。
6. 再考虑 NR/BYP、磁珠或 RC 滤波。

不要试图用一个超大的旁路电容“修复”错误的输入压差或布局。

## 13. 热设计与封装选择

### 13.1 同一电流，不同输入输出压差，发热完全不同

```text
P = (VIN - VOUT) × IOUT
```

例如输出 `3.3 V、100 mA`：

| 输入 | 功耗 |
|---:|---:|
| 3.5 V | 20 mW |
| 4.0 V | 70 mW |
| 5.0 V | 170 mW |
| 12 V | 870 mW |
|

小封装在 12 V 到 3.3 V、100 mA 时可能已经很热。

### 13.2 封装选择原则

- 小电流、低压差：SC70、SOT-23 等小封装。
- 中等功耗：SOT-223、DFN 带大散热焊盘。
- 高功耗：更大封装、外部散热铜或前级 Buck。

### 13.3 前级 Buck 应怎样给 LDO 供电

前级电压应满足：

```text
VBUCK,min ≥ VLDO,out,max + Vdropout,max + Vripple,margin + Vtrace,drop
```

前级太高：LDO 热损耗增加。前级太低：LDO 失去 PSRR 和稳压能力。

建议先按最坏 dropout 确定最低前级电压，再给 `50~200 mV` 的额外余量，具体取决于纹波和负载。

## 14. 并联、级联和分支供电

### 14.1 LDO 并联

普通 LDO 不建议直接并联输出，原因是：

- 输出设定值有误差。
- 一个 LDO 可能承担大部分电流。
- 发生环流。
- 限流和热保护可能不同步。

需要并联时，应使用：

- 专用均流器件。
- 输出小电阻做均流。
- 外部精密控制环路。
- 厂家明确支持的并联方案。

### 14.2 LDO 级联

级联可以提高隔离和 PSRR，但功耗是所有级的总和。常见结构：

```text
高电压 → 前级 Buck → 中间电压 → 低噪声 LDO → 模拟负载
```

前级 Buck 应把电压降到刚好满足后级 dropout，避免让 LDO 处理过大的压差。

### 14.3 数字/模拟分支

通用结构：

```text
前级电源 ──┬── 数字负载
           └── 磁珠/小电阻 → LDO → 模拟负载
```

注意数字信号回流不能跨越地平面缝隙，模拟电源隔离不应破坏高速信号的参考平面。

---

## 15. 反向电流、预偏置和时序

### 15.1 反向电流来源

- 输出电压高于输入电压。
- 多路电源同时连接。
- 后级大电容在输入掉电时维持输出。
- 其他芯片 IO 通过保护二极管向电源反灌。

### 15.2 必须确认的数据手册参数

- Reverse current 是否允许。
- 是否有内部反向保护。
- 输出是否自动放电。
- EN 低电平时内部功率管状态。
- 是否允许预偏置启动。

### 15.3 没有反向保护时的处理

- 输入端与输出端增加隔离器件。
- 使用负载开关或理想二极管。
- 规定上电、掉电顺序。
- 对后级 IO 做电源域隔离。

---

## 16. 启动、关断与大电容

### 16.1 启动检查

- 输入源是否限流。
- 输出电容有效值是多少。
- 启动时负载是否已经接入。
- EN 是否慢速爬升或抖动。
- 输入是否会因浪涌跌破 UVLO。

### 16.2 大电容充电

```text
ICOUT,start ≈ COUT × VOUT / tSS
```

如果芯片没有明确软启动，按最坏内部限流估算启动行为，不要只看稳态输出电流。

### 16.3 关断放电

若数据手册无内部放电，输出电压下降时间取决于负载：

```text
tdischarge ≈ COUT × VOUT / ILOAD
```

低功耗负载可能导致输出长时间保持，影响系统时序。

---

## 17. LDO PCB 布局

### 17.1 输入回路

```text
输入接口 → CIN → LDO IN → 功率管 → LDO OUT → COUT → 负载
```

输入电容和输出电容都应靠近芯片引脚，回路短且接地路径低阻。

### 17.2 反馈回路

- 固定输出版本也要检查输出取样路径。
- 可调版本的反馈分压靠近 FB。
- FB 远离数字时钟和开关电源节点。
- 输出电容负端接安静地。

### 17.3 散热

- 裸露焊盘按厂家推荐开窗。
- 热过孔连接到大面积地或散热铜。
- 功率器件不要贴近敏感模拟输入。
- 评估板布局不能完全照搬到狭小产品板，热阻可能改变很多。

---

## 18. 纹波、噪声和 PSRR 测量

### 18.1 正确测量

- 探头使用短地弹簧。
- 测量点在输出电容两端。
- 同时记录全带宽和 20 MHz 限带结果。
- 记录示波器垂直档位、带宽和采样时间。
- 如果要测 µV 级噪声，应确认仪器噪声底。

### 18.2 区分三类波形

| 现象 | 常见来源 |
|---|---|
| 低频缓慢变化 | 输入调整率、负载变化或环路响应 |
| 开关频率周期纹波 | 前级 Buck 传入、PSRR 不足 |
| 很窄的尖峰 | ESL、地弹跳、布局和测量回路 |

### 18.3 PSRR 测量

需要给输入端注入已知频率和幅度的纹波，再测输出衰减：

```text
PSRR(dB) = 20 × log10(ΔVIN / ΔVOUT)
```

必须扫频，至少覆盖：

- 100 Hz~1 kHz。
- 前级开关频率。
- 前级开关频率的主要谐波。
- 模拟电路敏感频段。

---

## 19. LDO 选型中的“好参数”判断

### 19.1 低压差

低 dropout 很重要，但不能只看典型值。优先看：

- 最大 dropout。
- 目标负载下的 dropout 曲线。
- 高温 dropout。
- dropout 附近的 PSRR。

### 19.2 低噪声

应同时看：

- 积分频带。
- 输出电容条件。
- NR/BYP 电容条件。
- 输入输出压差。
- 负载电流。

### 19.3 高 PSRR

重点看前级开关频率处，而不是只看低频。高 PSRR 和低噪声是相关但不同的指标：

- PSRR 反映输入噪声传递。
- 输出噪声反映 LDO 自身产生的噪声。

### 19.4 低静态电流

低 IQ 适合待机系统，但某些超低 IQ LDO 的瞬态、噪声或 PSRR 可能不如高功耗低噪声 LDO。

### 19.5 稳定电容范围

“支持陶瓷电容”是好信息，但仍应确认：

- 最小有效容量。
- 最大有效容量。
- ESR 范围。
- 启动和大负载阶跃。

## 20. SGM2036S-ADJ 作为具体参考

本节仅展示如何把通用方法映射到一个具体型号，实际使用仍以手上版本数据手册为准。

### 20.1 已知参考信息

| 参数 | 参考值/说明 |
|---|---|
| 类型 | 低输入电压、低噪声、低压差 LDO |
| 输出能力 | 约 300 mA 级 |
| 输入范围 | 约 1.6~5.5 V |
| 可调输出范围 | 约 0.8~5.0 V |
| 典型 dropout | 数据手册给出约190 mV@300 mA、VOUT=3.0 V |
| 典型静态电流 | 约30 µA |
| 封装 | SOT-23-5、SC70-5、DFN 等，按后缀确认 |

### 20.2 3.5 V 输入、3.3 V 输出

名义压差：

```text
VIN - VOUT = 3.5 - 3.3 = 0.2 V = 200 mV
```

低电流运放供电时可能可以工作，但应检查：

- 运放总电流和输出驱动电流。
- 输入纹波谷值。
- LDO 输出误差上限。
- 高温 dropout。
- 目标开关频率处 PSRR。

如果最大负载接近 300 mA，200 mV 裕量偏紧；若要稳定抑制前级纹波，通常应把前级电压提高到约 `3.6~3.8 V`，再核算 LDO 热耗散。

### 20.3 ADJ 版本设置 3.3 V

按典型 `VFB≈0.8 V`：

```text
VOUT = VFB × (1 + RUP / RDOWN)
RUP / RDOWN = 3.3 / 0.8 - 1 = 3.125
```

推荐组合：

```text
RUP   = 56.2 kΩ
RDOWN = 18.0 kΩ
```

典型输出：

```text
VOUT,typ = 0.8 × (1 + 56.2 / 18.0) ≈ 3.298 V
```

分压电流：

```text
Idivider ≈ 3.3 / (56.2 kΩ + 18.0 kΩ) ≈ 44.5 µA
```

如果更重视低功耗，可选：

```text
RUP   = 180 kΩ
RDOWN = 57.6 kΩ
```

典型输出约 `3.300 V`，分压电流约 `13.9 µA`，但对 FB 偏置电流和漏电更敏感。

### 20.4 SGM2036S 参考的选型结论

- 给运放小电流供电：重点看噪声、PSRR、输出电容和压差，而不是只看300 mA额定值。
- 3.4 V→3.3 V：100 mV 裕量偏紧，只有在低电流、低纹波和实测条件下才建议使用。
- 3.5 V→3.3 V：200 mV 裕量较好，但仍要看输入谷值和高温。
- 最大300 mA附近工作：应按最大 dropout、封装温升和输出电容稳定范围核算。

## 22. LDO 常见故障定位

| 现象 | 常见原因 | 优先检查 |
|---|---|---|
| 输出低于设定值 | dropout、限流、输入跌落、反馈错误 | 测 LDO IN 引脚、负载电流和 FB |
| 空载正常、带载下降 | dropout 或热限制 | 逐步增加电流并记录压差曲线 |
| 输入纹波几乎直通 | 接近 dropout、PSRR不足、输入频率过高 | 看目标频率 PSRR 和输入谷值 |
| 输出振荡 | 输出电容/ESR不符合要求、布局差 | 恢复推荐电容，检查有效容量 |
| 启动失败 | COUT过大、输入源限流、预偏置 | 测启动电流和 EN/VOUT |
| 输出过冲 | EN爬升、预偏置、环路和输出电容 | 观察启动与负载释放波形 |
| 关断后输出不降 | 无自动放电、负载太轻或反灌 | 检查放电路径和外部 IO |
| 芯片很热 | 输入输出压差过大、负载过大 | 计算 P=(VIN-VOUT)×I |
| 可调输出偏差大 | VFB误差、分压阻值太大、漏电 | 测 FB 和分压电流 |
| 模拟电路仍有噪声 | 负载本身、地回流、前级尖峰 | 分别测 LDO 输入、输出和负载端 |

## 24. 最终原则

1. LDO 只能降压，输入输出压差首先决定能不能稳压。
2. Dropout 必须使用目标负载、高温和输入谷值下的最大条件。
3. LDO 功耗等于压差乘以电流，效率不能脱离输入输出电压谈。
4. 输出电容按有效容量和 ESR 判断，不能只看标称 µF。
5. PSRR 必须看前级开关频率处，不能只看 1 kHz。
6. 输出噪声、输入纹波传递、负载瞬态和高频尖峰是不同指标。
7. 可调版本的反馈电阻要同时考虑 VFB、FB 偏置电流和电阻公差。
8. 大电容、预偏置和多路电源必须验证启动、关断和反向电流。
9. 低噪声 LDO 的 PCB 地、输入回路和输出取样同样重要。
10. 过温保护是最后防线，不能把热关断点当作正常工作温度。
11. 前级 Buck 给 LDO 供电时，应把前级输出设在满足最坏 dropout 后的最低合理值。
12. 规格书典型值用于理解性能，最小/最大保证值才用于量产边界。

---

> **一句话总结：**LDO 设计的核心不是“把电压降下来”，而是在压差、噪声、PSRR、瞬态、热和启动约束之间取得可验证的平衡。
