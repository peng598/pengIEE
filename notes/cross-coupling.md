# 交叉耦合

好的，我们来深入剖析 **交叉耦合差分驱动器（Cross-Coupled Differential Driver）**。这是专业音频设备中最常用的单端→平衡转换拓扑，在 THD+N、CMRR、输入阻抗一致性等方面远优于简单的串联或并行结构。

---

## 一、核心原理：为什么需要交叉耦合？

传统并行结构（一个同相 + 一个反相）有两大缺陷：
- **输入阻抗不一致**：同相输入极高（>10MΩ），反相输入较低（由Rin决定），源阻抗变化会导致两路增益偏差。
- **共模抑制受限于运放匹配**：即使电阻精确，两运放的偏置电流、压摆率、带宽差异也会使高频CMRR快速下降。

**交叉耦合**通过在运放之间引入**两条交叉反馈路径**，让两个运放互相“锁定”，大幅降低对运放自身匹配的依赖，同时使输入阻抗统一为同相端阻抗，抗源加载能力更强。

---

## 二、经典拓扑结构（双运放 + 4电阻）

这是 **THAT 1646** / **DRV134** 的内部核心电路，也是最常用的分立实现。

### 电路图（文字版 ASCII）

```
                R2 (反馈)
        ┌───────/\/\/\───────┐
        │                     │
Vin ── R1 ──┬── 运放A(+) ────┼── +输出
             │                │
             │                │
             R3 (输入电阻)     │
             │                │
             └── 运放B(-) ────┼── -输出
                          │   │
                          R4  │
                          │   │
                          └───┘
                          地 (R4的另一端接地)
```

更规范的画法如下（便于理解节点关系）：

```
运放A：
  - 同相端（+）通过 R1 接输入 Vin
  - 同相端（+）还通过 R3 接运放B的输出（交叉）
  - 反相端（-）通过 R2 接运放A自己的输出（反馈）
  - 反相端（-）直接接地

运放B：
  - 同相端（+）直接接地
  - 反相端（-）通过 R4 接运放A的输出（输入）
  - 反相端（-）通过 R5 接运放B自己的输出（反馈）

Vout+ = 运放A输出
Vout- = 运放B输出
```

这种4电阻版本是最简洁的，但实际应用常用**6电阻版本**（增加一个输入电阻和一个反馈电阻）以获得更高对称性和可调性。

## 三、电阻取值与增益计算

假设所有电阻为 **R**（即 R1=R2=R3=R4=R，典型值10kΩ），则：

- 运放A是**同相加法器**：两个输入（通过 R1 和 R3）在运放A同相端加权叠加，输出 Vout+ 与这两个输入呈正相关。
- 运放B是**反相放大器**：输入来自运放A输出（通过 R4），反馈电阻R5决定反相增益。

经过节点方程推导（关键是运放A反相端接地，同相端电压由 Vin 和 Vout- 通过 R1、R3 分压决定），最终结果：

```
Vout+ = (R2/R1) × Vin + (R2/R3) × Vout-
Vout- = -(R5/R4) × Vout+
```

令所有电阻相等 **R1=R2=R3=R4=R5=R**，并代入简化：

- 由第二式：`Vout- = -Vout+`
- 代入第一式：`Vout+ = Vin × (R2/R1) - Vout+ × (R2/R3)`
- 若 R1=R3，则 `Vout+ = Vin × (R2/R1) - Vout+` → `2Vout+ = Vin × (R2/R1)` → `Vout+ = (R2 / (2R1)) × Vin`

所以当所有电阻相等时，增益仅 **0.5**（-6dB）。这通常不够，需要调整。

**标准取值**（如 THAT 1646）：  
取 `R1 = 2R, R2 = R, R3 = R, R4 = R, R5 = R`，则差分增益为 **1**（0dB），单端输出为 ±0.5 Vin（因为差分摆幅是两倍的输出，所以总增益仍为1）。

实际设计中，我们通常希望**差分增益为2到4倍**，以匹配+4dBu输入到+6dBu等。推荐一组经过验证的取值（来自《Audio Power Amplifier Design Handbook》）：

```
R1 = 10kΩ
R2 = 20kΩ  (增益控制)
R3 = 10kΩ
R4 = 10kΩ
R5 = 20kΩ
此时：Vout+ = Vin × (20/10) / (1 + 20/10) = 2Vin / 3 ≈ 0.667Vin
      Vout- = -0.667Vin
差分输出 = 1.333×Vin   （相当于增益1.333倍，约2.5dB）
```

若要更高增益（如麦克风需要的40dB），需在输入前增加一级前置LNA。交叉耦合驱动器本身不适合直接高增益（稳定性受限），通常增益设定在 -6dB ~ +6dB 之间，作为阻抗变换和平衡转换级。

## 四、交叉耦合的核心优势

| 参数     | 并行同相+反相            | 交叉耦合                         |
| ------ | ------------------ | ---------------------------- |
| 输入阻抗   | 同相极高，反相低（不一致）      | 统一为 R1 + (R1//R3) 近似值，通常10kΩ |
| 高频CMRR | 依赖运放匹配，<60dB@20kHz | 由电阻网络决定，可达85dB+@20kHz        |
| 直流偏移   | 两运放独立偏置，累加         | 交叉反馈抑制直流分量，输出偏移<±5mV         |
| 噪声     | 两路独立噪底，相加          | 共模噪声自动抵消，等效输入噪声低             |
| 稳定性    | 需外部补偿              | 内部交叉反馈增强相位裕度，不易振荡            |
| 对运放要求  | 需选配对               | 普通双运放即可，无需精密配                |

## 五、麦克风输入转差分ADC的适配

你要将麦克风非平衡信号在板子上转换为差分信号给ADC。交叉耦合驱动器通常置于**前置放大器之后**——先用一个低噪声前置放大（如NE5534或OPA1611）将麦克风信号放大到线路电平（+4dBu ~ +6dBu），再用交叉耦合驱动器转差分。

### 推荐信号链
```
麦克风 → 前置放大器（×100, 40dB） → 交叉耦合驱动器（增益1×，平衡转换） → ADC差分输入
```

交叉耦合驱动器此时的作用：
- 将单端高电平信号转换为**隔离的地参考差分信号**
- 提供恒定、一致的输入阻抗（10kΩ），避免影响前级的负载变化
- 将前置放大器的输出和ADC输入之间的地环路噪声抵消掉
- 对ADC提供精确的共模偏置（通过运放B同相端接地，输出共模自动为0V；若ADC需要非零共模，可在运放B同相端加VOCM）

### 关键设计注意事项
1. **电阻精度**：全部使用0.1%公差、25ppm温漂的电阻，±0.1dB增益误差。
2. **运放选择**：推荐低噪声双运放，如 OPA2134（FET输入，低偏流）、NE5532（低噪声、高带宽）、TL072（低成本）。麦克风级之后用噪声不敏感。
3. **共模偏置**：若ADC需要共模电压（如2.5V），将运放B同相端通过一个电压跟随器接2.5V，同时调整电阻使其在差分输出中不引入共模偏移。但更简单是用全差分运放驱动ADC。
4. **PCB布线**：四个反馈电阻必须对称布局，走线等长，避免寄生电容差模。反馈走线远离输入信号。
5. **输出保护**：每路输出串联22Ω电阻，防止外部电缆容性负载导致振荡。

## 七、结论：对麦克风输入转差分，交叉耦合是好选择吗？

**好，但不是最优**。如果你已经在前置放大将麦克风信号提升到线路电平（>1Vrms），交叉耦合可以提供优异的平衡转换，且输入阻抗一致，CMRR高。但它毕竟需要4~6个精密电阻，对PCB布局敏感，且增益调节不灵活（需同时调整多个电阻才能保持对称）。

**更优选择依然是全差分运放（OPA1632）**，它可以：
- 直接接收麦克风小信号并放大40~60dB的同时完成单端→差分转换
- 内置共模反馈，VOCM引脚可直接接ADC参考
- 只需3个外部电阻设定增益
- 噪声极低，CMRR>90dB
- 无需PCB对称布局（内部交叉反馈已完成）

因此，如果你已在用交叉耦合结构，可以继续使用；如果尚未确定，建议优先考虑全差分运放。
