# LC谐振

### 一、核心
比喻：钟摆（动能与势能的转换）

想象一个理想的、没有摩擦的钟摆：

1. **初始状态**：你将钟摆拉到最高点然后放手。
    
    - 此时，它的**速度为零**，但**高度最高**，因此它的**势能最大**。
        
2. **下落过程**：钟摆从最高点摆向最低点。
    
    - **势能**逐渐转化成**动能**。
        
    - 到达最低点时，**高度最低（势能最小）**，但**速度最快（动能最大）**。
        
3. **上升过程**：依靠惯性，钟摆从最低点摆向另一端的最高点。
    
    - **动能**又逐渐变回**势能**。
        
    - 到达另一侧最高点时，**速度再次为零（动能最小）**，**高度最高（势能最大）**。
        
4. **循环往复**：如果没有摩擦（能量损耗），这个**动能 ↔ 势能**的转换过程将永远持续下去。钟摆会以固定的频率（由其臂长决定）来回摆动。

### 在LC电路中的对应关系

现在，我们把钟摆模型映射到LC谐振电路：

- **电感（L）** ➔ **“运动的惯性”** （对应**动能**）
    
    - 电感通过电流时会产生磁场，储存**磁能**。电流就像运动的速度，电感量就像物体的质量。**电流不能突变**，正如物体的运动有惯性。
        
- **电容（C）** ➔ **“弹簧或重力”** （对应**势能**）
    
    - 电容两端有电压时会产生电场，储存**电能**。电压就像弹簧的形变或物体的高度。**电压不能突变**。
        
- **LC谐振回路** ➔ **“整个钟摆系统”**
    
    - 电感和电容连接在一起，就构成了一个可以让能量在 **“磁能”**（电感中）和 **“电能”**（电容中）之间来回转换的系统。

### 三、LC谐振的物理过程（一个完整周期）

让我们跟踪能量在LC回路中的一次完整旅程：

1. **状态一：全部能量在电容中（钟摆在最高点）**
    
    - 电容被充电到最大电压 `V_max`，储存了最大的电能 `(1/2) * C * V_max²`。
        
    - 电感中电流为0，磁能为0。
        
    - **此时：电能最大，磁能为零。**
        
2. **过程一：电容 → 电感放电**
    
    - 电容开始通过电感放电，电流开始建立。
        
    - 随着电流增大，电感开始建立磁场，储存磁能。电容上的电压因放电而下降。
        
    - **能量转换：电能 ↘ ， 磁能 ↗**
        
3. **状态二：全部能量在电感中（钟摆在最低点）**
    
    - 电容放电完毕，电压为0，电能为0。
        
    - 电感中电流达到最大 `I_max`，储存了最大的磁能 `(1/2) * L * I_max²`。
        
    - **此时：电能为零，磁能最大。**
        
4. **过程二：电感 → 电容“反充电”**
    
    - 由于电感的惯性（电流不能突变），电流会继续保持原方向流动，开始给电容**反向充电**。
        
    - 电容电压开始反向升高，电能增加。电感电流减小，磁能减少。
        
    - **能量转换：磁能 ↘ ， 电能 ↗**（但极性相反）
        
5. **状态三：全部能量回到电容中（钟摆到另一侧最高点）**
    
    - 电感电流下降到0，磁能为0。
        
    - 电容被反向充电到 `-V_max`，电能再次达到最大。
        
    - **此时：电能最大，磁能为零。**
        

然后，整个过程反向重复（电容反向放电...），如此循环，形成**正弦振荡**。

### 四、关键参数：谐振频率

就像钟摆的摆动频率只由其臂长和重力决定一样，LC回路的振荡频率也只由它自身的**电感（L）** 和**电容（C）** 决定，这就是**谐振频率**。

**计算公式： f₀ = 1 / (2π√(L * C))**

- **L 越大**：惯性越大，电流变化越慢，振荡频率 **越慢**。
    
- **C 越大**：能储存的电荷越多，充放电时间越长，振荡频率 **越慢**。
    

### 五、现实世界：衰减振荡

在理想的、没有损耗的LC回路中，振荡会永远持续。但现实世界中，一切都有电阻：

- 电感的导线电阻
    
- 电容的等效串联电阻（ESR）
    
- PCB走线的电阻
    

这些电阻会在一轮轮的能量转换中**消耗能量（转化为热量）**，就像给钟摆加了**空气摩擦**。因此，振荡的幅度会一次比一次小，最终停止下来，形成您之前在BUCK电路开关节点看到的**衰减振荡**，也就是**振铃**。

### 总结

**LC谐振的本质是能量在电感的磁场和电容的电场之间无损耗（或低损耗）地来回转换，并表现为电压和电流的正弦振荡。** 其振荡频率由L和C的乘积决定。

这个原理被广泛应用于：

- **收音机调台**：通过调节LC的谐振频率来选择不同电台的载波频率。
    
- **时钟发生器**：为数字系统提供稳定的时钟信号。
    
- **滤波器**：让特定频率的信号通过，而阻挡其他频率。
    
- **开关电源的振铃**：作为需要被抑制的寄生效应。
