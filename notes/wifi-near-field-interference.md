# WIFI 近场干扰

问题：W302D wifi天线干扰到音频线，导致出现电流声及滴滴的声音

好问题。我们先拆成两块：**「近场与远场」概念澄清**，再聚焦 **「音频线耦合干扰」这一具体痛点**，最后给出一套**可落地执行的解决方案**。

---

## 一、WIFI 5G 频段的近场与远场

5G WiFi 频段（如 5.150~5.850GHz）中心波长约 **5.5cm**（λ = c/f）。

| 区域                  | 距离天线                      | 电磁场特性                         | 工程关注点                  |
| ------------------- | ------------------------- | ----------------------------- | ---------------------- |
| **近场（反应近场 + 辐射近场）** | < λ/2π ≈ **8.7mm**        | 电场与磁场非比例关系，能量在器件间来回震荡（感应场）    | 天线阻抗匹配、邻近金属件调谐、耦合串扰严重  |
| **过渡区（Fresnel区）**   | 约 0.1λ ~ 1λ （0.5~5.5cm）   | 场结构复杂，方向图未稳定                  | 天线罩、外壳影响最佳测试位置         |
| **远场（Fraunhofer区）** | > 2D²/λ（通常 > 1~2λ ≈ 10cm） | 电磁波近似平面波，E/H 比值固定（377Ω），方向图稳定 | 天线增益、波束宽度、法规测试（FCC/CE） |

> **对设计的影响**：  
> - 如果音频线距离WIFI天线 **< 8mm** 且处于5G频段，那么耦合主要来自**近场感应**，非常强且难以用简单滤波解决。  
> - 如果距离 **> 10cm**，则基本属于远场辐射耦合，用屏蔽线 + 共模扼流圈通常能大幅改善。

---

## 二、音频线耦合“电流声 + 保活包滴滴声”的根本原因

**电流声** → 通常是 **50/60Hz 工频或开关电源纹波**（几百kHz~几MHz）耦合进音频路径。  
**保活包滴滴声** → 这是因为WIFI模块会**周期性发射数据包**（如每100ms），射频载波被整流（通过晶体管的PN结或连接器非线性）后产生**可听频域的包络噪声**（类似PWM噪声），然后耦合到音频地或信号线。

关键路径一般有3条：

1. **空间耦合**：电磁场直接感应到裸漏的音频线或PCB走线（近场>远场）。
2. **地电流耦合**：射频电流流经公共地，在音频地回路上产生压降，被音频放大器放大。
3. **电源耦合**：WIFI射频前端的PA瞬间拉大电流，导致电源波动，而音频供电没有隔离好。

## 三、可量产落地的一揽子方案（按
优先级排序）

### ✅ 方案一：物理隔离（成本最低，效果最好）

| 操作        | 具体做法                                         |
| --------- | -------------------------------------------- |
| **拉开距离**  | 音频线（包括走线）尽量放在板边，**距离 WIFI 天线至少 20mm**（远场区外）。 |
| **净空区要求** | 天线下方所有层需掏空地铜，音频线禁止穿行净空区。                     |
| **90°交叉** | 如果必须在同层交叉，使用 90° 交叉 + 中间用地层隔开（多层板优势）。        |
| **屏蔽罩**   | 为 WIFI 模块+射频前端加屏蔽罩（五面体），且**开缝不要正对音频走线方向**。   |

### ✅ 方案二：地回路设计（几乎零成本，效果显著）

- **星形接地**：音频地、数字地、射频地在电源输入端汇于一点，避免环形地。
- **音频地独立**：将音频功放、Codec、音频插座的地通过**磁珠（如 600Ω @100MHz）或 0Ω电阻**单点连接到主地。
- **减小射频回路面积**：WIFI 模块的滤波电容尽量靠近馈点，射频电流不要经过大片音频地。

### ✅ 方案三：音频线路滤波（批量成本增加几毛钱）

| 滤波器类型 | 对于5G 4900-5850MHz 干扰 | 对于工频/开关纹波 |
| --- | --- | --- |
| **共模扼流圈（CMC）** | ✅ 非常有效，抑制共模射频共模噪声 | 对差模噪声效果弱 |
| **差分LC滤波器** | 需要截止频率<1MHz才能抑制射频，但会影响音频带宽 | 有效抑制开关噪声 |
| **铁氧体磁珠** | 贴片磁珠（如1800Ω @100MHz）串在音频线上 | 对低频纹波几乎无效 |

> **推荐组合**：  
> 在音频差分线对（正负）上各串一个 **300~600Ω @100MHz 的磁珠**，再对地并联 **2个 22pF + 100pF 电容**（陶瓷COG），形成 π 型滤波。  
> 如果音频线是单端（如耳机MIC），在信号线对地并联 **22pF + 100pF**，并串磁珠。

### ✅ 方案四：电源去耦（适合电流声+启动瞬态）

- 为音频模块使用独立 **LDO (如 TPS7A20、AMS1117-3.3)**，输入端加 10μF + 0.1μF + 1nF 组合电容。
- 在 LDO 输出端加磁珠（如 600Ω @100MHz）后给音频供电，避免 PA 拉电流倒灌。

### ✅ 方案五：软件/固件层面规避（零成本，但需确认可行性）

- **调整保活包的发射时序**：将 WIFI 保活包的发射时刻与音频采样时钟对齐（例如在音频采样间隔中发射），或者**推迟到静音时隙**。
- **降低发射功率**：如果信噪比有余量，降低 PA 增益可以减少射频能量辐射。
- **使用低功耗空口模式**：如 802.11ax 的 Target Wake Time (TWT)，可更主动地规划发射时间。

### ✅ 方案六：测试与验证清单（确保问题落地）

1. **近场探头扫描**：在音频线路上用频谱仪+近场探头，看5G频段能量强度，确认主要耦合路径。
2. **接地阻抗测试**：用万用表测量音频地与WIFI模块地之间的交流阻抗（1MHz~100MHz），若阻抗过高则需加宽地平面。
3. **替换法**：临时断开WIFI天线，换一个**50Ω负载**（假负载），看噪声是否消失 → 消失说明是天线辐射引起；若还有，多半是电源或地耦合。
4. **波形测量**：用示波器挂在音频输出，抓取“滴滴声”波形的时间位置，与WIFI发包的GPIO信号同步对比。

## 四、工程落地顺序建议（快速解决 + 量产稳定）

| 步骤     | 操作                           | 预期效果                | 时间       |
| ------ | ---------------------------- | ------------------- | -------- |
| **1天** | 拉开天线与音频线物理距离 > 20mm，加磁珠+电容滤波 | 噪音降低 10~15dB        | 原理图/布局小改 |
| **2天** | 做地回路切割（音频地串磁珠），电源独立LDO       | 可消除大部分电流声           | 板级验证     |
| **3天** | 协调软件工程师调整保活包发射时机             | 彻底消除“滴滴声”（如果耦合源于包络） | 固件改动     |
| **1周** | 打样 + 调测 + 暗室预扫（辐射发射 & 音频信噪比） | 确认符合量产标准            | 完整验证     |
