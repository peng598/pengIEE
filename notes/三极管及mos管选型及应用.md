# MOS 管及三极管开关选型与设计经验指南

本文面向硬件原理图设计、产品调试、器件替代和失效分析。重点不是背参数，而是回答工程中真正会遇到的问题：

- 什么时候用三极管比 MOS 管更合适？
- 什么时候 MOS 管明显更优？
- 怎么根据负载、电压、电流、速度、漏电、温升和成本做选型？
- 基极电阻、栅极电阻、上拉下拉、续流、TVS、布局应该怎么设计？
- 调试时看到发热、误动作、烧管、关不掉、开不全，该从哪里查？

## 2. 一句话结论

三极管 BJT 是“用持续的基极电流换确定导通”，MOSFET 是“用足够的栅极电压和栅极驱动能力换低导通损耗”。

实战里可以先这样判断：

| 条件 | 更常优先选 |
|---|---|
| 小电流、低频、低成本、GPIO 能给出足够基极电流 | NPN/PNP 三极管 |
| 中大电流、长时间导通、效率和温升敏感 | MOS 管 |
| MCU 电压低，但 MOS 没有在该栅压下给出 `RDS(on)` | 三极管或换真正逻辑级 MOS |
| 关断漏电特别敏感 | 小信号三极管或低漏电 MOS，按数据手册确认 |
| 不允许体二极管造成反向导通 | 三极管、背靠背 MOS、专用负载开关 |
| 高频 PWM、大电流、电机驱动 | MOS 管加合适栅极驱动 |
| 高边电源开关，压降低、效率高 | PMOS、NMOS 高边驱动或专用负载开关 |
| 简单电平反相、开漏输出、低速控制 | NPN 三极管或 NMOS |

## 3. 核心差异：电流驱动与电压驱动

### 3.1 三极管 BJT

三极管有 NPN、PNP 两类。做开关时常工作在截止区和饱和区。

- NPN 低边开关：负载接电源，三极管接地侧。
- PNP 高边开关：负载接地，三极管接电源侧。
- 导通需要基极电流。
- 饱和后压降近似为 `VCE(sat)`。
- 关断时需要把基极电荷释放掉。

典型损耗：

```text
P_BJT ≈ VCE(sat) × IC + VBE × IB
```

工程上常用“强迫 β”保证饱和：

```text
IB ≥ IC / β_forced
```

低速开关常取：

```text
β_forced = 5 ~ 20
```

常用保守起点：

```text
β_forced = 10
```

### 3.2 MOSFET

MOS 管有 NMOS、PMOS 两类。做开关时主要看栅源电压 `VGS` 是否足够、导通电阻 `RDS(on)` 是否足够低。

- NMOS 低边开关最常见。
- PMOS 高边开关简单，但同尺寸下电阻通常比 NMOS 大。
- 栅极直流电流很小，但有栅极电容，开关瞬间需要充放电。
- 导通损耗主要由 `RDS(on)` 决定。
- 绝大多数离散 MOS 带体二极管，会影响反向电流路径。

典型损耗：

```text
P_MOS(conduction) ≈ ID² × RDS(on)
```

栅极驱动平均功耗：

```text
P_gate ≈ Qg × VGS × fSW
```

## 4. 选型第一步：先定义负载，而不是先找管子

器件选型失败，很多不是因为管子差，而是没有先把负载定义清楚。

选型前至少明确这些条件：

| 项目    | 必须确认                       |
| ----- | -------------------------- |
| 电源电压  | 标称值、最高值、浪涌、反接可能            |
| 负载电流  | 平均电流、峰值电流、启动电流、堵转电流        |
| 负载类型  | 电阻、LED、容性、感性、电机、继电器、加热片    |
| 控制信号  | MCU 电压、GPIO 最大源/灌电流、默认上电状态 |
| 开关频率  | 偶尔开关、低频 PWM、高频 PWM、通信波形    |
| 导通占空比 | 长期开、短脉冲、脉冲宽度               |
| 环境温度  | 常温、密闭、高温、贴近热源              |
| 关断要求  | 允许漏电多少，是否允许反向电流            |
| 保护要求  | 短路、过压、ESD、浪涌、插拔、反接         |
| 成本与供应 | 封装、库存、替代料、产线可焊性            |

经验规则：

- 继电器、电磁阀、电机这类负载，必须考虑感性反冲。
- 灯泡、加热丝、风扇这类负载，必须考虑启动浪涌。
- 大电容电源开关，必须考虑上电冲击和 MOS 的 SOA。
- 低功耗传感器供电开关，必须考虑关断漏电和体二极管。
- 高频 PWM，必须同时算导通损耗、开关损耗和驱动能力。

## 5. 快速决策树

### 5.1 低边开关

负载一端接正电源，另一端由管子拉到地。

优先级：

1. 电流小于 `50 mA`，频率低，GPIO 能提供足够基极电流：NPN 简单可靠。
2. 电流大于 `100 mA` 或长期导通：优先逻辑级 NMOS。
3. PWM 频率较高或电流较大：NMOS 加栅极驱动器。
4. 负载是线圈、电机：加续流路径、TVS 或吸收网络。

### 5.2 高边开关

管子在电源正端，控制负载供电。

优先级：

1. 小电流、低成本、压降不敏感：PNP。
2. 中等电流、压降和发热敏感：PMOS。
3. 大电流、低压降、高效率：NMOS 高边驱动或专用负载开关。
4. 需要限流、过温、软启动、反灌保护：专用负载开关或 eFuse。

### 5.3 电平转换与反相

低速逻辑反相、开漏、开集电极：

- NPN 或小信号 NMOS 都可。
- NPN 对阈值更像 PN 结，输入约 `0.7 V` 开始明显导通。
- NMOS 对阈值依赖器件差异，必须确认 `VGS(th)` 与实际逻辑电平的裕量。

### 5.4 模拟小信号控制

如果是模拟开关、采样保持、音频小信号、传感器信号：

- 普通 BJT 和普通 MOS 都可能引入非线性。
- 优先考虑模拟开关 IC、JFET、低泄漏 MOS、光耦或继电器。
- 关注导通电阻平坦度、电荷注入、漏电、寄生电容，而不只看电流。

## 6. 导通损耗怎么判断

### 6.1 BJT 导通损耗

BJT 饱和导通后不是理想短路，而是有 `VCE(sat)`。

```text
P ≈ VCE(sat) × IC
```

例子：

```text
IC = 200 mA
VCE(sat) = 0.2 V
P ≈ 0.2 × 0.2 = 0.04 W
```

这个功耗不大，SOT-23 小管通常可接受。

但如果：

```text
IC = 1 A
VCE(sat) = 0.25 V
P ≈ 0.25 W
```

在小封装中温升会明显，且 GPIO 可能提供不了所需基极电流。

### 6.2 MOS 导通损耗

MOS 导通后近似为电阻：

```text
P ≈ I² × RDS(on)
```

例子：

```text
I = 2 A
RDS(on) = 50 mΩ
P ≈ 2² × 0.05 = 0.2 W
```

同样电流下如果 MOS 实际 `RDS(on)` 是 `500 mΩ`：

```text
P ≈ 2² × 0.5 = 2 W
```

这就会严重发热。

### 6.3 交叉点估算

比较 BJT 和 MOS 的导通损耗，可用：

```text
VCE(sat) ≈ I × RDS(on)
I_cross ≈ VCE(sat) / RDS(on)
```

例如：

```text
VCE(sat) = 0.2 V
RDS(on) = 1 Ω
I_cross = 0.2 A
```

大于 `200 mA` 时，MOS 的压降可能超过 BJT。这个例子常出现在错误使用“非逻辑级 MOS”或栅压不足时。

再看低阻 MOS：

```text
VCE(sat) = 0.2 V
RDS(on) = 30 mΩ
I_cross ≈ 6.7 A
```

此时在几安培范围内 MOS 明显更优。

## 7. MOS 选型最容易踩的坑：误用 VGS(th)

`VGS(th)` 不是完全导通电压。

数据手册中的 `VGS(th)` 通常定义为：

```text
ID = 250 µA 或 1 mA 时的栅源电压
```

这只表示 MOS 刚刚开始有微小电流，不能说明它能带 `500 mA`、`2 A` 或 `10 A`。

正确看法：

| 参数 | 正确用途 |
|---|---|
| `VGS(th)` | 判断大致开启门槛、关断裕量、器件批次漂移 |
| `RDS(on) @ VGS=10V` | 适合 10V/12V 栅极驱动 |
| `RDS(on) @ VGS=4.5V` | 可用于 5V MCU 驱动的初步判断 |
| `RDS(on) @ VGS=2.5V` | 可用于 3.3V 系统的初步判断 |
| `RDS(on) @ VGS=1.8V` | 适合 1.8V 逻辑直接驱动 |

如果数据手册只写：

```text
RDS(on) @ VGS = 10 V
```

而你的 MCU 只有 `3.3 V`，不要默认它能低阻导通。

工程建议：

- 3.3V GPIO 直接驱动时，优先选择明确给出 `RDS(on) @ VGS=2.5V` 或 `3.0V` 的 MOS。
- 1.8V GPIO 直接驱动时，必须找明确支持 `1.8V` 栅压的 MOS，或加驱动/电平转换。
- 不要只看商品标题写“逻辑级”，要看数据手册的 `RDS(on)` 测试条件。

## 8. BJT 选型与基极电阻设计

### 8.1 BJT 关键参数

| 参数 | 选型意义 |
|---|---|
| `VCEO` | 集电极-发射极耐压，必须高于电源和尖峰 |
| `IC` | 持续集电极电流，必须高于负载电流 |
| `ICM` | 脉冲电流，评估启动浪涌 |
| `VCE(sat)` | 饱和压降，决定发热和负载实际电压 |
| `hFE` | 放大倍数，开关饱和设计不能只按典型值 |
| `PD` | 封装耗散功率 |
| `fT` | 高频能力，小信号参数，不等于饱和开关速度 |
| `Cob/Cib` | 寄生电容，影响高频和边沿 |
| `ICBO/ICEO` | 漏电，低功耗和高温场景重要 |

### 8.2 低边 NPN 基极电阻计算

典型电路：

```text
VCC ─ 负载 ─ 集电极 C
                 NPN
GND ───────── 发射极 E
MCU ─ Rb ─── 基极 B
```

计算步骤：

1. 确定负载电流 `IC`。
2. 选择强迫放大倍数 `β_forced`，低速开关常用 `10`。
3. 计算基极电流：

```text
IB = IC / β_forced
```

4. 计算基极电阻：

```text
Rb = (VGPIO - VBE(sat)) / IB
```

常用估算：

```text
VBE(sat) ≈ 0.8 V
```

例子：3.3V MCU 控制 100mA 负载。

```text
IC = 100 mA
β_forced = 10
IB = 10 mA
Rb = (3.3 - 0.8) / 0.01 = 250 Ω
```

这说明 MCU 要输出约 `10 mA`，很多 GPIO 虽然能做到，但已经不算轻松。若 MCU 推荐单脚电流只有 `2 mA` 或 `4 mA`，就不适合这样硬推 BJT 饱和。

### 8.3 经验取值

| 负载电流 | NPN 低边开关常见起点 |
|---|---|
| 1 mA | `Rb = 10kΩ ~ 47kΩ` |
| 10 mA | `Rb = 2.2kΩ ~ 10kΩ` |
| 50 mA | `Rb = 1kΩ ~ 4.7kΩ` |
| 100 mA | `Rb = 470Ω ~ 2.2kΩ`，需核查 GPIO |
| 大于 200 mA | 通常优先考虑 MOS 或驱动级 |

不要机械套表，最终以饱和压降、GPIO 能力和温升验证。

### 8.4 基极下拉或上拉

为了避免上电复位期间误导通：

- NPN 低边开关：基极对地加 `47kΩ ~ 200kΩ` 下拉。
- PNP 高边开关：基极对发射极加 `47kΩ ~ 200kΩ` 上拉。

如果环境噪声强、线很长、负载危险，应取更强的偏置，例如 `10kΩ ~ 47kΩ`。

## 9. MOS 选型与栅极驱动设计

### 9.1 MOS 关键参数

| 参数 | 选型意义 |
|---|---|
| `VDS` | 漏源耐压，要覆盖电源、浪涌、感性尖峰 |
| `ID` | 电流能力，不能只看首页大字，要结合封装散热 |
| `RDS(on)` | 导通电阻，必须看实际 `VGS` 条件 |
| `VGS(max)` | 栅源耐压，常见为 `±20V` 或更低 |
| `Qg` | 总栅电荷，决定驱动难度和开关损耗 |
| `Qgd` | 米勒电荷，影响开关平台和 dv/dt 误导通 |
| `Ciss/Coss/Crss` | 寄生电容，影响高速开关和振铃 |
| `VSD` | 体二极管压降 |
| `tr/tf/td` | 在指定驱动条件下的开关时间 |
| `EAS` | 单脉冲雪崩能力 |
| `SOA` | 安全工作区，线性区和热插拔尤其关键 |
| `RθJA/RθJC` | 热阻，决定实际温升 |

### 9.2 低边 NMOS 典型电路

```text
VCC ─ 负载 ─ D  NMOS  S ─ GND
              G
              │
MCU ─ Rg ─────┘
      │
     Rpd
      │
     GND
```

常用起点：

| 元件 | 起始值 | 作用 |
|---|---:|---|
| 栅极串联电阻 `Rg` | `10Ω ~ 100Ω` | 抑制振铃、限制瞬态栅极电流、降低 EMI |
| 栅极下拉 `Rpd` | `47kΩ ~ 200kΩ` | 防止上电悬空误导通 |
| 栅源齐纳 | `5.1V ~ 15V` | 保护栅极，视驱动电压选择 |
| 漏源 TVS | 按电源和尖峰选 | 吸收感性尖峰和浪涌 |

### 9.3 GPIO 直接驱动 MOS 的限制

GPIO 直接驱动 MOS 适合：

- 低频开关。
- 小到中等栅电荷 MOS。
- 负载电流不大。
- 边沿速度要求不高。

不适合：

- 高频 PWM。
- 大功率 MOS。
- 半桥、全桥。
- 电机驱动。
- 需要快速关断的保护开关。

估算 GPIO 能否驱动：

```text
t_drive ≈ Qg / I_GPIO
```

例如：

```text
Qg = 20 nC
GPIO 实际可提供 5 mA
t ≈ 20 nC / 5 mA = 4 µs
```

如果 PWM 是 `20 kHz`，周期 `50 µs`，4µs 的边沿已经不短，开关损耗和发热可能明显。

### 9.4 栅极电阻不是越小越好

栅极电阻太小：

- 边沿过快，EMI 增大。
- 漏极振铃明显。
- 栅极可能过冲超过 `VGS(max)`。
- 半桥中更容易出现误导通。

栅极电阻太大：

- 开关变慢。
- 开关损耗增加。
- PWM 下发热。
- 关断延迟变大。

经验：

- 低速开关：`47Ω ~ 220Ω` 常见。
- 中高速 PWM：`5Ω ~ 33Ω` 常见，需要示波器看波形。
- 半桥驱动：开通和关断可用二极管分离电阻，分别优化。

## 10. 开关损耗与频率

低频开关通常只算导通损耗即可。高频 PWM 必须算开关损耗。

MOS 近似开关损耗：

```text
P_sw ≈ 0.5 × VDS × ID × (tr + tf) × fSW
```

总损耗：

```text
P_total ≈ ID² × RDS(on) × D + P_sw + P_gate
```

其中：

- `D` 是占空比。
- `tr/tf` 是上升/下降时间。
- `P_gate ≈ Qg × VGS × fSW`。

例子：

```text
VDS = 24 V
ID = 3 A
tr + tf = 200 ns
fSW = 100 kHz
P_sw ≈ 0.5 × 24 × 3 × 200 ns × 100 kHz
P_sw ≈ 0.72 W
```

如果驱动能力差，边沿变成 `1 µs`：

```text
P_sw ≈ 3.6 W
```

这就是“低频不热，高频一 PWM 就热”的常见原因。

BJT 高频开关也有问题：

- 饱和后有存储时间。
- 基极电荷释放慢会拖尾。
- 可用基极-发射极泄放电阻或 Baker clamp 改善。
- 高频大电流场景通常不用普通 BJT 饱和开关。

## 11. 漏电、反向电流和真正关断

### 11.1 MOS 的关断漏电

MOS 关断漏电 `IDSS` 会随温度上升显著变大。低功耗产品不能只看 25°C 典型值，应看：

- 最高工作温度。
- 最大值而非典型值。
- `VDS` 测试条件。

电池设备中，若负载休眠电流只有几微安，MOS 的高温漏电可能已经不能忽略。

### 11.2 BJT 的关断漏电

BJT 也有漏电，如 `ICBO`、`ICEO`。高温下同样会上升。

小信号 BJT 在某些低压低漏电场景下可能比功率 MOS 更合适，但不能凭经验绝对判断，必须查目标型号数据。

### 11.3 MOS 体二极管造成的反向通路

离散 MOS 基本都有体二极管。

低边 NMOS 中体二极管通常不影响正常低边开关，但在高边、电源切换、反接、双电源域中会非常关键。

常见问题：

- 关断后负载被反向供电。
- 多路电源相互反灌。
- 电池和 USB 之间形成非预期通路。
- 电机桥臂续流路径失控。

解决方法：

- 使用背靠背 MOS。
- 使用专用负载开关。
- 使用理想二极管控制器。
- 使用继电器或光耦继电器。
- 在小电流场景改用 BJT 或二极管隔离。

---

## 12. 感性负载设计：继电器、电机、电磁阀

感性负载断电时会试图维持电流，产生高压尖峰。没有吸收路径时，开关管会承受过压甚至击穿。

### 12.1 续流二极管

继电器线圈、电磁阀低速开关常用：

```text
二极管反并联在线圈两端
```

优点：

- 简单便宜。
- 对开关管保护强。
- 尖峰电压低。

缺点：

- 线圈释放慢。
- 继电器断开延迟变长。
- 电磁阀响应变慢。

### 12.2 TVS 或齐纳钳位

如果需要快速释放：

- 用 TVS 钳位到较高电压。
- 用二极管串齐纳。
- 用 RC 吸收。

较高钳位电压让电感电流衰减更快，但开关管耐压和雪崩能力必须足够。

### 12.3 电机负载

电机比继电器更复杂：

- 启动电流可能是额定电流的数倍。
- 堵转电流可能非常大。
- 碳刷电机会产生强噪声。
- 反电动势会影响开关管电压。
- PWM 会带来 EMI 和开关损耗。

电机驱动建议：

- 小电机低频开关可用 NMOS 低边加 TVS。
- PWM 调速优先用 MOS，加合适栅极驱动。
- 双向控制用 H 桥或专用电机驱动芯片。
- 电机两端可加 RC、磁珠、共模电感或电容抑制噪声。

---

## 13. 低功耗设计经验

低功耗开关设计关注点和功率开关不同。

### 13.1 BJT 的基极电流是持续功耗

BJT 导通时一直消耗基极电流。

例子：

```text
3.3V MCU
IB = 1 mA
导通时间占空比 100%
基极驱动功耗约为 3.3 mW
```

对普通产品不大，但对纽扣电池或长期待机设备可能不能接受。

### 13.2 MOS 的栅极静态功耗很低

MOS 栅极直流近似不耗电，低频开关时很适合低功耗。

但要注意：

- 栅极上拉/下拉电阻会消耗静态电流。
- 过小的上拉/下拉浪费电。
- 电平转换电路可能有静态电流。
- MOS 漏电和体二极管可能破坏断电效果。

### 13.3 上拉下拉电阻取值

低功耗产品常希望电阻大一些：

```text
100kΩ ~ 1MΩ
```

但电阻太大：

- 上电状态容易被干扰。
- 节点边沿慢。
- 湿度、污染、漏电会影响状态。
- 长线输入容易误触发。

工程折中：

- 板内短线、低噪声：`100kΩ ~ 470kΩ`。
- 外部接口、长线、强干扰：`4.7kΩ ~ 47kΩ`。
- 安全相关默认状态：宁可增加一点功耗，也要确保默认关断。

## 14. 高边开关设计

### 14.1 PNP 高边

典型电路：

```text
VCC ─ E  PNP  C ─ 负载 ─ GND
        B
        │
       控制
```

PNP 导通条件：

```text
VB 比 VE 低约 0.7V 以上
```

优点：

- 电路简单。
- 小电流成本低。
- 不需要高边驱动芯片。

缺点：

- 有基极电流消耗。
- 压降为 `VCE(sat)`。
- 大电流时驱动困难。
- MCU 低压直接控制高电压 PNP 需要电平转换。

### 14.2 PMOS 高边

典型电路：

```text
VCC ─ S  PMOS  D ─ 负载 ─ GND
        G
        │
       控制
```

PMOS 导通条件：

```text
VG 比 VS 低足够多
VGS 为负且幅值足够
```

优点：

- 静态驱动电流小。
- 压降可低于 PNP。
- 中小电流电源开关常用。

缺点：

- 同尺寸下 `RDS(on)` 通常高于 NMOS。
- 栅极不能被拉得过低导致 `VGS(max)` 超限。
- 高电压电源由低压 MCU 控制时需要电平转换和栅源保护。

### 14.3 NMOS 高边

NMOS 高边要让栅极高于源极：

```text
VG > VS + 所需 VGS
```

如果源极接在负载上，导通后源极接近电源电压，因此栅极需要比电源更高。常用方案：

- 自举高边驱动。
- 电荷泵高边驱动。
- 隔离驱动。
- 专用高边开关芯片。

适合：

- 大电流。
- 低压降。
- 半桥、全桥、电机驱动、电源转换。

## 15. 保护设计

### 15.1 基本保护清单

| 风险 | 常用措施 |
|---|---|
| 感性反冲 | 续流二极管、TVS、RC 吸收、RCD 吸收 |
| 栅极过压 | 栅源齐纳、栅极电阻、TVS |
| 电源浪涌 | TVS、保险丝、限流、电源滤波 |
| 反接 | 串二极管、PMOS/NMOS 理想二极管、保险丝 |
| 短路 | 限流、采样电阻、eFuse、保护芯片 |
| 热失控 | 降额、热关断、铜皮散热、温度检测 |
| ESD | TVS、串阻、保护二极管、布局隔离 |
| 误导通 | 栅极下拉、基极下拉、默认态设计 |

### 15.2 MOS 栅极保护

MOS 栅极氧化层怕过压。常见 `VGS(max)`：

```text
±20 V
±12 V
±8 V
```

低压逻辑 MOS 可能栅极耐压更低，不能按 `±20V` 想当然。

高电压 PMOS 高边例子：

```text
VCC = 24 V
PMOS 源极接 24 V
如果栅极被 NPN 直接拉到 GND
VGS = 0 - 24 = -24 V
```

这可能超过 `VGS(max)`，需要栅源齐纳或分压限制。

### 15.3 BJT 基极保护

BJT 的基极-发射极反向耐压通常不高，常见只有 `5V ~ 7V`。在交流、感性耦合、长线输入中，要避免基极-发射极被反向击穿。

常用措施：

- 基极串联电阻。
- 基极-发射极并联反向二极管。
- 输入端加 TVS。
- 长线输入加 RC 滤波。

---

## 16. 低压 MCU 控制高压负载

常见组合：

```text
MCU 3.3V 控制 12V/24V 负载
```

### 16.1 低边开关

最简单：

- NPN 低边。
- NMOS 低边。

只要负载允许低边断开，优先低边方案。

注意：

- MCU 地必须和负载电源地共地，除非用隔离。
- 感性负载续流路径要回到负载电源，不要让 MCU 地承受尖峰。
- MOS 源极要接系统地，保证 `VGS` 明确。

### 16.2 高边开关

如果负载必须接地，电源正端开关：

- 小电流用 PNP 或 PMOS。
- 24V 系统用 MCU 直接控制 PMOS 栅极通常不安全，需要 NPN/NMOS 做电平转换。
- PMOS 栅源要加钳位，避免 `VGS` 过压。
- 大电流用专用高边开关更省心。

### 16.3 光耦隔离

需要隔离时：

- 控制侧和负载侧地不共地。
- 光耦输出可驱动 BJT、MOS 或专用驱动器。
- 注意光耦 CTR、速度、温漂和饱和延迟。
- 大电流 MOS 不能直接靠普通光耦慢慢推，通常要加驱动级。

## 17. 常见电路模板

### 17.1 MCU 控制 LED

小电流单颗 LED：

- GPIO 直接驱动即可，串限流电阻。
- 如果电流较大或多路 LED：NPN 或 NMOS 低边。

NPN 适合：

- `5mA ~ 50mA`。
- 低频开关。
- 成本敏感。

NMOS 适合：

- 多颗 LED。
- PWM 调光。
- 电流较大。

### 17.2 MCU 控制继电器

推荐：

- NPN 低边或 NMOS 低边。
- 线圈两端加续流二极管。
- 如需快速释放，用 TVS 或二极管串齐纳。
- MCU 引脚加基极/栅极串阻和默认下拉。

选 BJT 时：

```text
IB ≥ Icoil / 10
```

如果线圈电流 `100mA`，基极要约 `10mA`，这对 MCU 可能偏大，此时 NMOS 更好。

### 17.3 MCU 控制蜂鸣器

无源蜂鸣器：

- 高频驱动，优先 NMOS 或推挽驱动。
- BJT 可以用，但要考虑存储时间和驱动电流。

有源蜂鸣器：

- 低频开关，NPN 或 NMOS 都可。
- 注意启动电流和反向电动势。

### 17.4 小风扇

小直流风扇是电机负载：

- 优先 NMOS 低边。
- 加 TVS 或续流路径。
- PWM 频率要避开可闻噪声或按风扇规格选择。
- 有些四线风扇应使用专用 PWM 控制脚，不建议直接切电源调速。

### 17.5 电源域开关

给传感器、模块、射频芯片断电：

- 高边 PMOS 或负载开关 IC。
- 注意模块 IO 反灌电流。
- 注意 MOS 体二极管方向。
- 需要真正断电时，检查所有信号线是否通过 ESD 二极管反向供电。

### 17.6 大电流加热片

加热片近似电阻负载：

- 优先低 `RDS(on)` NMOS。
- 看稳态功耗和 PCB 铜皮散热。
- PWM 频率不需要太高，低频可降低开关损耗。
- 注意冷态阻值可能低于热态阻值。

## 18. 速度、存储时间和米勒效应

### 18.1 BJT 饱和后的关断慢

BJT 深饱和后，基区储存电荷较多，关断时需要释放，表现为：

- 集电极电流拖尾。
- 波形关断慢。
- 高频下损耗增加。
- 关断延迟不稳定。

改善方法：

- 不让 BJT 进入深饱和。
- 使用 Baker clamp。
- 基极加泄放电阻。
- 基极反向抽电流。
- 改用肖特基钳位三极管或 MOS。

### 18.2 MOS 米勒平台

MOS 开关时，栅极电压会在米勒平台附近停留。此时漏极电压变化，栅极驱动电流主要用于给 `Cgd` 充放电。

现象：

- 栅极波形有平台。
- 漏极电压下降/上升期间损耗最大。
- 驱动能力不足时平台时间变长。

改善：

- 降低栅极电阻。
- 使用栅极驱动器。
- 选低 `Qg`、低 `Qgd` MOS。
- 优化 PCB 回路。

### 18.3 dv/dt 误导通

漏极快速变化会通过 `Cgd` 耦合到栅极，可能使 MOS 误导通。

常见于：

- 半桥。
- 电机驱动。
- 长线感性负载。
- 高压快速开关。

措施：

- 栅极下拉更强。
- 驱动器具备 Miller clamp。
- 关断电阻更小。
- 栅源并电容需谨慎，会增加驱动损耗。
- 优化功率回路和栅极回路布局。

## 19. EMI 与波形调试

开关管不是只要能开关就行，边沿会产生 EMI。

### 19.1 EMI 来源

| 来源 | 说明 |
|---|---|
| 高 `dv/dt` | 电压快速变化通过寄生电容耦合 |
| 高 `di/dt` | 电流快速变化在寄生电感上产生尖峰 |
| 回路面积大 | 辐射增强 |
| 栅极振铃 | 可能误导通或超过栅极耐压 |
| 漏极振铃 | 可能超过 `VDS` 或产生强干扰 |

### 19.2 调试顺序

1. 用示波器短地弹簧测漏极波形。
2. 看栅源波形，不只看对地栅极波形。
3. 看源极是否因公共电感产生跳动。
4. 调整栅极电阻，观察边沿和温升。
5. 必要时加 RC snubber 或 TVS。
6. 检查功率回路面积和地回流。

### 19.3 栅极电阻调试经验

如果 EMI 大、振铃大：

- 适当增大开通电阻。
- 加强关断能力，避免误导通。
- 开通和关断用二极管分开调。

如果 MOS 发热大：

- 看是否边沿太慢。
- 降低栅极电阻或加驱动器。
- 选更低 `Qg` 或更低 `RDS(on)` 的平衡型号。

## 20. 默认状态与上电时序

很多“偶发动作”都发生在上电、复位、下载程序、掉电瞬间。

### 20.1 必须定义默认态

每个控制管都应明确：

- MCU 复位时是开还是关？
- MCU 引脚高阻时是开还是关？
- 电源慢上升时会不会半导通？
- 下载程序时引脚复用会不会误触发？
- 外部插拔时会不会瞬间导通？

### 20.2 常见做法

NPN/NMOS 低边：

- 基极/栅极下拉。
- 默认关断。

PNP/PMOS 高边：

- 基极/栅极上拉到源极/发射极。
- 默认关断。

关键负载：

- 使用双级控制。
- 使用使能芯片。
- 使用上电复位芯片。
- 使用硬件互锁。

## 21. 布局布线经验

### 21.1 功率回路要小

开关管、负载、电源输入电容、续流路径构成高 di/dt 回路。这个回路面积越大，尖峰和辐射越严重。

布局原则：

- 开关管靠近负载或电源路径。
- 续流二极管靠近线圈和开关管。
- TVS 靠近被保护节点。
- 大电流走宽线或铺铜。
- 控制地和功率地避免共用细长回路。

### 21.2 栅极/基极走线

栅极是高阻节点，容易受干扰。

建议：

- 栅极电阻靠近 MOS 栅极。
- 栅极下拉靠近 MOS。
- 栅极线不要与漏极高 dv/dt 节点长距离并行。
- 大功率 MOS 的源极驱动回路尽量短。
- 半桥中优先使用 Kelvin source 封装或单点回到驱动器。

### 21.3 散热铜皮

小封装 MOS 或 BJT 的实际电流能力主要由散热决定。

不要只看数据手册首页的 `ID = 30A` 之类数字，应结合：

- PCB 铜皮面积。
- 层数。
- 环境温度。
- 相邻热源。
- 封装热阻。
- 允许结温。

温升估算：

```text
TJ ≈ TA + P × RθJA
```

例如：

```text
TA = 60°C
P = 0.5 W
RθJA = 100°C/W
TJ ≈ 110°C
```

看起来只有 `0.5W`，在高温密闭环境中已经不轻松。

## 22. 典型选型场景

### 22.1 3.3V MCU 控制 20mA LED

推荐：

- GPIO 直接驱动或 NPN。
- 若多路 PWM，NMOS 也可。

BJT 设计：

```text
IC = 20mA
IB = 2mA
Rb = (3.3 - 0.8) / 2mA ≈ 1.25kΩ
```

可选 `1.2kΩ` 或 `1.5kΩ`。

### 22.2 3.3V MCU 控制 100mA 继电器

BJT：

```text
IB ≈ 100mA / 10 = 10mA
```

GPIO 压力较大。

推荐：

- 逻辑级 NMOS。
- `RDS(on)` 明确在 `VGS=2.5V` 或 `3.3V` 下给出。
- 线圈加续流二极管或 TVS。

### 22.3 5V MCU 控制 12V 1A 灯带

推荐：

- NMOS 低边。
- `VDS ≥ 30V`，更严苛环境可选 `40V` 或 `60V`。
- `RDS(on) @ VGS=4.5V` 足够低。
- 栅极串 `22Ω ~ 100Ω`，下拉 `100kΩ`。

不推荐：

- 小信号 BJT 直接扛 1A。
- 达林顿管，除非能接受较大压降和发热。

### 22.4 24V 电磁阀

推荐：

- NMOS 低边或专用低边驱动。
- `VDS` 至少 `60V`，视浪涌环境可更高。
- 加 TVS 或续流网络。
- 若要求释放快，不只用普通二极管续流。

### 22.5 电池供电传感器断电

推荐：

- 高边 PMOS 或负载开关 IC。
- 查高温漏电。
- 检查 IO 反灌。
- 若需要极低漏电，考虑专用 load switch 或模拟开关。

## 23. 三极管什么时候比 MOS 更好

### 23.1 低成本小电流开关

小电流、低速控制时，NPN 加一个基极电阻非常直接：

- 器件便宜。
- 参数容易理解。
- 对栅极静电不敏感。
- 不容易因为 `VGS(th)` 误判而半导通。

### 23.2 驱动电压不足时

如果手头 MOS 需要 `10V` 才能低阻导通，而系统只有 `3.3V`，MOS 会半导通发热。此时 BJT 只要基极电流足够，可能更稳定。

但更好的方案通常是：

- 换真正逻辑级 MOS。
- 或加 MOS 驱动。

不是说 BJT 永远更好，而是它对“电压驱动不足”的问题不敏感。

### 23.3 反向电流路径更可控

普通 MOS 有体二极管，某些电源切换场景容易反灌。BJT 没有同样的漏源体二极管路径，在小电流高边或隔离控制中可能更省事。

### 23.4 高阻节点和漏电敏感

某些低漏电小信号 BJT 在高阻节点控制中表现好。功率 MOS 的高温漏电未必满足要求。

### 23.5 简单电平整形和反相

BJT 输入像一个 PN 结，阈值直观，做低速电平转换、反相、开集电极输出非常方便。

---

## 24. MOS 什么时候明显更好

### 24.1 中大电流长时间导通

低 `RDS(on)` MOS 的压降和损耗通常远低于 BJT。

例子：

```text
I = 2A
RDS(on) = 30mΩ
Vdrop = 60mV
P = 0.12W
```

BJT 若 `VCE(sat)=0.2V`：

```text
P = 0.4W
```

而且还要持续基极电流。

### 24.2 MCU GPIO 电流有限

比如 `200mA` 负载：

```text
BJT 按 β_forced=10
IB = 20mA
```

很多 MCU GPIO 不适合这么用。MOS 栅极只需要瞬间充放电，低频时 GPIO 压力小得多。

### 24.3 PWM 调速和调光

MOS 更适合 PWM：

- 导通损耗低。
- 不存在 BJT 深饱和存储问题。
- 可用驱动器快速开关。
- 大电流效率高。

### 24.4 并联和热分配

MOS 的导通电阻通常随温度上升，具有一定自动均流倾向。BJT 容易热失控，并联需要发射极均流电阻。

## 25. 常见故障树

### 25.1 MOS 发热

优先检查：

1. `VGS` 是否足够，不是只看 `VG` 对地。
2. `RDS(on)` 是否在实际 `VGS` 下有保证。
3. 负载电流是否有启动浪涌或堵转。
4. PWM 频率是否太高。
5. 栅极电阻是否太大，边沿太慢。
6. 是否进入线性区，例如软启动时间太长。
7. 封装散热是否不足。
8. 漏极尖峰是否超过额定导致雪崩发热。

### 25.2 BJT 发热

优先检查：

1. 基极电流是否不足，未饱和。
2. `VCE(sat)` 是否比预期大。
3. 负载电流是否超过设计。
4. 封装功耗是否不足。
5. 是否使用达林顿导致压降高。
6. 高频开关时存储时间导致损耗。

### 25.3 关不断

MOS：

- 栅极悬空。
- 下拉太弱。
- 体二极管反向供电。
- 漏电过大。
- MCU 引脚复位态不是高阻预期。
- 外部信号通过 ESD 二极管反灌。

BJT：

- 基极悬空。
- 基极偏置残留。
- 驱动级漏电。
- 光耦漏电或 CTR 误判。
- 高温漏电导致微导通。

### 25.4 开不全

MOS：

- 栅压不足。
- 高边 NMOS 没有把栅极抬到源极以上。
- PMOS 的 `VGS` 幅值不够。
- 误用 `VGS(th)`。
- 驱动器电流不足。

BJT：

- 基极电阻太大。
- GPIO 电流不够。
- `β_forced` 取得太乐观。
- 负载电流峰值超过预期。

### 25.5 烧管

常见根因：

- 感性负载无续流。
- `VDS/VCE` 耐压不足。
- 栅极过压。
- 负载短路无保护。
- SOA 超限。
- 反接或热插拔。
- PCB 散热远低于数据手册理想条件。

## 26. 器件替代经验

替代 MOS 时不能只看：

```text
VDS、ID、封装
```

还要看：

- `RDS(on)` 在实际 `VGS` 下是否相当。
- `Qg/Qgd` 是否显著变大。
- `VGS(max)` 是否相同。
- 体二极管恢复特性是否影响电路。
- `SOA` 是否满足热插拔或线性区。
- 引脚排列是否一致。
- 封装散热焊盘是否一致。

替代 BJT 时不能只看：

```text
NPN/PNP、VCEO、IC
```

还要看：

- `VCE(sat)` 在目标 `IC/IB` 下是否相当。
- `hFE` 分档是否影响偏置。
- 封装功耗是否相当。
- 高频参数和存储时间。
- 漏电和温度范围。
- 引脚排列，尤其 SOT-23 不同厂家可能有差异。

---

## 27. 达林顿、数字三极管和专用开关

### 27.1 达林顿管

达林顿管电流放大倍数高，基极驱动省，但缺点明显：

- `VCE(sat)` 高，常见可到 `0.8V ~ 1.2V` 或更高。
- 发热大。
- 速度慢。

适合：

- 继电器阵列。
- 低速大基极增益场景。
- 能接受压降和发热。

不适合：

- 低压大电流。
- 效率敏感。
- 高速 PWM。

### 27.2 数字三极管

数字三极管内部集成基极电阻和下拉/上拉电阻。

优点：

- BOM 少。
- 板子整洁。
- 小信号控制方便。

缺点：

- 内置电阻固定，不能灵活设置基极电流。
- 大电流负载可能驱动不足。
- 替代时要确认内阻比例。

### 27.3 专用负载开关

如果需求包括：

- 软启动。
- 限流。
- 过温保护。
- 反灌保护。
- 欠压锁定。
- 故障指示。

优先考虑负载开关、eFuse、高边开关 IC，而不是用分立管硬拼。

---

## 28. 安全工作区 SOA

`ID` 和 `VDS` 单独都没超，不代表 MOS 安全。尤其在线性区、热插拔、软启动、短路保护中，要看 SOA。

危险场景：

- MOS 用作线性限流。
- 大电容缓慢充电。
- 热插拔输入。
- 电机启动长时间堵转。
- 短路保护动作太慢。

SOA 本质上限制的是：

```text
某个 VDS 下，某个持续时间内，允许通过多大 ID
```

经验：

- 开关应用尽量让 MOS 快速通过线性区。
- 软启动不是越慢越安全，太慢会让 MOS 长时间承受高 `VDS × ID`。
- 大电容上电应用优先使用带 SOA 保证的热插拔/负载开关器件。

---

## 29. 温度降额

所有参数都要考虑温度。

### 29.1 MOS 温度影响

- `RDS(on)` 随温度升高而增大，常可增加 `1.5 ~ 2` 倍。
- 漏电随温度升高增加。
- 结温越高，可靠性越差。

设计时不要只用 25°C 的 `RDS(on)` 算损耗。

保守估算：

```text
RDS(on)_hot = 1.5 × RDS(on)_25°C
```

高温严苛场景可取 `2 ×`。

### 29.2 BJT 温度影响

- `VBE` 随温度升高下降。
- 漏电增加。
- `hFE` 变化大。
- 热失控风险更明显。

BJT 并联时必须非常谨慎，通常需要发射极电阻均流。

## 31. 调试作业卡

### 31.1 上电前

1. 万用表确认负载电阻是否合理。
2. 确认管脚方向、封装引脚和 PCB 封装一致。
3. 确认续流二极管方向。
4. 确认栅极/基极默认态。
5. 限流电源上电。

### 31.2 第一次上电

1. 不接负载，测控制脚默认电平。
2. 接假负载或限流负载。
3. 测 `VGS` 或 `VBE`。
4. 测 `VDS(on)` 或 `VCE(sat)`。
5. 测负载两端电压。
6. 用热像仪或手背远距离感知温升，异常立即断电。

### 31.3 波形测试

MOS：

- 测栅源电压 `VGS`，不是只测栅极对地。
- 测漏源电压 `VDS`。
- 测源极地弹。
- 看栅极是否有过冲、振铃、米勒平台过长。

BJT：

- 测基极电压。
- 测 `VCE(sat)`。
- 看关断拖尾。
- 高频时看集电极波形是否干净。

### 31.4 温升测试

至少测试：

- 最高输入电压。
- 最大负载。
- 最大占空比。
- 最高环境温度或模拟高温。
- 堵转、短路、插拔等异常情况。

记录：

```text
TA 环境温度
TC 封装温度
负载电流
占空比
开关频率
波形尖峰
测试持续时间
```

## 32. 量产与可靠性经验

### 32.1 不要按典型值量产

量产设计应优先用：

- 最大值。
- 最小值。
- 温度范围。
- 批次差异。
- 老化和污染后的漏电变化。

典型值只能帮助理解，不能作为边界设计依据。

### 32.2 降额建议

常用起点：

| 参数 | 建议 |
|---|---|
| `VDS/VCE` | 至少留 `30% ~ 50%` 裕量，感性负载更多 |
| `ID/IC` | 不按首页极限用，结合热设计降额 |
| `VGS(max)` | 正常工作不要贴近极限 |
| 功耗 | 高温下按允许结温反推 |
| 电阻功耗 | 至少 `2×` 裕量，脉冲另算 |
| TVS 功率 | 按浪涌能量，不只看钳位电压 |

### 32.3 生产测试项目

建议加入：

- 关断漏电测试。
- 导通压降测试。
- 控制脚默认态测试。
- 负载开关功能测试。
- PWM 波形抽检。
- 高低温边界样品测试。
- 感性负载断电尖峰抽检。

## 34. 设计实例：从需求到器件

### 34.1 需求

```text
MCU: 3.3V
负载: 12V 继电器
线圈电流: 80mA
开关频率: 每分钟几次
要求: 成本低，可靠，默认关断
```

### 34.2 BJT 方案

计算：

```text
IC = 80mA
β_forced = 10
IB = 8mA
Rb = (3.3 - 0.8) / 8mA ≈ 312Ω
```

问题：

- GPIO 需要输出约 `8mA`。
- 若 MCU 推荐电流充足，可以接受。
- 若低功耗或 GPIO 能力弱，不理想。

设计：

- `Rb = 330Ω`。
- 基极下拉 `100kΩ`。
- 线圈并续流二极管。
- BJT 选 `IC ≥ 200mA`、`VCEO ≥ 30V`、封装功耗足够。

### 34.3 MOS 方案

选型：

- NMOS，`VDS ≥ 30V`。
- `RDS(on)` 在 `VGS=2.5V` 或 `3.3V` 下有保证。
- 电流能力远大于 `80mA`，小封装即可。

设计：

- 栅极串 `47Ω`。
- 栅极下拉 `100kΩ`。
- 线圈并续流二极管。

比较：

- BJT 成本低、直观。
- MOS 对 GPIO 更轻松、压降低、温升更小。
- 该例中两者都可用，若 MCU 电流紧张优先 MOS。

## 35. 设计实例：24V 2A 电磁阀

### 35.1 需求

```text
电源: 24V
负载: 电磁阀
电流: 2A
控制: MCU 3.3V
开关: 低频
要求: 释放速度较快
```

### 35.2 推荐方案

优先 NMOS 低边，不推荐普通 BJT。

选型：

- `VDS ≥ 60V`，浪涌严苛可选 `80V ~ 100V`。
- `RDS(on) @ VGS=2.5V/3.3V` 足够低，或加栅极驱动。
- 封装能承受功耗。
- 看单脉冲雪崩和 SOA。

保护：

- 用 TVS 或二极管串齐纳，而不是单纯普通续流二极管。
- 钳位电压低于 MOS 安全耐压。
- TVS 能量满足线圈能量。

调试：

- 测断电瞬间 `VDS` 尖峰。
- 测释放时间。
- 测 MOS 温升。
- 测 MCU 地弹和误复位。

## 36. 设计实例：电池产品模块断电

### 36.1 需求

```text
电池: 3.7V 锂电
被控模块: 传感器
工作电流: 20mA
关断漏电: < 1µA
MCU: 1.8V 或 3.3V
```

### 36.2 风险

- MOS 漏电。
- PMOS 体二极管方向。
- 传感器 IO 通过 ESD 二极管反向供电。
- 上拉电阻静态电流。
- MCU 复位时误上电。

### 36.3 推荐方案

- 优先低漏电负载开关 IC。
- 或 PMOS 高边，确认漏电和体二极管方向。
- 所有连接到传感器的 IO 在断电时不能输出高电平。
- 必要时串电阻或使用电平隔离。

检查：

```text
整机睡眠电流 = MCU 睡眠 + 开关漏电 + 上拉下拉电流 + 被控模块反灌电流
```

不要只测开关本身。

## 37. 设计原则总结

1. 先定义负载，再选管子。
2. MOS 不看 `VGS(th)` 判断能不能带负载，要看实际 `VGS` 下的 `RDS(on)`。
3. BJT 开关要按强迫 β 设计，不按典型 `hFE` 设计。
4. 小电流低速场景，BJT 常常简单、便宜、确定。
5. 中大电流和效率敏感场景，MOS 通常更好。
6. 感性负载必须给电流释放路径。
7. 高边开关要特别注意驱动电平、体二极管和 `VGS(max)`。
8. 上电复位默认态必须靠硬件保证。
9. 高频 PWM 要算开关损耗，不只算导通损耗。
10. 功率器件的真实能力由封装、铜皮、温度和 SOA 决定。
11. 替代料要比对动态参数、热参数和引脚，不只比耐压电流。
12. 量产设计用最差值和温度边界，不用典型值当依据。

## 38. 最短实战口诀

```text
小电流、低频、便宜、简单：先想三极管。
大电流、低压降、低发热、PWM：先想 MOS。
BJT 算基极电流，MOS 查实际栅压下的 RDS(on)。
线圈电机必做续流，电源开关必查反灌。
先看波形，再谈玄学；先算热，再谈电流。
```
