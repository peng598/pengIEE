# 选型

### 第一步：明确核心选型参数

	电源与SOC部磁珠选型频率不一样,

选型时，你必须关注以下几个核心参数：

1. **额定电流：** 这是**最最重要**的参数。它必须大于你电源输出的最大直流电流，并留有充足余量（建议20-30%）。电流过载会导致磁珠饱和，轻则感值下降，重则发热烧毁。
    
2. **直流电阻：** 磁珠的直流电阻会带来压降和功率损耗（`P_loss = I² * DCR`）。对于大电流输出，必须选择DCR极低的磁珠，以避免效率下降和过热。
    
3. **阻抗-频率曲线：** 这是磁珠的“指纹”。你需要关注：
    
    - **目标阻抗：** 在你需要滤波的**噪声频率点**上，磁珠的阻抗是多少。例如，如果你的开关电源开关频率是500kHz，你需要看磁珠在500kHz及其谐波（如1MHz, 10MHz）处的阻抗。
        
    - **谐振点：** 磁珠在某个频率下阻抗最大，超过后由于寄生电容影响，呈现容性，阻抗下降。要确保你的噪声频率在磁珠的有效滤波范围内。
        
4. **封装尺寸：** 如0402、0603、0805等。尺寸越大，通常额定电流和通流能力越好，但占用PCB空间也大。

5. **1. 分析噪声频谱（确定你要滤除什么）**

- **开关电源的自身噪声：** 主要是开关频率（如几百kHz）及其谐波。你需要磁珠在**开关频率及其谐波**上有足够高的阻抗。
    
- **负载瞬变引起的高频噪声：** 数字负载（如CPU、FPGA）高速开关时会产生高达数百MHz的噪声。你需要磁珠在**100MHz附近**有高阻抗。
    

**2. 基于额定电流初步筛选**

- 从制造商（如Murata, TDK, Taiyo Yuden）的官网筛选工具中，输入你的**最大直流电流**，列出所有符合条件的磁珠。
    
- **切记：** 磁珠的额定电流是指其因直流电阻发热导致温度上升的限值，**不是其饱和电流**。但很多厂家也会提供饱和电流曲线，最好一并参考。
    

**3. 基于直流电阻二次筛选**

- 计算磁珠带来的**最大压降**：`ΔV = I_max * DCR`。这个压降必须在你的负载芯片所能接受的输入电压范围之内。
    
- 计算**功率损耗**：`P_loss = I_max² * DCR`。这个损耗会导致磁珠自身发热，如果过大，会影响其性能和可靠性。
    

**4. 查看阻抗-频率曲线，锁定最终型号**

- 在初步筛选出的列表中，对比不同型号的阻抗-频率曲线。
    
- **选择一个在目标噪声频率点上阻抗足够高，但在低频（你的电源直流）处阻抗很低的型号。**

### 第三步：重要注意事项与常见误区

1. **磁珠 vs. 电感**
    
    - **磁珠**：用于**衰减高频噪声**（>10MHz效果最佳），是**噪声终结者**。它串联在电源路径中。
        
    - **电感**：用于**LC滤波电路**，平滑电流，是**能量存储者**。它在开关电源的拓扑结构中作为核心元件。
        
    - **简单区分：** 如果电路关心的是**抑制高频噪声**，用磁珠；如果关心的是**维持电流稳定或实现能量转换**，用电感。
        
2. **磁珠的副作用**
    
    - **压降和发热：** 由DCR引起，在大电流应用中非常突出。
        
    - **可能引起振荡：** ==如果在磁珠后面接了一个大的容性负载（如多个芯片的退耦电容），会形成一个LC谐振电路。如果这个谐振点的Q值较高，可能会在负载瞬变时产生振铃（振荡）。==**解决方法**：在磁珠输出端串联一个小的电阻（如0.5-1Ω）来阻尼振荡，或者选择DCR稍大一点的磁珠。
        
3. **布局布线**
    
    - 磁珠下面和附近**不要走线**，尤其是时钟等敏感信号线。
        
    - 磁珠后的电容（去耦电容）应尽量靠近负载芯片的电源引脚放置。

### 实战举例

**场景：** 一个3.3V、最大电流1A的开关电源输出，为一块FPGA板卡供电。开关频率为800kHz，希望抑制高频噪声。

**选型过程：**

1. **额定电流：** 至少选择1.2A~1.5A的磁珠。
    
2. **DCR：** 假设允许最大压降为50mV，则 `DCR < 0.05V / 1A = 50mΩ`。我们会选择DCR远小于50mΩ的型号，比如20mΩ以下。
    
3. **阻抗：** 关注两个点：
    
    - **800kHz**：需要有一定阻抗（比如几欧姆到几十欧姆）。
        
    - **100MHz**：需要有较高的阻抗（比如几十欧姆以上），以抑制高频数字噪声。
        
4. **型号候选：**
    
    - 查阅Murata的BLM系列，例如 **BLM18PG121SN1**（0603封装）。
        
        - 额定电流：2A（满足）。
            
        - DCR：最大35mΩ（压降约35mV，满足）。
            
        - 阻抗：@100MHz时，120Ω（优秀）。
            

**最终建议：** 理论计算后，**务必搭建实际电路进行测试**，用示波器观察磁珠前、后的波形，确认噪声抑制效果以及没有引入振铃等副作用。
