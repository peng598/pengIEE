# 何时需要传输线分析与端接

## 先算电气长度，再决定是否端接

对近似均匀介质，传播速度 $v\approx c/\sqrt{\varepsilon_{\mathrm{eff}}}$，单向延迟 $t_d=\ell\sqrt{\varepsilon_{\mathrm{eff}}}/c$。微带线采用有效介电常数，带状线可在准 TEM 近似下使用周围介质的相对介电常数。厂商材料 Dk、设计 Dk 和有效介电常数的定义不一定相同。

取 $\varepsilon_{\mathrm{eff}}=3.5$、$\ell=100$ mm，得到 $v\approx1.60\times10^8$ m/s，$t_d\approx0.624$ ns。若最快边沿为 1 ns，远端反射在 1.25 ns 左右返回源端，已与边沿和采样时间同量级，应使用传输线模型；若边沿为 50 ns，同样路径可能可用集总 RC 近似，但仍须核验负载和干扰。

## 经验阈值的含义

$t_d\gtrsim t_r/6$ 或 $\ell\gtrsim vt_r/6$ 是一种较保守的建模起点，不是“超过即发生谐振”的定律。源端阻抗、负载电容、拓扑、门限与允许过冲共同决定是否需要额外端接。短线也可能因封装 L 与输入 C 发生局部欠阻尼，长线在足够缓慢边沿和合适源阻抗下也可能满足规格。

分析 SI 最快情况时，不应使用手册中最大的上升时间。选用最高驱动、最轻负载和相关工艺/电压/温度角的最快波形；时序最慢情况另行分析。

## 一次完整的工程判断

1. 获取引脚 IBIS 或手册波形，确认负载和边沿定义。
2. 将封装、走线、连接器、支路与负载输入电容连成网络。
3. 计算或仿真反射、阈值重复穿越、稳定时间和钳位电流。
4. 根据拓扑决定源端阻尼、终端电阻、ODT 或降低驱动强度。
5. 在接收端测量，使用实际噪声裕量和时序窗口验收。

“需要传输线模型”与“必须在 PCB 上加一只匹配电阻”是两个决策，不能合并成一个长度阈值。
