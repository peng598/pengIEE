# ESD失效分析

### **ESD失效分析**

#### **1. 什么是ESD？**

**ESD** 代表 **静电放电**。它是指带有不同静电电位的两个物体，由于直接接触或静电场感应，导致电荷在它们之间快速转移的现象。

在日常生活中，我们接触门把手时感到的电击就是一次ESD事件。对于脆弱的集成电路而言，这种瞬间的放电可以产生数千伏的电压，尽管能量很小，但足以造成毁灭性的损伤。

#### **2. ESD为什么会损坏电子元器件？**

现代集成电路的制造工艺已经进入纳米级别，其内部的绝缘层（如栅氧）极薄，导线和晶体管结也非常微小。ESD事件会在极短的时间内（纳秒级别）产生巨大的瞬时电流和高温，导致器件发生物理性损伤。

**主要失效机理：**

1. **热损伤**
    
    - **机理**： ESD的大电流在很小的电阻区域（如PN结）产生焦耳热，形成局部高温（可达上千摄氏度），导致硅、金属或多晶硅熔化、汽化。
        
    - **表现**： 形成熔融丝、孔洞、合金钉等。ESD管出现低阻的现象
        
2. **介质击穿**
    
    - **机理**： ESD的高电压加在薄绝缘层（最典型的是MOS管的栅氧层）两端，当电场强度超过其介电强度时，绝缘层会被瞬间击穿，形成永久的导电通路。
        
    - **表现**： 栅氧短路。这是最常见且最致命的ESD损伤之一。
        
3. **电磁损伤**
    
    - **机理**： 快速变化的ESD电流会产生强大的电磁场，感应出高电压/电流，干扰或损坏内部的电路，特别是对射频或模拟电路。
        
4. **电荷注入**
    
    - **机理**： ESD脉冲期间，高能载流子（热载流子）可能被注入到栅氧层中，被陷阱捕获，导致器件参数（如阈值电压）发生漂移，虽然不一定立即失效，但会降低可靠性和寿命。
        

#### **3. ESD失效的模式与现象**

ESD失效通常分为 **“硬失效”** 和 **“软失效”**。

- **硬失效**： 指由上述热损伤或介质击穿引起的**灾难性、永久性**损伤。器件功能完全丧失。
    
- **软失效**： 指由电荷注入等引起的**参数性退化**。器件可能暂时还能工作，但性能下降（如漏电流增加、速度变慢、噪声增大），或在后续使用中提前失效。
    

#### **4. ESD失效分析流程**

当怀疑一个器件因ESD失效时，通常会遵循一个标准化的分析流程来定位和确认失效点。

**核心流程：**

1. **非破坏性分析**
    
    - **外观检查**： 在光学显微镜下检查封装和引脚是否有异常。
        
    - **电性测试**： 这是最关键的一步。使用参数分析仪、示波器等测量器件的I-V特性曲线。
        
        - **典型ESD特征**：
            
            - **PN结**： 正常的二极管I-V曲线是单向导通的。ESD损伤后，可能出现**漏电流大增**（曲线在反向偏压时“翘起来”），或者完全**短路**（电阻接近于零）。
                
            - **MOS管栅极**： 栅极与源/漏/衬底之间本应是极高电阻（>GΩ）。如果击穿，则表现为**低阻通路**。
                
    - **X-Ray检查**： 检查内部引线键合、芯片连接等是否有异常。
        
    - **声学扫描显微镜**： 检测封装内部的分层、裂纹等。
        
2. **破坏性分析**
    
    - **开封**： 使用化学或等离子体方法去除塑料封装，暴露出芯片。
        
    - **内部光学检查**： 在高倍光学显微镜下观察芯片表面，寻找明显的烧伤、熔坑、变色等ESD损伤痕迹。
        
3. **精细定位与形貌观察**
    
    - **扫描电子显微镜**： 在SEM的高分辨率下，可以更清晰地观察损伤区域的微观形貌，如熔融的金属线、击穿的栅氧孔洞。
        
    - **聚焦离子束**： 如果表面看不到损伤（特别是栅氧击穿），需要使用FIB在特定区域进行剖切，制作横截面样品，然后用SEM观察截面，从而找到隐藏在介质层下方的损伤点。
        
    - **透射电子显微镜**： 提供原子级别的分辨率，用于分析最精细的损伤结构，如栅氧击穿通道的精确形态。
        
4. **成分分析**
    
    - **能量色散X射线光谱**： 与SEM联用，分析损伤区域的元素成分，确认是否有金属迁移、硅熔化等。
        
5. **结论与报告**
    
    - 综合所有分析数据，确定失效机理（如栅氧击穿、结熔毁），推断ESD应力模型（如HBM, CDM），并提出改进建议。
        

#### **5. 常见的ESD应力模型**

为了模拟真实世界中的ESD事件，业界建立了标准模型：

1. **人体模型**： 模拟人体带电后接触器件时的放电。典型参数： 100pF电容通过1.5kΩ电阻放电。
    
2. **机器模型**： 模拟金属工具或设备带电后的放电。典型参数： 200pF电容直接放电（低阻抗），脉冲更尖锐，破坏力更强。
    
3. **带电器件模型**： 模拟器件自身在生产、运输过程中摩擦带电，然后接触到接地的金属表面时，从其内部向外放电。这是现代自动化生产中最主要的威胁。
    
4. **充电板模型**： 模拟器件在带静电的绝缘表面上移动时，由于电场感应导致的放电。
    

#### **6. 如何预防ESD失效？**

预防是应对ESD问题的上策。

- **芯片设计层面**：
    
    - 在芯片的每个输入/输出引脚和电源引脚之间集成**ESD保护电路**。这些电路能在纳秒内响应ESD脉冲，提供一个低阻抗的泄放路径，将电流“引流”到地，从而保护内部的核心电路。
        
- **制造与装配层面**：
    
    - **使用防静电工作区**： 防静电地板、工作台、腕带。
        
    - **使用防静电包装**： 防静电袋、泡沫。
        
    - **控制环境湿度**。
        
    - **所有设备和人员必须良好接地**。
        
- **运输与使用层面**：
    
    - 在拿取电路板或芯片前，先触摸接地的金属物体释放自身静电。
        
    - 避免在干燥、易产生静电的环境（如铺有地毯的房间）中直接操作电子部件。
        

### **总结**

ESD失效分析是一门结合了电子工程、材料科学和故障物理的交叉学科。它是一个系统的“侦探”过程，从电性异常出发，通过一系列先进的显微分析技术，最终定位到纳米级别的物理损伤，并揭示其背后的失效机理。其根本目的不仅在于找出“死因”，更在于反馈给设计和生产环节，从而打造出更 robust、更可靠的产品。

对于任何从事微电子行业的人员而言，理解ESD及其失效分析都是一项至关重要的技能。
