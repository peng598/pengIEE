# DDR layout 注意

布局要放在中间,用连接线观察,确保后续走等长更容易

布局好后放置电容,过孔 过孔最小0.3 0.2 设好间距 ,确保线能在两个孔间穿过

走线先走数据,先预拉出线,不用考虑等长,连起来就行

拉全部线,在按组内等长蛇形走线,

注意:
	1\差分线等长需要遵循3W间距 详细见差分线要求
	2\数据线间距要求3W间距,能减少70%串扰;4W能减少90%
	3\带状线和微带线因为两边介质不一样,数据延迟也会不一样,所以走线的时候尽可能确保同一层的走线长度一样,如果不一样需要仿真,然后做出长度冗余
	4\地址线对长度要求相对没这么严格,在必要情况下可以不走同一层
