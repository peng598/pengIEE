# 音频 CODEC 通用选型与硬件设计经验手册

## 1. 文档目的

本手册用于音频 CODEC（音频编解码器）的器件选型、外围设计、PCB 布局、软件初始化和量产验证。内容适用于语音终端、录音设备、智能硬件、蓝牙音频、USB 音频和带麦克风的电池设备。

最终设计必须以具体芯片数据手册、参考原理图和评估板测试结果为准。

## 2. 先定义系统需求

选型前先回答以下问题：

| 项目 | 需要明确的内容 |
|---|---|
| 音频方向 | 只采集、只播放，还是 ADC 与 DAC 全双工 |
| 输入 | 模拟麦克风、线路输入、数字 MEMS/PDM 麦克风 |
| 输出 | 线路输出、耳机、扬声器功放、外部功放 |
| 通道 | 单声道、立体声、双麦克风、阵列 |
| 音质 | 语音、普通音乐、高保真音乐 |
| 采样率 | 8/16/32/44.1/48/96/192 kHz |
| 主控接口 | I2S、TDM、PDM、PCM、USB Audio |
| 电源 | 3.3 V、1.8 V、模拟/数字分电源 |
| 功耗 | 常开、待机唤醒、电池供电 |
| 软件平台 | 裸机、RTOS、Linux、Android |

建议先做一页《音频需求规格表》，再从数据手册筛选器件，避免只看采样率或位数。

## 3. CODEC 的基本组成

典型 CODEC 内部包含：

- ADC：模拟信号转换为数字音频
- DAC：数字音频转换为模拟信号
- PGA：模拟可编程增益放大器
- MICBIAS：驻极体麦克风偏置
- 模拟输入选择器和混音器
- 数字音量、静音和数字滤波器
- PLL 或时钟分频器
- I2C/SPI 控制接口
- I2S/TDM/PCM 数字音频接口
- 耳机驱动器或线路输出缓冲器

不同产品集成度差异很大。需要耳机或扬声器驱动时，必须确认输出级的真实负载能力，不能只看 DAC 指标。

## 4. 核心规格参数及性能判断

### 4.1 ADC/DAC 通道数

- 单声道语音：1 ADC，必要时 1 DAC
- 立体声音乐：2 ADC，2 DAC
- 双麦克风降噪：至少 2 个同步 ADC
- 麦克风阵列：关注 TDM 通道数、采样同步和相位一致性

通道数够用后，还要检查是否支持同时采集和播放，以及不同通道是否共享 PGA、MICBIAS 或时钟资源。

### 4.2 采样率

| 应用 | 常用采样率 |
|---|---|
| 窄带语音 | 8 kHz、16 kHz |
| 宽带语音 | 16 kHz、24 kHz |
| 普通消费音频 | 44.1 kHz、48 kHz |
| 高品质音频 | 96 kHz |
| 专业音频 | 192 kHz |

48 kHz 是嵌入式产品最常见的折中方案。若系统需要播放音乐，最好同时支持 44.1 kHz 系列和 48 kHz 系列，避免不必要的采样率转换。

### 4.3 分辨率和有效性能

“24 bit”是接口或转换器标称位数，不等于实际有 24 bit 有效分辨率。应重点看：

- ADC/DAC SNR 或动态范围
- ENOB（有效位数）
- THD+N
- 满量程输入/输出条件

理想情况下，可用下式估算有效位数：

```text
ENOB = (SNR - 1.76) / 6.02
```

例如 SNR 为 98 dB，ENOB 约为 16 bit。对于普通语音，90 dB 左右通常足够；音乐产品建议 ADC/DAC 动态范围达到 100 dB 以上。

### 4.4 SNR、动态范围

SNR 越高，底噪越低。建议参考：

| SNR/动态范围 | 典型评价 |
|---:|---|
| 小于 80 dB | 低成本或语音级 |
| 80~95 dB | 普通语音/消费级 |
| 95~105 dB | 较好的消费音频 |
| 105~115 dB | 高品质音频 |
| 大于 115 dB | 高端或专业级 |

比较时必须确认是否为 A-weighted。A-weighted 数值通常更高，不能和非加权数据直接比较。

### 4.5 THD+N

THD+N 越低越好，包含谐波失真和噪声。常见参考：

| THD+N | 约等于 dB | 评价 |
|---:|---:|---|
| 0.03% | -70 dB | 普通语音 |
| 0.01% | -80 dB | 一般消费级 |
| 0.003% | -90 dB | 较好 |
| 0.001% | -100 dB | 高品质 |

必须同时看测试频率、输出幅度、负载阻抗和带宽。某些芯片在 1 kHz 指标很好，但在高频或大输出幅度时明显变差。

### 4.6 频率响应

普通音频可选择 `20 Hz~20 kHz，±0.5 dB` 左右的器件。语音产品更应关注语音带宽内的平坦度和数字滤波器延迟。

### 4.7 通道串扰

立体声系统建议串扰不高于 `-80 dB`，高品质产品可要求 `-90 dB` 或更低。串扰不仅由芯片决定，也受 PCB 模拟走线、电源回流和输出连接器影响。

## 5. 模拟输入选型与计算

### 5.1 输入满量程

确认数据手册中的输入量是：

- 峰值、峰峰值还是 RMS
- 单端还是差分
- 以 AVDD 为参考还是固定电压
- 是否包含 PGA 增益

正弦波关系：

```text
VPP = 2 × VPEAK
VRMS = VPEAK / sqrt(2)
VPP = 2 × sqrt(2) × VRMS
```

输入信号峰值超过 ADC 满量程会削顶。设计时建议预留 3~6 dB 峰值裕量。

### 5.2 麦克风 PGA

麦克风输出很小，通常需要 PGA。重点参数：

- 增益范围，例如 0~30 dB、0~40 dB
- 增益步进，例如 0.5 dB、1 dB、3 dB
- 增益误差
- 输入等效噪声
- 增益切换是否有爆音

输入级噪声会直接影响录音底噪。不要只比较 CODEC 的 ADC SNR，还要查看麦克风输入等效噪声。

### 5.3 麦克风偏置

使用驻极体麦克风时确认：

- 是否内置 MICBIAS
- MICBIAS 电压范围
- 最大偏置电流
- 每个通道是否独立偏置
- 偏置输出噪声和去耦要求

偏置电阻、电容必须按芯片参考设计选择。偏置电流不足会造成灵敏度下降或失真。

### 5.4 输入耦合和高通截止频率

交流耦合电容与输入电阻形成高通：

```text
fC = 1 / (2 × pi × R × C)
```

例如 `R=10 kΩ，C=1 µF`，截止频率约为 15.9 Hz。语音输入通常可设置在 10~100 Hz；音乐输入应避免截止频率过高导致低频衰减。

## 6. 模拟输出选型与计算

### 6.1 线路输出

线路输出通常连接到高阻输入，负载一般要求大于 10 kΩ。确认：

- 输出摆幅
- 输出共模电压
- 输出驱动电流
- 是否需要隔直电容
- 输出端推荐 RC/LC 网络

### 6.2 耳机输出

若直接推动耳机，需检查 16 Ω、32 Ω、64 Ω 等负载下的：

- 最大 RMS 输出电压
- 最大输出功率
- THD+N
- 输出噪声
- 直流失调
- 插拔爆音

耳机功率估算：

```text
P = VRMS^2 / RLOAD
IOUT_RMS = VRMS / RLOAD
```

例如 32 Ω 耳机需要 20 mW 时：

```text
VRMS = sqrt(0.02 × 32) ≈ 0.8 V
IOUT_RMS ≈ 25 mA
```

如果芯片输出电流达不到，必须增加耳机放大器。

### 6.3 输出耦合电容

输出耦合电容与负载形成高通：

```text
fC = 1 / (2 × pi × RLOAD × COUT)
```

32 Ω 负载、`COUT=100 µF` 时，截止频率约 49.7 Hz。耳机应用中电容过小会削弱低频；需要根据负载选择低 ESR 电容。

## 7. 数字音频接口

### 7.1 I2S 必须确认的参数

- 主机/从机模式
- BCLK、LRCLK、MCLK 的提供者
- 采样边沿
- 左右声道极性
- 数据延迟一位还是零位
- 16/20/24/32 bit 数据格式
- 采样率和 BCLK 比例

I2S 常见关系：

```text
BCLK = 采样率 × 每帧总 bit 数
```

例如立体声、32 bit 时隙、48 kHz：

```text
BCLK = 48000 × 64 = 3.072 MHz
```

### 7.2 TDM/PDM

多麦克风设计应确认：

- TDM 时隙数量和时隙宽度
- 每个通道的时隙位置
- PDM 时钟频率
- PDM 麦克风左右声道选择
- 通道间同步误差

## 8. 时钟和 PLL

常用主时钟：

| 采样率系列 | 常见 MCLK |
|---|---:|
| 44.1 kHz | 11.2896 MHz、22.5792 MHz |
| 48 kHz | 12.288 MHz、24.576 MHz |

若同时支持两种采样率系列，确认芯片是否集成 PLL，还是需要外部切换时钟。MCLK、BCLK 走线应远离麦克风输入和模拟输出。

## 9. 电源和功耗设计

常见电源引脚：

- AVDD：模拟电路
- DVDD：数字核心
- IOVDD：I2C、I2S 等接口电平
- PLLVDD：锁相环
- HPVDD：耳机或输出级

选型时检查每路电源的电压范围和上电时序。建议：

```text
DC-DC -> 数字电源
      -> 磁珠/低噪声 LDO -> AVDD
```

模拟电源滤波不能替代合理布局。每个电源脚应就近放置数据手册推荐的 100 nF 和 1~10 µF 去耦电容。

必须查看以下功耗状态：

- 录音功耗
- 播放功耗
- ADC+DAC 全双工功耗
- 待机功耗
- 关断后的漏电流
- 唤醒时间

电池产品尤其要确认 MICBIAS、PLL、耳机放大器能否单独关闭。

## 10. PCB 布局经验

1. CODEC 放在麦克风和音频连接器附近。
2. 麦克风输入走线短、对称，必要时采用差分走线。
3. DC-DC 电感、SW 节点和高 di/dt 回路远离 CODEC。
4. AVDD 单独滤波，滤波器靠近 CODEC 电源脚。
5. MCLK、BCLK、LRCLK 避免从模拟输入下方穿过。
6. 模拟输出与数字高速线保持距离。
7. 参考地平面连续，按数据手册规定处理 AGND/DGND。
8. 去耦电容到电源脚和地的回路尽可能短。
9. 不要让扬声器大电流回流经过麦克风地。
10. 预留测试点：AVDD、DVDD、MCLK、BCLK、LRCLK、ADC 输入、DAC 输出。

## 11. 参数“好不好”的实用判断

不要孤立比较一个数字，应在相同条件下比较：

- 采样率相同
- 输入/输出幅度相同
- 负载相同
- 带宽相同
- 加权方式相同
- 是否包含外部放大器

对一般嵌入式音频，以下指标可作为起点：

| 指标 | 语音产品 | 普通音乐产品 | 高品质音乐 |
|---|---:|---:|---:|
| ADC/DAC SNR | ≥85 dB | ≥95 dB | ≥105 dB |
| THD+N | ≤0.01% | ≤0.003% | ≤0.001% |
| 频响 | 100 Hz~8 kHz | 20 Hz~20 kHz | 20 Hz~20 kHz，±0.2 dB |
| 通道串扰 | ≥-70 dB | ≥-80 dB | ≥-90 dB |
| 采样率 | 16/48 kHz | 44.1/48 kHz | 96/192 kHz |

## 14. 上电初始化建议

推荐软件顺序：

1. 保持 CODEC 复位或静音。
2. 等待模拟和数字电源稳定。
3. 配置时钟、PLL 和采样率。
4. 配置 I2S/TDM 数据格式。
5. 配置输入选择、PGA、MICBIAS。
6. 配置 DAC 音量和输出路径。
7. 等待 PLL 锁定和模拟电路稳定。
8. 逐步取消静音，避免开机爆音。

掉电时反向执行：先静音，再关闭输出、PLL、MICBIAS 和 ADC/DAC。

## 15. 必做验证项目

### 15.1 录音链路

- 输入静音时测噪声底
- 输入 1 kHz 正弦波测 THD+N
- 扫频测频率响应
- 检查最大输入不削顶
- 改变 PGA 增益检查爆音和噪声

### 15.2 播放链路

- 空载和额定负载测噪声
- 测最大输出摆幅和功率
- 测 THD+N、频响、串扰
- 检查开关机、插拔、静音爆音

### 15.3 系统级干扰

- DC-DC 各负载下测音频底噪
- MCU、LCD、无线发射时测频谱
- USB 插拔和充电时测噪声
- 不同电池电压下测满量程和失真
- 待机/唤醒反复测试是否有杂音

## 16. 典型选型结论

- 只做语音采集：优先低噪声 ADC、足够 PGA、MICBIAS 和低功耗。
- 双麦克风降噪：优先双通道同步 ADC、通道相位一致性和 TDM 支持。
- 音乐播放：优先 DAC 动态范围、THD+N、时钟和耳机输出能力。
- 电池设备：优先待机功耗、快速唤醒、独立关闭模块和电源时序。
- 高干扰系统：优先差分输入、独立模拟电源、良好 PLL 和 PCB 参考设计。
- 量产产品：除了性能，还要核对封装、温度等级、供货周期、软件驱动和替代料。

## 17. 最终建议

音频 CODEC 选型的优先级通常是：

```text
功能匹配
> 输入输出电气匹配
> 数字接口和时钟匹配
> SNR/THD+N 等性能
> 电源与功耗
> PCB 可实现性
> 软件支持和供应链
```

如果芯片的输入输出电平、I2S 时序或电源时序不匹配，即使 SNR 很高，也不适合直接使用。建议先用评估板确认音频指标和软件初始化，再冻结原理图和 PCB。
