# 噪声门、信噪比与音频处理：原理、顺序和验证

> 本笔记整理自一段关于“少加处理才能还原声音”的问答，并对其中的绝对化结论进行工程化修正。

## 1. 先给结论

1. 音频处理没有“所有指标同时变好”的方案，实际都是用一个指标的代价换另一个指标的改善。
2. 噪声门主要改善的是**无信号时的听感和输出静音段噪声**，不能提高说话期间的真实信噪比。
3. 压缩器能提高平均响度、降低峰均比，但化妆增益会把底噪一起抬高，并可能造成呼吸声、泵动和瞬态损失。
4. 高通滤波器可以去掉低频噪声、机械振动和近讲效应；代价是频响改变以及滤波器引入的相位/群时延。
5. EQ、压缩器、噪声门的顺序没有唯一答案。顺序取决于检测器要“看到”什么，以及最终要解决的是噪声、动态、频响还是响度。
6. “还原”不是绝对概念。麦克风、前置放大器、监听设备、房间和人耳都会改变声音；工程目标通常是可控、可重复、符合用途，而不是完全不处理。

## 2. 关键指标和公式

### 2.1 信噪比 SNR

以 RMS 电压定义时：

```text
SNR(dB) = 20 log10(V_signal,rms / V_noise,rms)
```

以功率定义时：

```text
SNR(dB) = 10 log10(P_signal / P_noise)
```

例如语音段 RMS 为 -20 dBFS，噪声 RMS 为 -60 dBFS：

```text
SNR = -20 - (-60) = 40 dB
```

如果噪声门只在停顿时关闭，语音段的 -20 dBFS 和 -60 dBFS 都没有改变，因此语音段 SNR 仍约为 40 dB。播放整段节目时，静音段被压低，节目级平均噪声可能下降，测得的“整段 SNR”会变大，但这不是麦克风或前端的本底噪声变小。

### 2.2 动态范围

```text
Dynamic Range(dB) = L_max - L_noise_floor
```

压缩器降低峰值与弱音之间的差异；化妆增益再整体抬高电平。若噪声也被抬高，动态范围不一定增加，甚至可能降低。

### 2.3 THD、THD+N 和 IMD

总谐波失真：

```text
THD(%) = 100 * sqrt(V2^2 + V3^2 + ... + Vn^2) / V1
```

总谐波失真加噪声：

```text
THD+N(%) = 100 * sqrt(V_harmonics^2 + V_noise^2) / V_fundamental
```

互调失真（IMD）是两个或多个频率经过非线性系统后产生的和频、差频分量。压缩、限制、削波、饱和和某些降噪算法都可能产生调制侧带或互调产物。普通线性 EQ 本身不会产生谐波失真，但会改变噪声带宽、峰值和相位。

### 2.4 响度、峰值和峰均比

```text
Crest Factor(dB) = Peak(dBFS) - RMS(dBFS)
```

压缩和限制通常降低峰均比，使 RMS/LUFS 可以提高；这不等同于保真度提高。数字系统还应关注 True Peak，避免采样间峰值在编码或 DAC 后过载。

## 3. 各类处理对参数的真实影响

| 处理 | 可能改善 | 可能恶化 | 工程判断 |
|---|---|---|---|
| 高通 HPF | 去除低频噪声、风噪、碰撞噪声；改善语音可懂度 | 改变低频频响；非线性相位滤波器会产生群时延 | 先用低阶、低截止频率的削减型处理，避免过度 |
| EQ | 修正频响、降低掩蔽、提高可懂度 | 提升某频段会同时提升该频段噪声；占用余量；相位改变 | 优先削减问题频段，再少量提升目标频段 |
| 压缩器 | 控制峰值、提高平均响度、使语音更稳定 | 底噪被化妆增益抬高；瞬态变钝；泵动、喘息、失真 | 目标是可控动态，不是把所有声音压平 |
| 噪声门/下行扩展器 | 停顿时降低噪声和串音；改善节目级噪声 | 误切弱音、气息和混响尾音；阈值不当会产生咔嗒声 | 通常用温和范围和较长释放时间 |
| 限制器 | 防止削波；允许更高节目响度 | 峰值被截断；THD+N、IMD、泵动风险上升 | 放在最终输出，保留约 -1 dBTP 余量 |
| 降噪算法 | 降低稳定背景噪声 | 音乐噪声、金属感、语音纹理损失 | 只处理稳定噪声，保留干声备份并做 AB 比较 |
| 混响/延迟/加宽 | 增强空间感和包围感 | 增加非原始能量；相位相容性和清晰度可能下降 | 这是效果处理，不应称为“还原” |

### 3.1 噪声门为什么不能直接提高说话时 SNR

噪声门的基本逻辑是：当检测电平低于阈值时，把增益降低；高于阈值时恢复增益。

```text
若 L_detector < T：G_out = -Range dB
若 L_detector >= T：G_out = 0 dB（或按软膝曲线渐变）
```

假设语音为 -30 dBFS、噪声为 -60 dBFS，门限为 -45 dBFS：

- 说话时：门打开，语音和噪声都通过，SNR 仍约 30 dB。
- 停顿时：门关闭，噪声下降 20 dB，听感更安静。
- 如果门限设到 -35 dBFS，弱音也可能被当成噪声切掉。

因此应区分“语音段 SNR”和“整段节目/静音段噪声”。供应商或软件只给出一个变大的 SNR 数值时，必须确认测量时门是否关闭、信号电平是多少、带宽和加权方式是什么。

## 4. 信号链顺序：没有唯一标准

### 4.1 适合语音录音的起始链路

```text
麦克风 → 话放/ADC → HPF → 问题频段削减 EQ → 温和扩展器 → 压缩器
       → 去齿音（按需要）→ 少量音色 EQ → 峰值限制器 → 输出
```

说明：

- HPF 和削减型 EQ 放在压缩前，避免低频噪声或刺耳频段过度触发压缩器。
- 扩展器放在压缩前，常用于避免压缩器把停顿底噪抬起来。
- 去齿音可以放在压缩前，防止齿音触发压缩；也可以放在压缩后，处理压缩后重新突出的齿音。
- 最终限制器一般放在输出端，负责最后的峰值保护。
- 若只是清理录音停顿，也可以在压缩后再放一个轻度噪声门，但要防止切断尾音。

### 4.2 现场扩声或会议语音

```text
HPF → 啸叫/共振削减 EQ → 压缩器（可选）→ 扩展器/噪声门（可选）→ 限制器
```

现场系统更重视反馈稳定、可懂度和余量。门限、释放时间和房间噪声必须在真实场地测量后设定，不能照搬录音棚参数。

### 4.3 母线或母带处理

```text
校正 EQ → 总线压缩/多段压缩（按需要）→ 饱和/削波（按需要）→ True Peak 限制器
```

“非线性永远最后”不是定律。限制器通常最后，是因为它负责最终峰值；但创意饱和、剪辑和压缩完全可能被有意放在前面。应根据听感、测量结果和目标响度决定。

## 5. 常见错误结论的修正

### 错误一：噪声门提高了系统真实 SNR

更准确的说法：噪声门降低了无信号时间内的输出噪声，改善节目级噪声表现；它不会降低信号存在时的前端等效输入噪声（EIN）。

### 错误二：压缩器的化妆增益“真实提高 SNR”

化妆增益同时放大信号、底噪和前级残留失真。它提高的是输出电平和响度，不保证 SNR 提高。若要提高 SNR，应在噪声源之后尽早建立足够电平，并降低前端噪声，而不是靠后级放大。

### 错误三：EQ 后接压缩一定等于白调

EQ 后压缩会让被提升频段更容易触发压缩，但这有时正是目的，例如控制低频爆破或齿音。若希望 EQ 只改变音色而不明显改变总线增益，可以使用侧链滤波、并行压缩或把音色 EQ 放到压缩后。

### 错误四：噪声门必须放在最后

多数人声链路把扩展器放在压缩器前，是为了避免压缩器抬高底噪；最后再加一个轻度门只是一种特定用途。位置应由“检测器需要看到的信号”和尾音是否重要决定。

## 6. 可落地的参数起点（语音）

以下是起始值，不是通用标准；必须根据录音电平、话筒、房间和节目类型微调。

### 6.1 高通

- 男声：70–90 Hz 起步；女声：80–120 Hz 起步。
- 斜率：6 或 12 dB/oct；先听低频主体是否变薄。
- 如果是风噪或机械噪声，宁可先查机械和结构问题，不要用很高截止频率掩盖。

### 6.2 噪声门/扩展器

- 先测停顿噪声 RMS，再把门限设在噪声之上约 6–10 dB。
- Attack：1–5 ms；Hold：50–150 ms；Release：100–300 ms。
- Range：先用 -10 到 -20 dB，不建议一上来完全静音。
- 设滞回（开门和关门门限不同）可减少临界点抖动。

### 6.3 压缩器

- Ratio：2:1–4:1。
- Attack：10–30 ms，保留辅音和起始瞬态。
- Release：80–200 ms，按句子节奏调整，避免泵动。
- 平均增益衰减 GR：约 3–6 dB；持续超过 8–10 dB 要重点检查自然度和噪声。
- 化妆增益只补偿需要的响度，不要把噪声推到可闻。

### 6.4 输出限制器

- True Peak ceiling：常从 -1 dBTP 起步。
- 观察短时响度、峰值、GR 和听感，不以“越响越好”为目标。

## 7. 实验验证流程

### 7.1 验证噪声门是否真的改善 SNR

1. 录制 30–60 秒纯停顿，记录输入增益、采样率和带宽。
2. 录制同一段固定电平语音或 1 kHz 测试音。
3. 分别关闭和开启噪声门，测量语音段 RMS、停顿段 RMS、LUFS-I、峰值和 True Peak。
4. 用同一频带计算：`SNR = 语音段 RMS - 停顿段 RMS`。
5. 如果只在门关闭时 SNR 变大，而语音段 SNR 不变，说明改善来自静音处理，不是前端噪声性能提升。

### 7.2 验证压缩器代价

- 输入 1 kHz 正弦、语音短句和瞬态脉冲，分别测量压缩前后 RMS、峰值、峰均比和 GR。
- 做输入电平扫描，观察 THD+N 是否随 GR 增大而上升。
- 把化妆增益设为 0 dB 和目标响度值各测一次，区分压缩本身与后级放大带来的噪声。

### 7.3 验证 EQ、相位和瞬态

- 用对数扫频测频响；用脉冲响应或双通道测量估计群时延。
- 比较最小相位 EQ 与线性相位 EQ 的频响、前振铃/后振铃和瞬态听感。
- 对立体声信号做单声道求和，检查 EQ 或加宽处理是否产生明显相消。

### 7.4 听感验证

- 所有 AB 比较必须匹配响度，否则更响的版本通常会被误认为更好。
- 保留未经处理的干声，采用短片段循环比较：辅音、弱音、尾音、齿音、背景噪声和瞬态。
- 工程验收同时看仪表和听感，不以单一 SNR、LUFS 或 THD 数字下结论。

## 9. 一句话工程准则

先解决声源、话筒位置、房间和增益结构，再用最少的处理达到用途要求；每增加一个处理器，都记录它改善了哪个指标、牺牲了哪个指标，并用同响度 AB 和测量数据验证。

## 10. 常见效果器总览

效果器可以按改变的物理量分成四类：

| 类别 | 代表处理 | 主要改变 |
|---|---|---|
| 频域处理 | HPF、LPF、参数 EQ、动态 EQ、去齿音 | 频谱包络、带宽、相位 |
| 电平/动态处理 | 压缩、限制、扩展、噪声门、AGC | 振幅包络、峰值、动态范围 |
| 时间处理 | 延迟、回声、混响、合唱、镶边、移相 | 时间结构、反射、相位 |
| 非线性和重建 | 饱和、失真、削波、激励器、降噪、变调 | 谐波、噪声、音高和波形结构 |

效果器的“改善”必须带有场景限定。例如混响可以改善空间感，却通常降低语言可懂度；降噪可以降低背景噪声，却可能增加音乐噪声和语音纹理损失。

## 11. 混响 Reverb

### 11.1 原理

自然声场中，直达声之后会到达大量反射声。早期反射决定房间尺寸和声源位置，后期密集反射形成混响尾音。混响器用算法或实际空间的脉冲响应重建这些反射。

常见实现：

- **算法混响**：延迟线、全通滤波器和反馈网络组合，参数可调，CPU 占用低。
- **卷积混响**：输出为输入与房间脉冲响应的卷积，真实度高，但脉冲响应本身决定声音。
- **Plate/Room/Hall/Spring**：分别模拟金属板、房间、大厅和弹簧结构，频响与密度不同。

### 11.2 关键公式

线性时不变系统的卷积：

```text
y(t) = x(t) * h(t) = ∫ x(τ) h(t-τ) dτ
```

混响时间 RT60 的 Sabine 近似：

```text
RT60 ≈ 0.161 V / A
A = Σ(α_i S_i)
```

其中 `V` 是房间体积（m³），`S_i` 是表面积，`α_i` 是吸声系数，`A` 是等效吸声面积（m²）。房间越大、吸声越少，RT60 越长。

常用混响密度用指数衰减表示：

```text
E(t) = E0 · 10^(-6t / RT60)
```

### 11.3 对指标的影响

- **空间感**：增加；但这是增加反射声，不是恢复原始干声。
- **语言可懂度**：通常下降，尤其是 1–4 kHz 尾音过长时，辅音被后续音节掩蔽。
- **SNR**：如果把混响当作有用信号，测得的总能量可能提高；但背景噪声也会被拖成长尾，实际清晰度可能下降。
- **动态范围**：尾音能量填充低电平区，主观动态变小。
- **相位/单声道相容性**：多通道混响可能在单声道相加时相消。
- **频响**：预延迟、阻尼和反射滤波会改变频谱。

### 11.4 参数起点

- 人声：Pre-delay 20–60 ms，Decay 0.8–1.8 s，Wet 5%–15%。
- 会议语音：Decay 通常小于 0.8 s，Wet 尽量低，避免影响可懂度。
- 低频阻尼要高于中高频，避免低频混响堆积。

### 11.5 测试方法

用脉冲或短脉冲激励，测量 RT60、早期反射到达时间和频带衰减；将处理前后语音做辅音识别或短语可懂度 AB 测试，并检查单声道相加电平。

## 12. 延迟和回声 Delay/Echo

### 12.1 原理

把输入复制一份并延迟，再按反馈系数重复：

```text
y[n] = x[n] + g · y[n-D]
```

`D` 是采样点延迟，`g` 是反馈系数。若延迟副本与原声叠加，会形成梳状滤波。

### 12.2 梳状滤波公式

设延迟时间为 `τ`：

```text
峰值频率：f_peak = k / τ
谷值频率：f_notch = (2k+1) / (2τ)
```

当 `τ=1 ms` 时，梳状间隔约为 1 kHz；这就是扬声器反射或双麦克风距离差造成音色空洞的原因。

### 12.3 影响和用途

- 20 ms 以下：主要听到音色和相位变化，容易产生梳状滤波。
- 20–40 ms：开始出现 Haas/先到效应，听感变宽，但单声道相容性要检查。
- 50 ms 以上：可感知为独立回声，语言清晰度通常下降。
- Feedback 越大，重复次数和尾音越长；接近 1 时容易累积、啸叫或溢出。

## 13. 合唱 Chorus、镶边 Flanger、移相 Phaser

### 13.1 合唱

合唱把原声与一个缓慢调制的短延迟副本混合：

```text
y(t) = x(t) + a · x(t - τ(t))
τ(t) = τ0 + Δτ sin(2π fLFO t)
```

延迟调制造成轻微音高摆动和多声部错觉。它能增加厚度和宽度，但会损害瞬态定位、单声道相容性和音高稳定性。

### 13.2 镶边

镶边通常使用极短调制延迟和较高反馈，梳状陷波不断移动，产生喷气或扫频效果。它不是保真处理，会明显改变频响和相位。

### 13.3 移相

移相器用全通滤波器产生频率相关相位旋转，再与干声混合形成移动陷波。全通滤波器理想情况下幅频平坦，但混合后会产生相消。低频相位变化尤其可能影响低音单声道兼容性。

## 14. 参数 EQ、动态 EQ 和交叉滤波器

### 14.1 双二阶滤波器通式

数字 EQ 常用 biquad：

```text
H(z) = (b0 + b1 z^-1 + b2 z^-2) /
       (a0 + a1 z^-1 + a2 z^-2)
```

归一化时通常令 `a0=1`。中心频率、Q 值和增益决定系数。Q 越高，带宽越窄，频率选择性越强，瞬态振铃和群时延峰值也可能越明显。

### 14.2 影响

- **削减型 EQ**：可降低共振和掩蔽，也可能降低总能量和音色厚度。
- **提升型 EQ**：提高目标频段，但同时提高该频段噪声和削波风险。
- **动态 EQ**：只在检测到问题时改变增益，减少静态音色损伤；检测器和攻击/释放决定是否产生泵动。
- **线性相位 EQ**：稳态相位更一致，但可能产生前振铃和更高延迟。
- **最小相位 EQ**：延迟小、实时性好，但会改变相位。

## 15. 压缩、限制、扩展和噪声门

### 15.1 压缩器

理想静态压缩曲线（单位为 dB）：

```text
L_out = L_in                         (L_in ≤ T)
L_out = T + (L_in - T) / R           (L_in > T)
```

增益衰减：

```text
GR = (1 - 1/R) · (L_in - T)
```

压缩器还包含包络检测器、Attack/Release 平滑器和增益控制单元。快 Attack 会压低瞬态，慢 Attack 能保留起音；Release 太快会产生失真或泵动，太慢会导致后续音节持续被压低。

### 15.2 限制器

限制器是高比率压缩，目标是防止峰值超过上限。硬限幅可写作：

```text
y = clip(x, -A, +A)
```

硬拐点会产生谐波；Look-ahead 可提前降低增益，减少瞬态穿透，但会增加延迟。限制器后的 True Peak、THD+N 和响度必须一起观察。

### 15.3 上行压缩和扩展

上行压缩提高低电平信号，可能把细节和噪声同时抬高；下行扩展则降低低电平信号，属于噪声门的连续版本。两者都可能改变原始微动态。

## 16. 去齿音 De-esser

去齿音通常用 4–10 kHz 的带通检测器控制宽带或高频增益：

```text
若 L_sibilance > T：G_high ← G_high - GR
```

它可以降低“s、sh、t”过强和刺耳感，但过度处理会让声音口齿含混、空气感下降。应使用短 Attack、适中的 Release，优先动态衰减而非永久削掉高频。

## 17. 饱和、失真和软削波

### 17.1 原理

非线性函数把输入波形映射为不同形状。例如软饱和可近似为：

```text
y = tanh(kx) / tanh(k)
```

输入增大时斜率逐渐变小，波形峰值被压缩并产生谐波。硬削波则在阈值处突然截断，产生更多高次谐波。

### 17.2 影响

- 增加谐波密度、主观厚度和存在感。
- 降低峰均比，使平均响度上升。
- 提高 THD、IMD 和高频能量；过度时产生刺耳、毛刺和听感疲劳。
- 偶次谐波通常更“暖”，奇次谐波更“硬”，但实际听感还取决于频率、级数和电平。

测试时用 1 kHz、-18 dBFS 输入逐步增加电平，记录 THD+N 与输入电平曲线；不要只听“更响”的版本。

## 18. 激励器 Exciter

激励器通常先对高频带通，再进行非线性处理或谐波合成，最后与原信号混合。它能够让人声和镲片更明亮，但也会提高高频噪声、齿音、THD 和听觉疲劳。应在高频频带单独处理，避免低频被非线性放大。

## 19. 立体声扩展、M/S 和自动声像

Mid/Side 变换常写为：

```text
M = (L + R) / √2
S = (L - R) / √2
L = (M + S) / √2
R = (M - S) / √2
```

把 `S` 增益乘以宽度系数 `w`：

```text
S' = wS
```

当 `w>1` 时声场变宽；当 `w<1` 时变窄。过度增加 S 会导致单声道相加时相消，中心人声变薄。应始终比较 L+R 单声道、相关度和左右声道峰值。

## 20. 自动增益 AGC 和语音电平控制

AGC 通过慢速包络检测调节增益，使平均电平接近目标。典型目标是让远近说话者音量更接近，但它会把停顿噪声和键盘声抬高。AGC 与噪声门、压缩器叠加时容易出现“增益追噪声”和泵动。

建议顺序：先处理稳定噪声和明显低频问题，再做温和 AGC，最后用限制器防止峰值。AGC 的时间常数要明显慢于语音音节，避免每个音节都产生音量跳动。

## 21. 降噪、回声消除和语音增强

### 21.1 频谱减法

对每帧做 STFT，估计噪声谱 `N(k)` 并从输入谱 `Y(k)` 中扣除：

```text
|X_hat(k)| = max(|Y(k)| - α|N(k)|, β|Y(k)|)
```

`α` 是过减系数，`β` 是谱底。过大的 α 会提高噪声抑制，却产生音乐噪声和语音断裂。

### 21.2 维纳滤波

```text
H(k) = Φ_x(k) / (Φ_x(k) + Φ_n(k))
X_hat(k) = H(k)Y(k)
```

其中 `Φ_x` 和 `Φ_n` 分别是信号和噪声功率谱估计。噪声估计错误会造成语音失真或残留噪声。

### 21.3 回声消除 AEC

自适应滤波器估计扬声器到麦克风的回声路径 `h(n)`：

```text
y(n) = x(n) * h(n)
e(n) = d(n) - y(n)
```

`d(n)` 是麦克风接收信号，`e(n)` 是残差。双讲、非线性扬声器失真和路径变化会降低收敛效果。AEC 不等于噪声门，必须配合回声返回损耗增强量（ERLE）和双讲测试。

## 22. 音高修正和时间拉伸

- **PSOLA/时域重叠相加**：分割基音周期后改变周期位置，适合语音，可能产生颗粒感。
- **相位声码器**：STFT 后修改频率轨迹再重建，适合较长音乐片段，但容易产生瞬态模糊和相位展宽。
- **变调**：改变基频而尽量保持时长；大范围变调会产生共振峰错位和金属声。
- **时间拉伸**：保持音高而改变时长；比例偏离 1 越远，伪影越明显。

算法处理通常引入帧长相关延迟。实时硬件必须在音质、延迟和 CPU 负载之间取舍。

## 23. 用指标判断效果器是否值得保留

| 目标 | 应观察的指标 | 不能只看 |
|---|---|---|
| 降噪 | 语音段 SNR、停顿段 RMS、可懂度、残留噪声类型 | 单一 SNR 数值 |
| 提高响度 | LUFS-I、短时 LUFS、True Peak、GR、THD+N | 只看峰值 |
| 提高清晰度 | 频响、辅音可懂度、房间混响、同响度 AB | 只看高频是否更亮 |

| 保持保真 | 频响、相位、THD+N、IMD、噪声、延迟 | 只看“听起来更大声” |

## 25. 最终决策流程

```text
先确认噪声来源和增益结构
        ↓
能否通过话筒位置、屏蔽、接地、房间吸声解决？
        ↓ 否
用 HPF/EQ 去除明确问题频段
        ↓
用扩展器/降噪处理停顿或稳定噪声
        ↓
用压缩器控制动态，限制器保护峰值
        ↓
最后按节目目的加入混响、延迟、宽度或饱和
        ↓
同响度 AB + 频谱/响度/失真/单声道测试
```

如果某个效果器不能明确说明“改善了什么、牺牲了什么、如何测出来”，就不应仅因为声音更响、更亮或更宽而保留。

## 26. 效果器的通用内部结构

大多数实时效果器都可以拆成以下模块：

```text
输入电平表 → 预处理/滤波 → 检测器（主链或侧链）
                         ↓
                 控制律/参数平滑
                         ↓
干声 ─────────────────────┐
                           ├→ 湿声处理 → 干湿混合 → 输出限幅/电平表
湿声处理链 ────────────────┘
```

### 26.1 线性电平和 dB 的转换

数字音频中，线性振幅 `a` 转 dBFS：

```text
L_dBFS = 20 log10(a)
a = 10^(L_dBFS / 20)
```

功率或均方值转 dB 时使用 10 倍对数。把 dB 参数直接当振幅相加是错误的，必须先转换到线性域。

### 26.2 包络检测器

整流后的一阶 Attack/Release 平滑器：

```text
a_attack  = exp(-1 / (Fs · τ_attack))
a_release = exp(-1 / (Fs · τ_release))

若 x[n] > e[n-1]：e[n] = a_attack  · e[n-1] + (1-a_attack)  · x[n]
否则            ：e[n] = a_release · e[n-1] + (1-a_release) · x[n]
```

`Fs` 是采样率，`τ` 是时间常数。Attack/Release 越短，响应越快，但包络纹波和调制失真越明显。很多“压缩器听起来失真”的根源不是 VCA，而是检测器时间常数不合适。

RMS 检测器通常为：

```text
RMS[n] = sqrt((1/N) Σ x[n-i]^2)
```

Peak 检测器反应快，适合限制峰值；RMS 检测器更接近主观响度，适合音乐压缩。两者得到的压缩量不能直接比较。

### 26.3 侧链和检测器滤波

侧链是“用于检测的信号”，不一定等于最终输出信号。例如压缩器可以在侧链加入高通，让低频不再过度触发整体压缩；去齿音则在侧链只检测 4–10 kHz，而主链只衰减高频。

侧链高通的截止频率改变的是控制量，不直接改变主信号频响。调试时要分别观察主链频谱和侧链电平，否则容易误判 EQ 是否生效。

## 27. 算法混响的具体实现

### 27.1 Schroeder 混响

最基本的 Schroeder 混响由并联梳状滤波器和串联全通滤波器组成。

反馈梳状滤波器：

```text
y[n] = x[n] + g · y[n-M]
```

前馈/反馈全通滤波器的一种形式：

```text
y[n] = -g x[n] + x[n-M] + g y[n-M]
```

多条延迟线长度不能是简单整数倍，否则会产生明显的金属音和周期性梳状峰谷。实际实现会使用互质延迟长度、扩散器和低通阻尼。

### 27.2 由 RT60 计算反馈系数

延迟线长度为 `M` 个采样点，采样率为 `Fs`，每次循环的反馈系数为 `g`。经过 `RT60` 秒后能量需衰减 60 dB，即振幅衰减到 1/1000：

```text
g^(RT60 · Fs / M) = 10^-3
g = 10^(-3M / (RT60 · Fs))
```

例如 `Fs=48 kHz`、`M=2400`（50 ms）、`RT60=1.2 s`：

```text
g ≈ 10^(-3×2400/(1.2×48000)) ≈ 0.708
```

实际混响还会受到多个反馈回路、阻尼滤波器和扩散器影响，所以最终 RT60 必须用脉冲响应实测。

### 27.3 卷积混响

卷积混响直接使用实测或采样得到的脉冲响应 `h[n]`：

```text
y[n] = Σ x[k] h[n-k]
```

长脉冲响应会消耗大量乘加运算，工程上通常采用分区快速卷积：前段用小分区降低延迟，后段用 FFT 分区降低 CPU 负载。卷积混响的主要代价是内存、CPU 和固定延迟，而不是音质本身。

## 28. 延迟线、分数延迟和别名

整数采样延迟只能提供 `M/Fs` 秒的延时。合唱、镶边和物理建模常需要分数采样延迟，必须插值，例如线性插值：

```text
x(n+μ) ≈ (1-μ)x[n] + μx[n+1]
```

线性插值简单，但高频幅度会下陷；高质量效果器会使用三次插值、FIR 或 Lagrange 插值。延迟时间快速变化会造成瞬时频移；调制速度过高或反馈过大时，可能出现明显的金属声和调制边带。

非线性处理会产生超过 Nyquist 频率的谐波，这些谐波会折叠回可听频带形成别名：

```text
f_alias = |f_harmonic - kFs|
```

其中 `k` 取使结果落入 `0 ~ Fs/2` 的整数。饱和、失真、激励器和限幅器应考虑 2 倍、4 倍或更高倍过采样，并在降采样前使用抗混叠低通滤波器。

## 29. 动态 EQ、多段压缩和分频器

多段处理先用交叉滤波器把频谱分成多个频带，各段独立检测和控制，再重新合成。分频器的通带增益、相位和重组误差会直接影响声音。

Linkwitz-Riley 四阶分频常由两个二阶 Butterworth 级联得到，理想情况下交叉频率处两路各为 -6 dB，相加后总幅度平坦。实际工程需要检查：

- 分频点附近是否出现峰谷；
- 左右声道和单声道相加是否相位相容；
- 不同频带 Attack/Release 是否造成频带间泵动；
- 低频段压缩是否调制了中高频的整体电平。

动态 EQ 与多段压缩的区别是：动态 EQ 常作用于较窄的频带，解决共振、齿音和偶发刺耳；多段压缩更偏向于控制整段频带的动态。两者都依赖侧链滤波器和时间常数，参数过激会使音色随时间漂移。

## 30. 采样率、位深和余量

### 30.1 Nyquist 限制

采样率 `Fs` 能无混叠表示的最高频率为：

```text
f_Nyquist = Fs / 2
```

48 kHz 系统的 Nyquist 频率为 24 kHz。ADC 输入必须有抗混叠低通；DAC 输出必须有重建低通。否则超声或处理产生的高频会折叠到音频带内。

### 30.2 量化噪声

理想 N 位 PCM、满幅正弦的量化信噪比近似为：

```text
SNR_quantization ≈ 6.02N + 1.76 dB
```

16 位约 98 dB，24 位约 146 dB（实际会受模拟噪声、时钟抖动和有效位数 ENOB 限制）。数字处理链应保留至少 6–12 dB 的峰值余量，避免级联 EQ、压缩补偿和混响叠加造成内部过载。

### 30.3 延迟预算

总延迟约为：

```text
T_total = T_ADC + T_buffer + T_algorithm + T_DAC
```

实时监听、通话和扩声必须把总延迟纳入设计。Look-ahead 限制器、长 FIR、卷积混响和相位声码器常是主要延迟来源。

## 31. 对应的模拟硬件实现

### 31.1 模拟压缩器

模拟压缩器通常由以下部分组成：

```text
输入缓冲 → RMS/Peak 检测 → 整流与 Attack/Release → VCA/OTA 控制 → 输出放大
```

常见增益控制元件包括 VCA、OTA、JFET 和光耦。VCA 线性度和控制馈通决定 THD+N；光耦响应慢但声音平滑；JFET 失真与温度离散性较明显。

### 31.2 模拟噪声门/扩展器

比较器检测包络，控制模拟开关、VCA 或 OTA。需要滞回、Hold 和 Release，否则输入接近门限时会反复开关，产生“抖门”和咔嗒声。PCB 上的电源纹波和检测器串扰也会直接转化为输出噪声。

### 31.3 模拟混响和延迟

- 弹簧和金属板混响依赖机械结构，具有明显的频响和非线性特征。
- BBD 桶式延迟会产生时钟噪声和带宽限制，需要抗混叠/重建滤波器。
- 数字延迟/混响通常由 ADC、DSP、DAC 实现，底噪和延迟由整个编解码链路决定。

### 31.4 ADC/DAC 前端注意事项

- 输入端设置可控增益，避免 ADC 过载；不要用后级数字增益弥补前级过低电平。
- 参考电压、模拟地和数字地回流路径要清晰；时钟和开关电源噪声要远离模拟输入。
- 低通抗混叠滤波器的截止频率、阶数和群时延要与采样率匹配。
- DAC 输出需要重建滤波、静音控制和上电/掉电时序，避免“砰声”。

| 饱和/限制 | 1 kHz THD+N、双音 IMD、过采样对比 | 别名、峰值控制、最大输出和热噪声 |
| 降噪/AEC | 固定噪声、双讲、回声路径变化 | SNR、ERLE、语音失真、收敛时间 |
| M/S 扩展 | L+R、相关度、声像稳定性 | 单声道兼容、中心声像衰减 |

## 33. 三套可直接试用的处理预设

### 33.1 自然人声录音

```text
HPF 80 Hz / 12 dB/oct
问题 EQ：只削减明确共振，单点不超过 -4 dB
扩展器：Range -10 dB，Attack 3 ms，Hold 100 ms，Release 200 ms
压缩器：Ratio 2.5:1，Attack 20 ms，Release 120 ms，GR 3–5 dB
去齿音：6–8 kHz，平均衰减 2–4 dB
混响：Pre-delay 35 ms，Decay 1.2 s，Wet 8%
限制器：True Peak -1 dBTP
```

### 33.2 会议/直播语音

```text
HPF 100 Hz / 12 dB/oct
窄带啸叫削减：只处理实测频点
扩展器：Range -12 dB，Release 250 ms
压缩器：Ratio 3:1，Attack 10 ms，Release 100 ms，GR 4–6 dB
轻度去齿音
混响关闭或 Wet < 5%
限制器：True Peak -1 dBTP
```

### 33.3 音乐总线

```text
宽带 EQ：优先小幅削减
总线压缩：Ratio 1.5:1–2:1，Attack 20–40 ms，Release Auto/100 ms
饱和：低混合比例，检查 THD+N 和高频别名
True Peak 限制器：根据发行平台目标响度设定
```

这些参数只能作为首轮测试起点，不能替代现场电平、房间和声源测量。

## 34. 现象到原因的排查表

| 听感/测量现象 | 优先怀疑 | 检查办法 |
|---|---|---|
| 停顿时忽大忽小 | 门限太接近噪声、Release 太短、AGC 追噪声 | 看包络和门状态，增加滞回/Release |
| 语音尾音被切掉 | 门限过高、Range 过大、Hold 太短 | 降低门限，先把 Range 改为 -10 dB |
| 人声发闷、没有冲击 | Attack 太快、限制器过重、HPF/低频削减过度 | 观察瞬态峰值，放慢 Attack 并降低 GR |
| 背景噪声被明显抬高 | 压缩化妆增益、上行压缩、AGC | 关闭补偿增益，单独测停顿段 RMS |
| 声音金属、像水声 | 降噪过强、短延迟反馈、过采样不足 | 降低降噪量，测频谱边带，开启过采样 |
| 立体声很宽但单声道变薄 | S 过度、短延迟梳状滤波、相位反转 | 监听 L+R，查看相关度和相消频点 |
| 混响拖尾盖住辅音 | Decay 太长、Pre-delay 太短、低频阻尼不足 | 缩短 RT60，增加 Pre-delay 和低频阻尼 |
| 处理后更响但更累 | 限制器过度、THD/IMD 上升、频段提升过多 | 同响度 AB，测 THD+N、True Peak 和高频能量 |

## 35. 最终原则

效果器不是“音质增强器”，而是对信号进行有目的的重构。设计或调试时应按以下顺序判断：

1. 先确认问题是否来自声源、话筒位置、房间、接地、电源或增益结构。
2. 再选改变最少的处理：优先窄带削减、温和扩展和适度动态控制。
3. 对混响、延迟、宽度和饱和等效果，明确它们是“创意添加”，不是“原始还原”。
4. 每次只改变一个变量，使用同响度 AB；同时记录 SNR、LUFS、True Peak、THD+N、IMD、相位、延迟和 CPU 占用。
5. 只有当听感改善与测量结果一致，并且副作用在产品场景可接受时，才把参数固化为产品方案。

## 36. 增益结构和噪声预算：所有效果器的基础

### 36.1 不同电平单位

模拟线路常用 dBu、dBV，数字系统常用 dBFS：

```text
dBu = 20 log10(Vrms / 0.775)
dBV = 20 log10(Vrms / 1.000)
```

`0 dBFS` 是数字系统的满幅上限，不是一个实际电压。模拟接口必须规定参考电平，例如 `+4 dBu ↔ -18 dBFS` 或 `+4 dBu ↔ -20 dBFS`，否则模拟余量和数字余量无法对应。

### 36.2 级联增益和噪声

两级串联时，前级噪声会被后级增益一起放大；后级噪声折算到输入端时要除以前级增益。输入等效噪声可近似为：

```text
e_total,in^2 = e1^2 + e2^2/G1^2 + e3^2/(G1G2)^2 + ...
```

这说明高质量话放应在信号源附近提供足够增益。用后端数字增益补偿前端增益不足，只会把 ADC 噪声和后级噪声一起抬高。

### 36.3 余量设计

```text
Headroom(dB) = Maximum_expected_peak - Nominal_operating_level
```

语音、鼓和现场扩声的瞬态峰值可能比平均电平高 12–20 dB。若各效果器都在 0 dBFS 附近工作，EQ 提升、混响叠加和压缩补偿很容易造成内部溢出。实际产品应在每个模块之间保留 6–12 dB 数字余量，并在模块输出设置软限幅或饱和保护。

## 37. 噪声门和下行扩展器的深入设计

### 37.1 静态曲线

下行扩展器在低于阈值时按比例衰减。用 dB 表示的一种理想曲线为：

```text
Lout = Lin                              (Lin ≥ T)
Lout = T + Rexp · (Lin - T)              (Lin < T)
```

当 `Rexp=4`、`T=-45 dBFS`、输入噪声 `Lin=-55 dBFS` 时：

```text
Lout = -45 + 4×(-55+45) = -85 dBFS
```

理论衰减为 30 dB；如果设置了 `Range=-20 dB`，实际只衰减到约 -75 dBFS。Range 是防止“完全静音”造成不自然断裂的重要参数。

### 37.2 时间参数的物理作用

- **Attack**：开门速度。过慢会吃掉辅音起始，过快可能把点击声直接放出。
- **Hold**：确认信号仍然存在的保持时间，防止每个音节之间反复关门。
- **Release**：关门速度。过快会产生切割感，过慢会让停顿残留噪声。
- **Hysteresis**：开门阈值和关门阈值的差值。适当滞回可减少临界点抖动。
- **Sidechain HPF**：避免低频碰撞或空调声触发开门。

### 37.3 选择门限的测量方法

1. 录制 30 秒纯背景噪声，计算与实际节目相同带宽、相同加权下的 RMS。
2. 将门限初始设为噪声 RMS + 6 dB。
3. 播放最弱的有效语音，检查门是否能稳定打开。
4. 如果弱音被切，降低门限或减小扩展比；如果停顿噪声频繁打开，增加 Hold、滞回或侧链高通。

不要用峰值噪声设置门限。峰值受偶发点击影响很大，应以短时 RMS 或包络统计值为主。

## 38. 压缩器的结构、检测方式和副作用

### 38.1 Feed-forward 与 Feedback

- **Feed-forward**：检测输入并计算增益，阈值、Ratio 和 GR 更容易精确控制。
- **Feedback**：检测输出，控制曲线更平滑，常带有独特的模拟音色，但参数受当前增益影响，建模更复杂。

### 38.2 Peak、RMS 和加权检测

- Peak 检测适合保护瞬态和限制器。
- RMS 检测更接近能量和主观响度，适合人声和音乐压缩。
- 侧链高通可以减少低频触发；侧链低通或带通可针对特定频段。

### 38.3 Soft-knee

硬膝在阈值处斜率突然改变，容易产生调制感。软膝在 `T-W/2` 到 `T+W/2` 范围内逐渐改变 Ratio。实现时可使用平滑过渡或二次曲线，确保一阶连续，减少增益突变。

### 38.4 泵动和喘息的原因

压缩器把低频鼓点或爆破音检测为大电平，整体增益下降；低频结束后增益恢复，其他频段随之忽大忽小，这就是泵动。压缩器把底噪抬高，且语音暂停时噪声随 Release 起伏，称为喘息。

解决顺序：

1. 检查话放增益和噪声源；
2. 在侧链加入 HPF；
3. 减小 Ratio 和最大 GR；
4. 放慢 Release 或使用程序相关 Release；
5. 必要时在压缩前加入温和扩展器。

## 39. 限制器、削波和 True Peak

### 39.1 采样峰值不等于模拟峰值

相邻采样点都低于 0 dBFS，重建后的连续时间波形仍可能在采样点之间超过 0 dBFS，这称为 inter-sample peak。AAC、MP3 等编码器还可能进一步产生峰值增益。

因此产品输出至少应同时显示：采样峰值、True Peak、短时响度和限制器 GR。仅看普通 Peak 表可能漏掉 DAC 或编码后的过载。

### 39.2 Look-ahead 的延迟

Look-ahead 把输入延迟一段时间，先观察即将到来的峰值，再提前降低增益。它能减少峰值穿透，但会引入：

```text
T_lookahead = N_lookahead / Fs
```

实时演出需把该延迟加入监听链路；录音后期则可以用更长 Look-ahead 换取更平滑的峰值控制。

## 40. 混响的听感指标和调试方法

### 40.1 EDT、T20、T30 和 RT60

实际衰减曲线往往不是单一直线，因此会分别计算：

- **EDT**：从 0 到 -10 dB 的早期衰减斜率外推到 60 dB。
- **T20**：从 -5 到 -25 dB 的斜率外推。
- **T30**：从 -5 到 -35 dB 的斜率外推。
- **RT60**：衰减 60 dB 所需时间。

不同频带的 RT60 相差太大，会造成低频轰鸣或高频过干。会议语音通常更关注 500 Hz–2 kHz 的 EDT、C50 和 D50，而不是追求很长的 RT60。

### 40.2 清晰度指标

语音清晰度常用 C50，音乐常用 C80：

```text
C50 = 10 log10(E_0-50ms / E_50ms-∞)
C80 = 10 log10(E_0-80ms / E_80ms-∞)
```

`D50` 为 50 ms 内能量占总能量的比例：

```text
D50 = E_0-50ms / E_total
```

C50、D50 越高，早期能量占比越大，语言通常越清楚；混响尾音越长，这些数值通常越低。

## 41. 空间效果的双耳原理

人耳定位主要利用两类线索：

- **ITD（双耳时间差）**：低频定位更依赖到达时间差。
- **ILD（双耳电平差）**：高频定位更依赖头部遮挡造成的电平差。

短延迟加宽利用先到效应，但延迟过短会形成梳状滤波；延迟过长会变成回声。M/S 扩展必须控制 S 分量增益，并检查以下量：

```text
Correlation = cross-correlation(L, R)
Mono = (L + R) / 2
```

相关度接近 -1 表示单声道相加有严重相消风险。不要仅凭立体声监听判断宽度是否安全。

## 42. EQ 的 Q 值、带宽和实际选择

参数 EQ 的近似带宽关系：

```text
Q ≈ f0 / BW
```

`f0` 是中心频率，`BW` 是 -3 dB 带宽。Q 越高，处理越窄，越适合去除啸叫和单点共振；但高 Q 大幅提升会产生明显的振铃和频率不自然。人声音色修正通常先用 Q=0.7–1.4 的宽带，小幅度处理；问题频点才使用高 Q 削减。

### 42.1 EQ 增益对余量的影响

某频段提升 `G` dB，线性幅度乘数为：

```text
A = 10^(G/20)
```

提升 6 dB 等于振幅乘 2，峰值余量减少 6 dB。若多个频段同时提升，峰值叠加还会受到相位关系影响，不能简单把 dB 相加。EQ 后应重新测量 True Peak 和内部电平。

## 43. 降噪的帧处理、伪影和延迟

STFT 语音降噪通常包含：加窗、FFT、噪声估计、频谱增益计算、IFFT 和 overlap-add。帧长决定频率分辨率和延迟：

```text
Δf = Fs / N_fft
T_frame = N_fft / Fs
```

帧长过短，频率分辨率不足；过长则延迟大、瞬态模糊。语音实时产品常在 10–32 ms 帧长范围内折中，并使用 50% 或更高重叠率。

降噪伪影包括：

- 音乐噪声：频谱增益在相邻频点和帧之间快速变化；
- 泵动：噪声估计随语音包络变化；
- 语音吞字：过度谱抑制或 VAD 错误；
- 高频空气感消失：频谱底过低或高频被持续衰减。

实际产品应同时测量降噪量、语音失真、双讲性能和算法延迟，而不是只给出“降噪多少 dB”。

## 44. AEC、VAD 和噪声门的协同

会议设备通常包含：

```text
回声估计 AEC → 残余回声抑制 RES → 噪声抑制 NS → VAD/门控 → AGC → 限制器
```

AEC 需要参考扬声器远端信号；VAD 判断当前是否有人说话；AGC 调整电平。顺序错乱会造成：

- 先 AGC 后 AEC：远端回声变化，AEC 难以收敛；
- 先强噪声门后 AEC：回声尾音被切断，误导自适应滤波器；
- 强 NS 后 VAD：语音特征被削弱，VAD 漏检；
- AEC 后再大幅压缩：残余回声和背景噪声被一起抬高。

验证 AEC 时要测 ERLE：

```text
ERLE(dB) = 10 log10(P_echo_before / P_echo_after)
```

还要进行单讲、双讲、远端静音、近端静音和回声路径突变测试。

## 45. DSP 实现中的数值稳定性

### 45.1 Biquad 状态和直流偏置

IIR 滤波器状态若未清零，启动时会出现爆音；输入存在 DC 偏置时，压缩器 RMS 和饱和器工作点会偏移。产品应提供：

- 上电状态清零或软启动；
- Bypass 切换时的交叉淡化；
- 参数跳变的平滑插值；
- 保护 NaN、Inf 和异常系数。

### 45.2 定点实现

定点 DSP 要明确 Q 格式、乘法位宽、舍入和饱和策略。截断误差会累积为噪声，反馈滤波器还可能因量化产生极限环。高质量实现通常使用更宽的累加器、误差反馈或低电平抖动（dither）。

### 45.3 参数平滑

若 EQ 增益或延迟时间逐采样突变，会产生宽带点击。线性平滑的一种形式：

```text
p[n] = p[n-1] + α (p_target - p[n-1])
```

`α` 决定平滑速度。对于频率、Q、混响反馈等参数，建议在控制率或音频率做连续插值，并限制最大变化速度。

## 46. 标准化测试信号和测试顺序

### 46.1 测试信号

1. **静音**：测本底噪声、DC、门控泄漏。
2. **1 kHz 正弦**：测增益、频率响应、THD+N。
3. **20 Hz–20 kHz 对数扫频**：测频响、相位、群时延和失真随频率变化。
4. **双音或多音**：测 IMD、互调侧带和频带间调制。
5. **脉冲/MLS**：测延迟、脉冲响应、混响尾音和 RT60。
6. **粉红噪声**：测长期频谱、RMS 稳定性和动态处理。
7. **真实语音/音乐**：测可懂度、听感、泵动和尾音。

### 46.2 推荐顺序

```text
旁路一致性 → 静音噪声 → 增益/频响 → 动态曲线 → 失真/IMD
→ 延迟/CPU → 单声道/相位 → 真实语音和音乐 AB
```

先确认旁路和增益一致，再比较音质；否则输入输出电平差会掩盖真正的处理副作用。

## 47. 数值例子：一条语音链的计算

假设 ADC 输出语音平均电平为 -24 dBFS，峰值为 -8 dBFS，停顿噪声为 -58 dBFS。

### 47.1 原始状态

```text
语音段 SNR = -24 - (-58) = 34 dB
峰均差 = -8 - (-24) = 16 dB
```

### 47.2 加 3:1 压缩

设阈值 `T=-30 dBFS`，输入峰值 `Lin=-8 dBFS`：

```text
GR_peak = (1 - 1/3) × (-8 + 30) ≈ 14.7 dB
Lout_peak ≈ -22.7 dBFS
```

若化妆增益补回 10 dB，则语音平均电平约为 -14 dBFS，但停顿噪声也从 -58 dBFS 上升到约 -48 dBFS。此时语音段 SNR 仍约为 34 dB，节目听感可能更响，却没有真正改善前端噪声。

### 47.3 再加 Range=-15 dB 的扩展器

停顿噪声低于门限时最多再下降 15 dB，停顿输出约为 -63 dBFS。节目级静音更干净，但弱音和混响尾音也可能被压低，必须以最弱有效语音进行验证。

## 48. 产品化时应固定的接口和保护

每个效果器模块建议明确以下接口：

- 输入/输出满幅定义和标称电平；
- 最大无削波输入和输出；
- 固定延迟与可变延迟；
- 旁路模式（真旁路、处理旁路或平滑旁路）；
- 参数范围、默认值、单位和步进；
- 上电、掉电、采样率切换时的状态处理；
- 异常输入、NaN、溢出和 CPU 超时的降级策略；
- 单声道、立体声、M/S 和多通道路由规则。

硬件产品还应测电源纹波、EMI 串扰、ADC 输入噪声、DAC 输出噪声、继电器/静音电路的瞬态，以及温度变化下参数漂移。

## 49. 复盘一段处理是否“值得”

可以用下面的四问作最终评审：

1. 它解决的是可重复测量的问题，还是只是让声音变响、变亮、变宽？
2. 改善是否发生在真正有用的时间段和频带，而不是只改善静音段统计值？
3. 它引入的失真、相位变化、延迟、CPU 负载和单声道风险是否能接受？
4. 去掉它后，听众是否能可靠感知差异；保留它后，产品指标是否可验证？

只有四个问题都有明确答案，才能把效果器从“试听设置”变成“产品方案”。

## 50. 声学基础：电子处理无法替代声源和房间

### 50.1 声压级和距离

声压级定义为：

```text
SPL(dB) = 20 log10(p_rms / p0)
p0 = 20 μPa（空气中的参考声压）
```

在自由声场、点声源近似下，距离加倍，声压级约下降 6 dB：

```text
ΔSPL ≈ -20 log10(r2/r1)
```

这解释了为什么麦克风靠近嘴巴能提高直达声相对环境噪声和混响的比例。它不是电子处理提高 SNR，而是**在声学域提高了直达声/环境声比**。

### 50.2 波长、驻波和房间模态

```text
λ = c / f
```

其中空气声速 `c` 约为 343 m/s。100 Hz 的波长约 3.43 m，所以低频问题常由房间尺寸、墙面和摆位决定，普通小音箱或 EQ 很难彻底解决。

矩形房间的模态频率近似为：

```text
f_pqr = (c/2) · sqrt[(p/Lx)^2 + (q/Ly)^2 + (r/Lz)^2]
```

`p、q、r` 为非负整数，`Lx、Ly、Lz` 为房间三边长度。模态会形成某些位置的低频隆起和衰减；EQ 只能削减隆起，无法可靠填补空间相消形成的深陷。

### 50.3 处理优先级

```text
声源/话筒距离与指向性 → 房间和摆位 → 机械隔振/屏蔽 → 增益结构 → DSP
```

越靠前的环节解决问题，副作用越小。例如风噪优先用防风罩和机械减振；处理已经录下来的风噪，通常会吞掉低频和语音细节。

## 51. 话筒、前端与声学输入

### 51.1 常见话筒类型

| 类型 | 优点 | 典型限制 | 常见用途 |
|---|---|---|---|
| 动圈 | 抗高 SPL、结构可靠、无需极化电压 | 灵敏度较低，高频和瞬态受振膜质量影响 | 舞台人声、乐器近讲 |
| 电容 | 灵敏度高、频响和瞬态通常更好 | 需要偏置/幻象供电，对湿度和过载更敏感 | 录音、测量、会议 |
| 驻极体/MEMS | 体积小、一致性高、易集成阵列 | 底噪、动态范围与封装声学设计有关 | 会议终端、耳机、消费电子 |
| 铝带 | 质感自然、八字指向明显 | 输出低、对风和幻象接法敏感 | 录音室特定音色 |

### 51.2 关键规格如何读

- **灵敏度**：例如 `-38 dBV/Pa`，表示 94 dB SPL（1 Pa）下输出电压。数值越接近 0，输出越大。
- **自噪声**：电容/MEMS 常以 dBA SPL 表示；越低越利于拾取安静声源。
- **最大 SPL**：达到指定 THD 前的最大声压，不等于整条链路都不会过载。
- **指向性**：心形、超心形、全指向、八字的离轴频响不同；不能只看主轴曲线。
- **EIN**：前置放大器的等效输入噪声，必须带宽和源阻抗条件一起看。

### 51.3 动圈话筒前端的工程重点

动圈话筒输出通常为 mV 级，需要较高、低噪声的前置增益。关键不是盲目追求“很大增益”，而是：

```text
足够增益 + 低输入电压噪声/电流噪声 + 合适输入阻抗 + 高 CMRR + 足够余量
```

平衡输入的共模抑制比：

```text
CMRR(dB) = 20 log10(A_d / A_cm)
```

对长线话筒、舞台灯光干扰和开关电源噪声，CMRR、阻抗平衡、屏蔽层接地策略往往比后级噪声门更重要。

### 51.4 近讲效应与高通

压力梯度型（心形、八字等）话筒靠近声源时低频增强，这就是近讲效应。人声近讲时常需 HPF 或低架削减，但截止点必须按话筒距离、声线和应用决定。若用很陡的 HPF“压住低频”，可能损失声音厚度并改变相位。

## 52. 心理声学：为什么“测得更好”不一定“听起来更好”

### 52.1 等响曲线

人耳对 2–5 kHz 最敏感，低频和极高频需要更大声压才有同样响度。因此在低音量监听下，人会倾向于把低频和高频调高；音量升高后，这种补偿可能显得过量。

产品调音必须规定参考监听声压或参考播放电平。没有统一电平，关于“低频够不够”“高频亮不亮”的结论不可复现。

### 52.2 临界带和掩蔽

强声音会掩蔽相近频率、相邻时间内的弱声音。可用 Bark 标度近似描述听觉频带位置：

```text
z(f) = 13 arctan(0.00076f) + 3.5 arctan[(f/7500)^2]
```

低频轰鸣会掩蔽人声清晰度，适度 HPF 或低中频削减可能让语音“更清楚”；这不是高频本身被创造出来，而是掩蔽被减少。

时间掩蔽说明大瞬态前后的一小段弱声不易被听见。限制器、去齿音和降噪若只在掩蔽区轻微工作，主观副作用可能小；若持续工作，则容易被察觉。

### 52.3 同响度 AB 和 ABX

更响的样本往往被听成更清晰、更有低频、更有细节。比较处理前后时：

1. 先把平均响度匹配到约 0.5 dB 以内；
2. 只改变一个变量；
3. 盲听随机 A/B/X，而不是看着插件名称试听；
4. 记录可重复识别的片段和原因。

ABX 不能替代测量，但能防止把音量偏差当成音质改善。

## 53. 其他常见创意效果器及其公式

### 53.1 Tremolo 与 Auto-pan

Tremolo 是振幅调制：

```text
y(t) = x(t) · [1 + m sin(2πf_LFO t)]
```

`m` 是调制深度，`f_LFO` 是低频振荡器频率。深度过大时，音量周期性归零，语音可懂度会下降。Auto-pan 是把同一 LFO 以不同增益分配给左右声道，会改变声像但不应造成总能量明显跳动。

### 53.2 Ring Modulator

环形调制把输入乘以载波：

```text
y(t) = x(t) · cos(2πf_c t)
```

若输入是频率 `f_s` 的正弦，输出会出现 `f_c+f_s` 和 `|f_c-f_s|` 两个边带。它是有意制造不和谐侧带的效果，不适合保真语音链路。

### 53.3 Vocoder

声码器用分析滤波器组提取调制信号各频带包络，再控制载波的同频带增益：

```text
carrier_i → bandpass_i → gain = envelope(modulator_i) → sum
```

频带数量越多，清晰度越高、CPU 越高；频带过少会使辅音不清。它本质上重合成声音，不是降噪或音色 EQ。

### 53.4 Bitcrusher 与降采样

Bitcrusher 直接减少有效量化位数；降采样效果会降低更新率。量化步进变大，量化误差增加：

```text
e_q[n] = x[n] - Q(x[n])
```

它会增加量化噪声、谐波和别名，属于 Lo-fi 创意效果。产品若提供此效果，必须与正常处理链明确隔离，避免误用于语音保真模式。

### 53.5 Granular（粒子）处理

粒子处理把信号切成短帧（grain），再重排、叠加、变速或变调：

```text
y(t) = Σ g_k(t - t_k) · w(t - t_k)
```

`w` 是窗函数。粒子过短会有颗粒感，过长则瞬态被拉糊；窗函数和重叠率决定是否出现点击。

## 54. 扬声器、分频和系统 DSP

### 54.1 扬声器不是理想负载

扬声器阻抗会随频率变化，在谐振点明显升高。功放的额定“4 Ω/8 Ω”只是一种标称值，电源、热设计、限流和保护都必须基于最差阻抗相位角和节目波形评估。

### 54.2 低音单元的主要约束

- **热限制**：音圈升温导致电阻增大，灵敏度和参数漂移。
- **位移限制**：极低频会造成振幅过大，即使功率不高也可能超行程。
- **箱体/端口限制**：倒相箱在调谐频率以下失去空气弹簧约束，必须使用次声高通保护。

Thiele-Small 参数、箱体容积、调谐频率和 DSP 高通必须协同设计。不能只按额定功率给扬声器做保护。

### 54.3 分频和时间对齐

分频器除了幅频，还必须考虑相位和声学中心偏移。两个单元在交叉点的时间差：

```text
Δt = Δd / c
```

对应相位差：

```text
Δφ = 2πfΔt
```

若不对齐，交叉区会形成峰谷和离轴声像偏移。DSP 延迟、全通滤波器或机械前后位置都可用于时间对齐；最终应使用门控近场/远场测量与听音共同验证。

### 54.4 扬声器保护 DSP

典型链路：

```text
输入 EQ → 分频 → 单元校正 EQ/延迟 → 峰值限制 → 热限制 → 功放
```

峰值限制保护机械位移，慢速热限制保护音圈平均功耗。两者必须分开设计：一个 Release 常为几十到几百毫秒，另一个热时间常数可达数秒到数十秒。

## 55. 麦克风阵列、波束形成和自动混音

### 55.1 Delay-and-sum 波束形成

阵列中每个麦克风对准目标方向后相加：

```text
y[n] = (1/M) Σ x_m[n - d_m]
```

目标方向的语音相干叠加，其他方向信号部分相消。理想情况下，对彼此不相关噪声，阵列增益约为：

```text
Array_gain ≈ 10 log10(M) dB
```

实际增益受麦克风间距、频率、房间混响、阵列误差和目标移动影响。阵列不能无限提高 SNR；在强混响房间中，直达声优势会迅速下降。

### 55.2 波束形成的工程陷阱

- 麦克风匹配误差会形成方向图偏差；
- 间距过大产生空间混叠，间距过小则低频指向性有限；
- 波束切换会导致声像跳变或音色变化；
- 对远讲、移动说话者和多说话者，需要 VAD、DOA 和自动混音协同。

### 55.3 自动混音

自动混音器在多个麦克风中抑制未发言通道，以降低开麦数量带来的环境噪声和啸叫风险。其增益共享、优先级、保持时间和切换平滑决定自然度。它比每路强噪声门更适合多人会议，但需要完整的双讲和抢话测试。

## 56. 数字时钟、同步与网络音频

### 56.1 时钟抖动

采样时刻误差会转化为幅度噪声。对频率为 `f_in` 的正弦，抖动限制的理论 SNR 近似：

```text
SNR_jitter ≈ -20 log10(2π f_in σ_t)
```

`σ_t` 是 RMS 时钟抖动。输入频率越高，抖动影响越大。系统设计要关注主从时钟、PLL、晶振相噪和时钟走线，而不是只看“采样率支持到多少”。

### 56.2 多设备同步

多台 ADC/DAC 若未共用或同步时钟，会慢慢漂移，最终产生丢样、重复样、爆音或声像漂移。网络音频系统常使用 PTP 同步；工程验收要覆盖长时间运行、网络抖动、主时钟切换和断网恢复。

### 56.3 网络音频的现实约束

网络音频除了带宽，还要考虑固定/可变缓冲、PTP 锁定时间、QoS、交换机配置和冗余链路。低延迟扩声系统的整体延迟预算必须包含网络缓冲和 DSP 块处理延迟。

## 57. 音频硬件可靠性与 EMC

### 57.1 接地和屏蔽

- 平衡传输依赖两根信号线阻抗对称与接收端 CMRR，不只是“接了三芯线”。
- 屏蔽层主要拦截电场耦合；双绞结构主要抑制磁场耦合。
- 大电流功放回流、数字时钟回流和微弱话筒输入回流不能混在同一狭窄路径上。
- 幻象供电必须通过匹配电阻对称施加，避免把直流或噪声转成差模信号。

### 57.2 常见干扰定位

| 现象 | 可能来源 | 优先检查 |
|---|---|---|
| 50/100 Hz 嗡声 | 地环路、工频磁耦合、电源纹波 | 接地路径、变压器距离、平衡接法 |
| 高频啸叫/噪点 | DC-DC、时钟、无线模块 | 频谱、布局、屏蔽、滤波和地回流 |
| 触摸/插拔爆音 | 直流偏置、静音时序、接触弹跳 | 输出耦合、继电器/模拟开关时序 |
| 话筒开关时噪声变大 | 幻象不平衡、前端饱和、线缆屏蔽问题 | 差分测量、CMRR、插座焊接 |

### 57.3 上电与掉电静音

编解码器、DSP、功放和继电器的时序不对，会让 DC 偏置或耦合电容充放电形成砰声。输出静音可以采用：

- 继电器延时接通/提前断开；
- 模拟静音开关；
- DAC 数字渐变（ramp）；
- 功放使能与 MUTE 时序控制。

任何一种方式都要测上电、掉电、热插拔、异常复位和反复循环，而不只是测一次正常开关机。

## 58. 测量、校准和标准化表达

### 58.1 为什么要校准

没有校准，仪器显示的 dBFS、dBu、SPL、频响和失真不能可靠比较。至少需要：

- 明确测试端口阻抗、参考电平和带宽；
- 校准测量麦克风灵敏度；
- 确认音频分析仪/声卡的自身底噪和 THD+N；
- 记录环境温湿度和背景噪声；
- 用已知参考源进行回归检查。

### 58.2 常用标准类别

- **AES17**：数字音频设备测量方法。
- **IEC 60268 系列**：声系统、麦克风、扬声器等相关测量。
- **ITU-R BS.1770 / EBU R128**：节目响度和 True Peak。
- **IEC 61672**：声级计性能要求。

标准的关键价值是统一测试条件。宣传参数若没有测试带宽、加权、输入电平、负载和失真门限，通常无法横向比较。

### 58.3 频响的表达陷阱

“20 Hz–20 kHz”必须追问容差，例如 `±0.5 dB` 还是 `-10 dB`；扬声器频响还必须说明测量距离、轴向、平滑方式、门控窗口和房间条件。没有这些条件，曲线很容易被误读。

## 59. 面向不同产品的优先指标

| 产品 | 最优先指标 | 次优先指标 | 常见误区 |
|---|---|---|---|
| USB 录音话筒 | 自噪、最大 SPL、频响、驱动稳定性 | 监听延迟、指向性、USB 兼容 | 只堆 DSP 效果，不处理结构噪声 |
| 会议终端 | AEC、双讲、阵列、远讲可懂度、延迟 | NS、AGC、自动混音、网络同步 | 用强门限掩盖 AEC/房间问题 |
| 无线话筒 | RF 稳定、抗干扰、动态范围、音频延迟 | 编解码、加密、电池、射频法规 | 只看发射功率，不看接收灵敏度和共存 |
| 有源音箱/功放 | 最大 SPL、失真、保护、热、分频对齐 | 网络、EQ、预设、延迟 | 只按额定功率选功放，不看位移/热限制 |
| 调音台/处理器 | 通道数、EIN、余量、路由、DSP 延迟 | 场景切换、冗余、网络音频 | 忽略场景切换爆音和时钟恢复 |

## 60. 从需求到产品的音频设计流程

```text
定义用户场景和验收语言
        ↓
定义声学、模拟、数字、时延和可靠性指标
        ↓
建立增益/噪声/功耗/热预算
        ↓
先做旁路硬件和基础声学样机
        ↓
引入最少必要的 DSP 模块并逐项测量
        ↓
真实场景盲听、长稳、EMC、异常时序验证
        ↓
固化默认参数、保护阈值、测试脚本和回归音频样本
```

需求要写成可验证的句子，例如“1 m 处 65 dBA 粉红噪声背景中，距离 3 m 的正常语速语句可懂度达到指定目标”，而不是“降噪效果好”或“声音清晰”。

## 61. 音频调试记录的最低要求

每一次改板、改 DSP 或改参数，应同时保存：

- 原始音频、处理后音频和旁路参考；
- 版本号、采样率、固件/DSP 算法版本；
- 话筒型号、距离、方位、房间和播放声压；
- 全部参数、默认值和预设名称；
- 频响、噪声、THD+N、IMD、延迟、响度和相关度结果；
- 失败样本、异常波形与修复结论。

音频问题常常“听得到但难复现”。完整记录能让问题从个人经验变成可追溯的工程结论。

## 62. 扩展后的总原则

专业音频不是单独优化 SNR、THD+N、响度或效果数量，而是在声学、模拟、DSP、时钟、电源、EMC、交互和应用场景之间做可验证的取舍。任何处理算法都应回答三件事：

```text
它解决哪个明确问题？
它引入哪些可测和可听的代价？
在目标产品、目标声源和目标环境下，代价是否值得？
```

能持续用这三句话审查设计，才会从“会调效果器”进入“能设计专业音频产品”。
