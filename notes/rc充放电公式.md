# RC充放电公式

RC充电时间常数(τ) 

$τ = R × C$

	例子:  10K * 1uF  =  10ms

一个最简单的RC电路由一个电阻（R）和一个电容（C）串联组成。

- **电容**：以电场形式储存能量。电压不能突变。
    
- **电阻**：消耗能量，限制电流的大小。
    

充放电过程，就是电容在储存能量和释放能量的过程。

### 1. 充电过程

假设电容初始电压为0。在时间 t=0 时刻，将开关闭合到一个电压为 **V₀** 的直流电源上。

**公式：**

**电压：**  
`Vᶜ(𝓉) = V₀ * (1 - e^(-𝓉/RC))`

**电流：**  
`I(𝓉) = (V₀ / R) * e^(-𝓉/RC)`

**其中：**

- `Vᶜ(𝓉)`：在 **t** 时刻，**电容两端的电压**。
    
- `V₀`：充电电源的电压。
    
- `R`：电阻值（单位：欧姆 Ω）。
    
- `C`：电容值（单位：法拉 F）。
    
- `e`：自然常数，约等于 2.71828。
    
- `I(𝓉)`：在 **t** 时刻，电路中的**电流**。
    

**过程理解：**

- **t = 0 时**：电容相当于短路，电压 `Vc = 0`，电流最大 `I = V₀ / R`。
    
- **t 增大时**：电容开始充电，`Vc` 指数上升，`I` 指数下降。
    
- **t → ∞ 时**：电容充满，相当于开路，`Vc = V₀`，电流 `I = 0`。
    

---

### 2. 放电过程

假设电容已经充有电压 **V₀**。在时间 t=0 时刻，将开关闭合到一个短路路径上。

**公式：**

**电压：**  
`Vᶜ(𝓉) = V₀ * e^(-𝓉/RC)`

**电流：**  
`I(𝓉) = -(V₀ / R) * e^(-𝓉/RC)` （负号表示电流方向与充电时相反）

**其中：**

- `Vᶜ(𝓉)`：在 **t** 时刻，**电容两端的电压**。
    
- `V₀`：电容的**初始电压**。
    
- `R`, `C`, `e` 含义同上。
    

**过程理解：**

- **t = 0 时**：电容电压 `Vc = V₀`，放电电流最大 `I = -V₀ / R`。
    
- **t 增大时**：电容开始放电，`Vc` 指数下降，`I` 的绝对值也指数下降。
    
- **t → ∞ 时**：电容放电完毕，`Vc = 0`，电流 `I = 0`。
    

---

### 3. 关键参数：时间常数 τ

在公式中，`RC` 这个乘积非常重要，它被称为**时间常数**，用希腊字母 **τ** 表示。

`τ = R * C`

**τ 的物理意义：** 它代表了充放电**速度**的快慢。

- **单位**：欧姆(Ω) * 法拉(F) = 秒(s)。所以它是一个时间量。
    
- **具体含义**：
    
    - 当充电时间 `t = τ` 时，`Vc = V₀ * (1 - e⁻¹) ≈ V₀ * 0.632`。即电压上升到**电源电压的 63.2%**。
        
    - 当放电时间 `t = τ` 时，`Vc = V₀ * e⁻¹ ≈ V₀ * 0.368`。即电压下降到**初始电压的 36.8%**。
        

**工程应用中的经验法则：**

- 通常认为，经过 `3τ` 的时间，充放电过程完成了约 95% (`Vc = 0.95V₀` 或 `0.05V₀`)。
    
- 经过 `5τ` 的时间，充放电过程完成了约 99.3% (`Vc = 0.993V₀` 或 `0.007V₀`)，可以认为基本结束。
    

**τ 对曲线的影响：**

τ 越大，充放电速度越慢；τ 越小，充放电速度越快。

---

### 4. 公式总结表

|过程|电容电压 `Vc(t)`|电路电流 `I(t)`|初始值 (t=0)|终值 (t→∞)|
|---|---|---|---|---|
|**充电**|`V₀ * (1 - e^(-t/RC))`|`(V₀ / R) * e^(-t/RC)`|`Vc = 0`, `I = V₀/R`|`Vc = V₀`, `I = 0`|
|**放电**|`V₀ * e^(-t/RC)`|`-(V₀ / R) * e^(-t/RC)`|`Vc = V₀`, `I = -V₀/R`|`Vc = 0`, `I = 0`|

### 5. 实例计算

**问题：** 一个 10kΩ 电阻和一个 100µF 电容串联。

1. 求时间常数 τ。
    
2. 用 5V 电源充电，问 1 秒后电容电压是多少？
    
3. 充满后开始放电，问 2 秒后电容电压是多少？
    

**解答：**

1. **τ = R * C =** 10 × 10³ Ω * 100 × 10⁻⁶ F = **1 秒**。
    
2. **充电过程**，使用充电公式，`t = 1s`, `τ = 1s`:  
    `Vc(1) = 5 * (1 - e^(-1/1)) = 5 * (1 - e⁻¹) ≈ 5 * (1 - 0.368) = 5 * 0.632 ≈ **3.16V**`  
    （正好是 63.2%，验证了时间常数的定义）
    
3. **放电过程**，使用放电公式，初始电压 `V₀ = 5V`, `t = 2s`, `τ = 1s`:  
    `Vc(2) = 5 * e^(-2/1) = 5 * e⁻² ≈ 5 * 0.135 ≈ **0.68V**`
