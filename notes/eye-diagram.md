# 眼图、抖动与链路误码验证

## 1. 眼图怎样形成

将许多码元波形按时钟相位叠加在一个或两个单位间隔 UI 内，就得到眼图。NRZ 的 UI 等于 $1/R_b$；PAM4 每符号承载两位时，UI 应按符号率计算，不应直接用原始 bit rate 的倒数。

接收器在某个时刻、某个判决电平采样。眼高反映垂直判决裕量，眼宽反映水平时序裕量，但它们受幅度噪声、失真、抖动、ISI 与触发方法共同影响。单一截图不能完整代表链路可靠性。

## 2. 固定传播延时不会直接闭眼

若整条波形只有恒定延时，眼图相对于外部参考整体平移；把采样相位正确对齐后，眼口不会因此必然变小。真正缩小裕量的常见因素包括：

- 码间串扰：有限带宽、反射和通道频率响应使当前码元依赖前后码型；
- 时变抖动：时钟/数据边沿相对采样时刻变化；
- 噪声、串扰、供电扰动与非线性失真；
- 多路径延迟不一致或差分偏斜导致的幅相失配。

因此“走线更长”应通过插损、反射、色散、串扰和接收时钟恢复来分析，不能直接等同于常数延迟造成闭眼。

## 3. 测试条件决定眼图含义

写清测量参考平面、码型、数据速率、发射预加重、接收均衡和时钟恢复设置。示波器理想外部触发与真实接收器 CDR 不同；CDR 带宽内可跟踪的抖动与带宽外残留的作用不同。

CTLE/DFE 后的眼图与通道原始眼图不能直接互相比较。DFE 属于基于判决的补偿，误判传播及接收器内部实现也需要考虑。去嵌入探头、夹具或连接器必须有可信传递函数，且不能通过过度高频补偿放大噪声制造虚假改善。

## 4. 从眼图到 BER

有限采样的眼图中没有点触碰掩膜，不等于证明任意低误码率。应按接口标准使用对应掩膜、滤波、码型、参考接收器和统计方法。

若测试 $N$ 位、观察到零误码，在独立且平稳的近似模型下，95% 单侧置信上界约为：

$$
BER_{upper}\approx\frac{-\ln0.05}{N}\approx\frac3N
$$

因此要用零误码证据支持约 $10^{-12}$ 上界，需约 $3\times10^{12}$ 位；10 Gb/s 连续测试理想时长约 300 s。突发误码、非平稳干扰、训练间隙与协议重传会使简单独立模型不充分，还应记录这些状态。

## 5. 调试顺序

先检查速率、码型与测量位置，再验证终端、连接器、回流和差分偏斜；对照通道 S 参数或时域反射，判断是插损、阻抗不连续还是串扰。随后在允许范围内调整发送均衡与接收均衡，并同时验证误码、功耗和跨温度表现。

保存眼图参数和原始波形，覆盖线缆/板卡组合、电压、温度与相邻通道活动。眼图是定位和合规证据的一部分，应与 BER、协议错误计数及连接稳定性共同解释。
