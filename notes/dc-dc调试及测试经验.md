# Buck DC-DC 通用设计、计算与调试经验手册

> 适用范围：非隔离降压型（Buck）开关电源的方案评估、器件计算、原理图检查、PCB 布局、样机测试和故障定位。  
> 文档版本：V1.0  
> 更新日期：2026-07-22

---

## 1. 这份手册怎么用

建议按照下面的顺序完成一个新设计：

1. 明确输入、输出、负载、纹波、温度和尺寸要求。
2. 从数据手册提取工作边界，而不是只看首页宣传参数。
3. 选择开关频率和电感纹波比例。
4. 计算电感、输入电容、输出电容和反馈网络。
5. 检查最小导通时间、最小关断时间、最大占空比和启动电流。
6. 估算损耗、效率和温升。
7. 按高频电流回路完成 PCB 布局。
8. 用正确方法测量启动、纹波、负载瞬态、温升和 EMI。
9. 在输入、负载、温度和元件容差的最坏组合下验证。

公式只能把方案带到正确的数量级。最终是否可靠，必须由数据手册和样机测试共同证明。

## 2. 先判断应该使用什么拓扑

| 输入与输出关系 | 常见拓扑 | 特点 |
|---|---|---|
| 输入始终高于输出 | Buck | 效率高、结构简单，本手册重点 |
| 输入始终低于输出 | Boost | 只能升压，关断时输入可能仍通过电感/二极管连接输出 |
| 输入可能高于或低于输出 | Buck-Boost、四开关 Buck-Boost | 输入范围灵活，但成本和控制复杂度更高 |
| 需要负电压 | 反相 Buck-Boost | 输出地与输入地关系需特别处理 |
| 需要电气隔离 | Flyback、Forward、LLC 等 | 需要变压器、安规间距和隔离反馈 |

如果 `VIN` 只是略高于 `VOUT`，还要检查 Buck 的最大占空比、MOS 导通压降和最小关断时间。不能因为理论上 `VIN > VOUT` 就直接认为一定能稳压。

## 3. 新项目必须先填写的设计输入

### 3.1 电气条件

| 项目 | 符号 | 必须填写的内容 |
|---|---:|---|
| 输入最低电压 | `VIN,min` | 包含电源容差、线损、连接器压降和纹波谷值 |
| 输入标称电压 | `VIN,typ` | 常态工作点 |
| 输入最高电压 | `VIN,max` | 包含充电、浪涌、热插拔和纹波峰值 |
| 输出电压 | `VOUT` | 标称值及允许误差 |
| 平均负载 | `IOUT,avg` | 用于平均损耗和常态温升 |
| 最大连续负载 | `IOUT,max` | 用于电感、电容、限流和热设计 |
| 瞬态峰值负载 | `IOUT,pk` | 峰值大小、持续时间和重复周期 |
| 允许稳态纹波 | `ΔVOUT` | 明确带宽，例如 20 MHz 限带 |
| 允许负载瞬态 | `ΔVtransient` | 负载阶跃时允许跌落和过冲 |
| 环境温度 | `TA` | 最低、常态和最高温度 |

### 3.2 系统条件

- 是否要求轻载高效率？
- 是否允许轻载跳脉冲或突发模式？
- 是否给 ADC、DAC、PLL、运放或射频电路供电？
- 是否有严格的 EMI、音频噪声或传导骚扰要求？
- 是否需要软启动、跟踪、同步、PG、可调限流或输出放电？
- 输入来自电池、USB、适配器、背板还是长线缆？
- 输出是否可能被外部电源反向灌电？
- 上电和掉电顺序是否受限制？

> **经验：**平均电流不能代替最大电流。平均电流主要用于效率和温升；电感峰值、电容 RMS、负载阶跃和保护必须按最大电流核算。

## 4. 阅读 DC-DC 数据手册时应提取什么

### 4.1 输入与输出边界

- 推荐工作输入范围，而不是绝对最大额定值。
- UVLO 开启阈值、关闭阈值和迟滞。
- 输出电压范围及反馈基准精度。
- 最大连续输出电流和峰值限流。
- 最大占空比或最低输入输出压差。

### 4.2 开关与控制参数

- 固定频率还是外部电阻可调频率。
- 开关频率容差。
- 最小导通时间 `tON,min`。
- 最小关断时间 `tOFF,min`。
- 控制方式：峰值电流模式、谷值电流模式、恒定导通时间、迟滞控制或电压模式。
- 轻载模式：强制 PWM、PFM、跳脉冲、二极管模拟。
- 是否支持外部同步。

### 4.3 功率与保护参数

- 高侧和低侧 MOS 的 `RDS(on)`。
- 高侧/低侧限流阈值及最小保证值。
- 短路保护形式：折返、打嗝、恒流或锁存。
- 软启动时间。
- 过温保护和恢复方式。
- 输入过压、输出过压和反向电流能力。

### 4.4 外围元件限制

- 推荐电感范围及电感选择公式。
- 输入、输出电容的最小值、最大值和 ESR 范围。
- 内部补偿还是外部补偿。
- 推荐 PCB 布局和评估板 BOM。
- Bootstrap 电容、补偿网络、频率电阻的推荐值。

> **禁止混淆：**“绝对最大额定值”只表示器件不应损坏的边界，不代表能够正常工作，更不代表适合长期量产运行。

## 5. Buck 的基础关系

### 5.1 理想占空比

连续导通模式下，理想 Buck 的占空比近似为：

```text
D ≈ VOUT / VIN
```

实际占空比还要补偿 MOS、电感 DCR、走线和采样路径的压降。

同步 Buck 可用下式粗略估算满载实际占空比：

```text
Dreal ≈ (VOUT + IOUT × RLS) / (VIN - IOUT × RHS + IOUT × RLS)
```

其中：

- `RHS`：高侧 MOS 导通电阻。
- `RLS`：低侧 MOS 导通电阻。

电感 DCR 和 PCB 压降还会进一步增大所需占空比。

### 5.2 电感伏秒平衡

高侧导通时：

```text
VL,on ≈ VIN - VOUT
```

低侧导通时：

```text
VL,off ≈ -VOUT
```

稳态下一个周期的电感平均电压为零，这是多数 Buck 计算公式的基础。

## 6. 开关频率怎么选择

### 6.1 高频的优点

- 电感和电容可以更小。
- 相同感量下电感纹波更低。
- 控制环路可能获得更快的瞬态响应。
- 开关频率更容易避开某些低频敏感区。

### 6.2 高频的代价

- MOS 开关损耗和驱动损耗增大。
- 电感磁芯损耗增大。
- EMI、开关尖峰和布局难度增加。
- 最小导通/关断时间限制更容易被触发。

### 6.3 一般经验

| 目标 | 常见选择倾向 |
|---|---|
| 高效率、空间不紧张 | 较低频率、较大电感 |
| 小型化 | 较高频率、较小电感 |
| 低纹波模拟电源 | 中等频率、较大电感，必要时后接滤波/LDO |
| 宽输入范围 | 优先保证最小导通/关断时间，而不是盲目提高频率 |

### 6.4 最小导通和关断时间检查

```text
tON  = D / fSW
tOFF = (1 - D) / fSW
```

必须满足：

```text
tON  ≥ tON,min
tOFF ≥ tOFF,min
```

考虑频率最高偏差后，编程频率上限近似为：

```text
fSW,set ≤ Dmin / [tON,min × (1 + Tolf)]

fSW,set ≤ (1 - Dmax) / [tOFF,min × (1 + Tolf)]
```

- 在 `VIN,max` 检查最小导通时间。
- 在 `VIN,min`、满载和最大占空比时检查最小关断时间。
- 应使用包含导通损耗的实际占空比，而不是只用理想值。

## 7. 电感计算与选型

### 7.1 电感纹波电流

理想 Buck 在 CCM 下：

```text
ΔIL = VOUT × (VIN - VOUT) / (VIN × L × fSW)
```

也可以写成：

```text
ΔIL = VOUT × (1 - D) / (L × fSW)
```

因此：

```text
L = VOUT × (VIN - VOUT) / (VIN × fSW × ΔIL)
```

### 7.2 纹波比例怎么定

定义：

```text
r = ΔIL / IOUT,max
```

常见初选范围：

| 纹波比例 | 特点 |
|---:|---|
| 10%~20% | 纹波低，但电感较大、动态可能较慢 |
| 20%~40% | 常见均衡范围 |
| 40%~60% | 电感较小，但峰值、损耗和输出纹波增加 |

最终仍应优先采用芯片数据手册的推荐范围。

### 7.3 应在哪个输入电压计算纹波

对固定输出 Buck，理想纹波项为：

```text
ΔIL = [VOUT / (L × fSW)] × (1 - VOUT / VIN)
```

因此在其他条件相同时，输入电压越高，纹波通常越大。宽输入范围设计应在 `VIN,max` 检查最大纹波和峰值电流。

### 7.4 峰值和 RMS 电流

```text
IL,PK     = IOUT,max + ΔIL / 2
IL,VALLEY = IOUT - ΔIL / 2
IL,RMS    ≈ √(IOUT² + ΔIL² / 12)
```

### 7.5 CCM 与 DCM 边界

当电感谷值下降到零时进入临界导通：

```text
IOUT,critical ≈ ΔIL / 2
```

低于该负载后，控制器可能进入 DCM、PFM 或跳脉冲模式，具体取决于芯片控制策略。

### 7.6 电感选型必须检查

- 标称感量和容差。
- 直流偏置下的感量下降。
- 饱和电流 `Isat`。
- 温升电流 `Irms`。
- DCR 和铜损。
- 开关频率下的磁芯损耗。
- 屏蔽结构和漏磁。
- 工作温度范围。

正常工作最低要求：

```text
Isat > IL,PK
```

建议再留 20%~50% 的正常工作裕量。如果芯片短路限流远高于额定输出电流，还要决定是否要求电感在故障期间也不深度饱和。

电感铜损近似为：

```text
PL,Cu = IL,RMS² × DCR
```

磁芯损耗不能只靠简单公式准确得到，应使用电感厂商给出的频率、纹波和温升曲线。

## 8. 输入电容计算与选型

### 8.1 输入电容 RMS 电流

理想 Buck 的输入电容 RMS 电流近似为：

```text
ICIN,RMS ≈ IOUT × √[D × (1 - D)]
```

当 `D=0.5` 时最严重：

```text
ICIN,RMS,max ≈ IOUT / 2
```

### 8.2 输入电压纹波

忽略 ESR、ESL 和输入源阻抗时：

```text
ΔVIN,C ≈ IOUT × D × (1 - D) / (fSW × CIN)
```

实际输入纹波还包括：

```text
ΔVIN ≈ ΔVIN,C + Ipulse × ESR + (ΔI / Δt) × ESL
```

### 8.3 输入电容选型原则

- 高频陶瓷电容必须贴近芯片 `VIN-GND`。
- 使用 X7R 或 X5R，避免 Y5V、Z5U。
- 按实际直流偏压后的有效容量计算。
- 检查 RMS 电流、温升和封装机械可靠性。
- 多颗小电容并联通常比单颗大电容拥有更低 ESL。
- 输入线长或上游阻抗高时，在接口处增加电解或固态储能电容。

### 8.4 MLCC 直流偏压降额

陶瓷电容的标称容量不等于工作容量。有效容量受以下因素影响：

- 电介质类型。
- 额定电压与实际偏压比例。
- 封装尺寸。
- 温度。
- 制造商和具体料号。

例如标称 `10 µF/6.3 V` 的小封装 MLCC，在 5 V 偏压下可能只剩几 µF。设计时应查看具体料号的 DC Bias 曲线。

### 8.5 热插拔和输入振铃

长线缆、低 ESR 陶瓷电容和电源热插拔可能形成高 Q 值 LC 振铃，使芯片输入瞬间超过额定值。

可考虑：

- 有一定 ESR 的电解/固态电容。
- 串联阻尼、电阻或磁珠。
- TVS。
- 热插拔控制器或浪涌限制。

不能只因为稳态输入是安全的，就忽略插拔瞬间的过压。

## 9. 输出电容计算与选型

### 9.1 稳态纹波

CCM 下，输出电压纹波近似为：

```text
ΔVOUT ≈ ΔIL / (8 × fSW × COUT) + ΔIL × ESR
```

该公式主要描述低频三角纹波。高频尖峰通常由以下因素决定：

- 输出电容 ESL。
- PCB 回路寄生电感。
- LX 振铃。
- 地弹跳。
- 示波器探头接地回路。

### 9.2 负载瞬态

负载突然增加时，在控制环路做出响应前，输出电容承担电流差：

```text
COUT ≥ ΔILOAD × Δtresponse / ΔVallow
```

还要加入 ESR 引起的瞬时台阶：

```text
ΔVESR = ΔILOAD × ESR
```

因此负载阶跃的初始压降通常由 ESR 决定，随后斜坡部分由电容量决定，后续恢复由控制环路决定。

### 9.3 输出电容过大有什么影响

优点：

- 稳态纹波减小。
- 负载突增时跌落减小。
- 负载突减时过冲通常减小。

代价：

- 启动充电电流增大。
- 启动时间可能变长。
- 可能触发限流、打嗝或输入电源限流。
- 控制环路带宽下降，恢复速度可能变慢。
- 内部补偿芯片可能超出稳定电容范围。
- 掉电后输出保持时间和储能增加。

软启动期间的平均电容充电电流近似为：

```text
ICOUT,start ≈ COUT × VOUT / tSS
```

启动时总需求近似为：

```text
Istart,total ≈ ICOUT,start + ILOAD,start
```

输出电容储能为：

```text
ECOUT = 0.5 × COUT × VOUT²
```

### 9.4 内部补偿与输出电容范围

如果芯片采用内部补偿，不能认为输出电容越大越好。必须检查：

- 数据手册推荐的最小/最大有效容量。
- 允许的 ESR 范围。
- 评估板使用的电感和电容组合。
- 负载阶跃波形是否存在持续振铃。

如果没有给出明确最大值，大幅偏离评估板配置时必须做环路或阶跃验证。

## 10. 反馈分压与输出精度

多数可调 Buck 使用：

```text
VOUT = VREF × (1 + RTOP / RBOTTOM)
```

因此：

```text
RTOP = RBOTTOM × (VOUT / VREF - 1)
```

### 10.1 电阻值怎么选

反馈电流：

```text
IFB,divider = VOUT / (RTOP + RBOTTOM)
```

- 电阻过小：静态损耗增加。
- 电阻过大：更容易受 FB 偏置电流、漏电、污染和噪声影响。
- 常见反馈电流在数 µA 到数十 µA，但应以芯片数据手册为准。

### 10.2 输出误差来源

- 反馈基准误差。
- 上、下分压电阻误差。
- FB 输入偏置电流。
- 线路压降和取样位置。
- 温漂。
- 负载调整率和输入调整率。

不要只按典型 `VREF` 计算。量产设计应使用最小/最大基准、电阻公差和温漂进行最坏值分析。

### 10.3 FB 布局

- 从输出电容正端进行 Kelvin 取样。
- 分压电阻靠近 FB 引脚。
- FB 走线远离 LX、电感、Bootstrap 和时钟线。
- 分压下端接安静地，不要经过大电流回流路径。
- 可选前馈电容必须按数据手册计算，不能随意添加。

## 11. 控制环路与稳定性

### 11.1 LC 双极点

输出 LC 的谐振频率为：

```text
fLC = 1 / [2 × π × √(L × C)]
```

输出电容 ESR 零点为：

```text
fESR = 1 / (2 × π × ESR × C)
```

### 11.2 为什么不能随意改变 L 和 C

改变电感或输出电容会改变：

- 功率级极点和零点。
- 环路交越频率。
- 相位裕量。
- 负载瞬态响应。
- 启动行为。

内部补偿器件尤其依赖厂家规定的 L、C 和 ESR 范围。

### 11.3 稳定性验证方法

优先级从低成本到高精度：

1. 观察负载阶跃后的振铃次数和衰减速度。
2. 改变输入电压、输出电容和负载，重复负载阶跃。
3. 使用频率响应分析仪测量环路增益和相位。

常见经验目标：

- 相位裕量通常希望大于约 45°，更稳妥可目标 50°~60°。
- 增益裕量通常希望大于约 10 dB。
- 交越频率通常明显低于开关频率，具体比例取决于控制架构和厂家设计。

这些只是经验目标，最终以芯片厂家建议和系统动态要求为准。

## 12. 效率、损耗和温升

### 12.1 基础关系

```text
POUT = VOUT × IOUT
PIN  = POUT / η
PLOSS = PIN - POUT
IIN,avg ≈ VOUT × IOUT / (VIN × η)
```

### 12.2 同步 Buck MOS 导通损耗

```text
PMOS,cond ≈ IOUT² × [D × RHS + (1 - D) × RLS]
```

### 12.3 开关损耗粗估

```text
PSW ≈ 0.5 × VIN × IOUT × (tr + tf) × fSW
```

这是简化估算，未包含寄生电容、驱动和反向恢复等全部损耗。

### 12.4 非同步 Buck 二极管损耗

```text
PD ≈ VF × IOUT × (1 - D)
```

### 12.5 其他损耗

- 电感铜损：`IL,RMS² × DCR`。
- 电感磁芯损耗。
- 输入/输出电容 ESR 损耗。
- 栅极驱动损耗。
- 控制器静态功耗。
- PCB 铜箔和连接器损耗。

### 12.6 温升估算

```text
TJ ≈ TA + PIC × θJA
```

数据手册 `θJA` 来自特定测试板，只适合早期估算。真实温升取决于：

- PCB 层数和铜面积。
- 热过孔。
- 封装焊盘。
- 风速和外壳。
- 周围热源。

最终必须在最高环境温度和最大负载下测量热稳定温度。

## 13. PCB 布局：先画电流回路，再放器件

### 13.1 最高优先级：输入高 di/dt 回路

同步 Buck 的关键回路是：

```text
CIN+ → 高侧MOS → LX → 低侧MOS → GND → CIN-
```

这个回路必须尽量小。输入陶瓷电容应直接贴在芯片 `VIN` 和功率 `GND` 附近。

### 13.2 第二优先级：输出功率回路

```text
LX → 电感 → COUT+ → 负载 → GND → 低侧MOS
```

电感、输出电容和芯片之间的功率走线应短、宽、连续。

### 13.3 LX 节点

- 铜皮只做到满足载流和散热。
- 不要在 LX 下方或附近走 FB、模拟信号和时钟。
- 不要让大面积 LX 铜皮成为天线。
- Bootstrap 电容紧贴 BS-LX 引脚。

### 13.4 地平面

- 优先使用连续地平面。
- 不要为了“数字地/模拟地”随意切割高速信号参考平面。
- 通过元件布局控制功率回流路径。
- 反馈分压下端和敏感模拟回路连接到安静区域。

### 13.5 反馈取样

```text
电感输出 → 输出电容正端 → 反馈分压 → FB
```

不要从电感前端、远端负载大电流路径或噪声节点取样。

## 14. EMI、振铃与吸收网络

### 14.1 常见噪声来源

- LX 高 `dv/dt`。
- 输入回路高 `di/dt`。
- 电感漏磁。
- MOS 开关与寄生 LC 振铃。
- 二极管反向恢复。
- PCB 回路面积过大。

### 14.2 优先处理顺序

1. 先缩小关键回路和 LX 面积。
2. 确保输入陶瓷电容位置正确。
3. 使用屏蔽电感。
4. 检查栅极驱动、Bootstrap 和地回路。
5. 最后再评估 RC Snubber、磁珠或输入滤波。

### 14.3 RC Snubber

Snubber 可以降低振铃和 EMI，但会增加损耗。其参数应基于实测振铃频率和寄生参数确定，不建议照搬固定值。

### 14.4 输入 π 滤波器的风险

Buck 在闭环下近似恒功率负载，其小信号输入阻抗可能表现为负阻特性：

```text
RIN,incremental ≈ -(VIN² / PIN)
```

高 Q 输入滤波器可能与变换器相互作用，引起低频振荡。输入滤波器应加入阻尼，并验证输入端和输出端的动态响应。

## 15. 如何正确测量纹波

### 15.1 错误方法

- 使用长鳄鱼夹接地线。
- 在距离输出电容很远的位置测量。
- 探头环路靠近电感和 LX。
- 只看自动测量数值，不观察波形结构。

长接地线会拾取磁场和电场，把辐射噪声误认为电源纹波。

### 15.2 推荐方法

- 探头直接跨接输出电容两端。
- 使用接地弹簧或同轴短接法。
- 同时保存 20 MHz 限带和全带宽结果。
- 分别测试空载、轻载、平均负载和最大负载。
- 在 `VIN,min`、`VIN,max` 和最高温度下测试。

### 15.3 如何识别波形

| 波形特征 | 常见原因 |
|---|---|
| 与开关周期一致的三角/锯齿纹波 | 电感纹波、电容容量或 ESR |
| 很窄的高频尖峰 | ESL、布局、LX 振铃或测量回路 |
| 低频成组突发 | PFM、跳脉冲或轻载模式 |
| 持续低频振荡 | 环路不稳定、输入滤波互动或输入源阻抗过高 |
| 负载变化时出现大幅凹陷 | 输出电容不足、环路慢或进入限流 |

## 16. 启动、关断、时序与反向电流

### 16.1 启动必须检查

- 输入电源是否限流。
- 输出电容充电电流。
- 启动时负载是否已经开启。
- 软启动是否可调。
- 是否出现输出过冲或反复打嗝。

### 16.2 EN 引脚

- 不允许悬空，除非数据手册明确允许。
- 检查高低阈值、迟滞和最大耐压。
- 分压使能时考虑输入容差和漏电。
- 时序要求高时使用电源监控或逻辑控制。

### 16.3 输出预偏置

如果启动前输出已被外部电源抬高，需要确认芯片是否支持预偏置启动。否则可能出现放电、反向电流或启动异常。

### 16.4 掉电和反灌

同步 Buck 可能存在输出向输入反向导通的路径，具体取决于控制器结构。需要检查：

- 输入掉电但输出由其他电源维持。
- 多路电源并联或时序交叉。
- 输出大电容向输入放电。
- 芯片是否允许反向电流。

必要时增加负载开关、理想二极管或防反灌器件。

## 17. 数字电源与模拟低噪声电源

典型结构：

```text
                           ┌→ 数字电源
DC-DC 主输出 ──────────────┤
                           └→ 磁珠/小电阻 → LDO → 模拟电源
```

### 17.1 不加 LDO 时

- 数字和模拟支路分别布线。
- 模拟支路可串磁珠或小电阻。
- 磁珠后放本地陶瓷电容。
- 每个模拟芯片电源脚放 `100 nF`，必要时增加 `1 µF`。
- 保持连续地平面，用回流路径控制噪声。

### 17.2 加 LDO 时

必须满足：

```text
VDC-DC,min ≥ VLDO,out,max + Vdropout,max + Vripple,margin + Vtrace,drop
```

接近 dropout 时，即使 LDO 仍有输出，PSRR 也可能明显下降。

选择 LDO 时应看：

- 目标负载下的最大 dropout，而不是典型满载宣传值。
- DC-DC 开关频率处的 PSRR。
- 输出噪声。
- 允许的输出电容和 ESR。
- 启动、关断和反向电流行为。

如果 LDO 输出为 3.3 V，DC-DC 就不能仍设为 3.3 V；通常应根据负载和 LDO 特性设为约 3.5~3.8 V。

## 18. 元件取值变化的经验总结

### 18.1 电感变大

- 电感纹波减小。
- 峰值电流下降。
- 输出纹波通常减小。
- 电感尺寸、DCR 或成本可能增加。
- 负载瞬态响应可能变慢。
- LC 谐振点下降，可能影响环路。

### 18.2 电感变小

- 电感纹波和峰值电流增加。
- 电感可更小。
- 磁芯损耗、MOS RMS 电流和输出纹波可能增加。
- 可能更早进入 DCM。

### 18.3 开关频率升高

- 相同纹波所需电感减小。
- 开关损耗和 EMI 增加。
- 更容易违反最小导通/关断时间。

### 18.4 输入电容增大

- 输入纹波和线缆瞬态通常改善。
- 热插拔浪涌增大。
- 与输入线缆形成的 LC 振铃可能更明显。

### 18.5 输出电容增大

- 输出纹波和负载瞬态通常改善。
- 启动电流增大。
- 环路变慢，可能影响稳定性。
- 掉电保持和反灌能量增加。

## 22. 完整通用算例：4.5 V → 3.3 V / 1 A

### 22.1 已知条件

| 项目 | 数值 |
|---|---:|
| 输入 | 4.5 V |
| 输出 | 3.3 V |
| 最大负载 | 1 A |
| 平均负载 | 0.5 A |
| 目标频率 | 1 MHz |
| 目标纹波比例 | 约 25% |

### 22.2 理想占空比

```text
D = 3.3 / 4.5 = 0.733
```

### 22.3 目标电感

取：

```text
ΔIL = 0.25 A
```

则：

```text
L = 3.3 × (4.5 - 3.3) / (4.5 × 1 MHz × 0.25 A)
  ≈ 3.52 µH
```

可以选择 `3.3 µH` 或 `4.7 µH`。

### 22.4 使用 4.7 µH、1 MHz

```text
ΔIL ≈ 3.3 × (4.5 - 3.3) / (4.5 × 4.7 µH × 1 MHz)
    ≈ 0.187 A
```

```text
IL,PK ≈ 1 + 0.187 / 2
      ≈ 1.094 A
```

平均负载 0.5 A 时，电感电流大约为：

```text
电感电流范围 ≈ 0.406 A ～ 0.594 A
```

### 22.5 输入电容

```text
ICIN,RMS ≈ 1 × √[0.733 × (1 - 0.733)]
         ≈ 0.442 A
```

若有效输入容量为 `20 µF`：

```text
ΔVIN,C ≈ 1 × 0.733 × 0.267 / (1 MHz × 20 µF)
       ≈ 9.8 mV
```

可采用：

```text
2 × 10 µF / 10 V X7R + 100 nF
```

### 22.6 输出电容

若有效输出容量为 `44 µF`、总 ESR 约 `5 mΩ`：

```text
ΔVC ≈ 0.187 / (8 × 1 MHz × 44 µF)
    ≈ 0.53 mV
```

```text
ΔVESR ≈ 0.187 × 5 mΩ
      ≈ 0.94 mV
```

理论低频纹波约 `1.5 mV`，实际还应加入 ESL、布局和开关尖峰。

可采用：

```text
2 × 22 µF / 10 V X7R + 100 nF
```

### 22.7 如果使用 2.2 µH

为了维持约 `0.267 A` 的电感纹波：

```text
fSW ≈ 0.88 / (2.2 × 0.267)
    ≈ 1.5 MHz
```

因此 `2.2 µH + 约1.5 MHz` 与 `3.3 µH + 1 MHz` 的电感纹波接近，但开关损耗和 EMI 通常更高。

### 22.8 这个算例最容易忽略的问题

`4.5 V` 如果正好是芯片推荐输入下限，那么它必须是芯片引脚处的最低瞬时电压，而不能只是电源适配器或连接器入口处的标称值。

```text
fSW(kHz) = 100000 / RFS(kΩ)
```

| 频率 | RFS |
|---:|---:|
| 500 kHz | 200 kΩ |
| 700 kHz | 约 143 kΩ |

## 24. 工程单位快速计算公式

本节公式已经把常用单位换算包含在内，适合直接放进计算器或电子表格。

### 24.1 电感纹波

输入单位：

- 电压：V
- 电感：µH
- 频率：MHz
- 结果：A

```text
ΔIL(A) = VOUT × (VIN - VOUT) / [VIN × L(µH) × fSW(MHz)]
```

反算电感：

```text
L(µH) = VOUT × (VIN - VOUT) / [VIN × fSW(MHz) × ΔIL(A)]
```

### 24.2 输出电容的容性纹波

输入单位：

- `ΔIL`：A
- `fSW`：MHz
- `COUT`：µF
- 结果：mV

```text
ΔVCOUT(mV) = 125 × ΔIL(A) / [fSW(MHz) × COUT(µF)]
```

ESR 纹波：

```text
ΔVESR(mV) = ΔIL(A) × ESR(mΩ)
```

总低频纹波粗估：

```text
ΔVOUT(mV) ≈ ΔVCOUT(mV) + ΔVESR(mV)
```

### 24.3 输入电容纹波

```text
ΔVIN(mV) ≈ 1000 × IOUT(A) × D × (1 - D)
            / [fSW(MHz) × CIN(µF)]
```

### 24.4 负载阶跃所需电容

输入单位：

- 电流阶跃：A
- 响应时间：µs
- 允许电压变化：mV
- 结果：µF

```text
COUT(µF) ≥ 1000 × ΔILOAD(A) × Δt(µs) / ΔVallow(mV)
```

例如 `0.5 A` 阶跃、响应时间 `5 µs`、允许跌落 `50 mV`：

```text
COUT ≥ 1000 × 0.5 × 5 / 50 = 50 µF
```

### 24.5 软启动充电电流

```text
ICOUT,start(A) = COUT(µF) × VOUT(V) / [1000 × tSS(ms)]
```

### 24.6 储能

电感峰值储能：

```text
EL(µJ) = 0.5 × L(µH) × IL,PK²(A)
```

输出电容储能：

```text
ECOUT(µJ) = 0.5 × COUT(µF) × VOUT²(V)
```

### 24.7 MOS 开关损耗快速估算

输入单位：

- 电压：V
- 电流：A
- 上升和下降时间：ns
- 频率：MHz
- 结果：mW

```text
PSW(mW) ≈ 0.5 × VIN × IOUT × (tr + tf)(ns) × fSW(MHz)
```

该式只做数量级估算，不包括 COSS、栅极驱动、反向恢复和寄生振铃损耗。

### 24.8 温升

```text
ΔT(°C) ≈ PLOSS(W) × θJA(°C/W)
```

## 25. CCM、DCM、PFM 与强制 PWM

### 25.1 CCM：连续导通模式

整个开关周期内电感电流都大于零。

特点：

- 计算关系最接近经典 Buck 公式。
- 纹波频率固定。
- 负载动态较容易预测。
- 中高负载时效率通常较高。

### 25.2 DCM：断续导通模式

每个周期内电感电流会下降到零，并保持一段时间。

特点：

- 轻载开关损耗可以降低。
- 占空比关系不再简单等于 `VOUT/VIN`。
- 纹波和动态响应与 CCM 不同。
- 可能产生更明显的低频调制或可闻噪声。

CCM/DCM 的理想临界负载为：

```text
IOUT,critical ≈ ΔIL / 2
```

### 25.3 PFM、Pulse Skip 和 Burst

| 模式 | 优点 | 代价 | 适用场景 |
|---|---|---|---|
| PFM | 轻载效率高 | 频率变化、噪声频谱扩散 | 电池设备、数字负载 |
| Pulse Skip | 实现简单、轻载省电 | 成组脉冲、低频纹波 | 一般数字系统 |
| Burst | 极低静态功耗 | 低频包络明显 | 待机功耗优先 |
| 强制 PWM | 固定频率、频谱可控 | 轻载效率下降，可能允许反向电流 | 模拟、射频、音频敏感系统 |

### 25.4 峰值电流模式的占空比问题

传统峰值电流模式在占空比超过 50% 时可能出现次谐波振荡，需要斜坡补偿。现代集成芯片通常已经内部实现，但斜坡补偿会影响电流环增益和瞬态性能。

不能因为芯片“内部补偿”就忽略超过 50% 占空比时的数据手册限制。

### 25.5 恒定导通时间控制

恒定导通时间或迟滞控制器往往要求输出端存在足够的纹波供比较器判定。全部使用超低 ESR 陶瓷电容时，某些芯片可能需要纹波注入网络。

换芯片时必须确认：

- 是否要求最小 ESR。
- 是否要求纹波注入。
- 开关频率是否随输入和负载变化。

## 26. 频率与电感的联合选择

不能先孤立决定电感，再单独决定频率。应将二者作为组合评估。

### 26.1 固定目标纹波时

由电感公式可知：

```text
L × fSW ≈ 常数
```

因此：

- 电感减半，频率约需加倍，才能维持相同电流纹波。
- 电感加倍，频率可约减半，但输出电容的纹波积分时间会增加。

### 26.2 组合比较表

| 组合 | 电感体积 | 开关损耗 | 电感纹波 | 动态响应 | EMI 难度 |
|---|---|---|---|---|---|
| 小 L + 高频 | 小 | 高 | 可保持不变 | 通常较快 | 高 |
| 大 L + 低频 | 大 | 低 | 可保持不变 | 通常较慢 | 较低 |
| 大 L + 高频 | 大 | 高 | 最低 | 不一定最快 | 高 |
| 小 L + 低频 | 小 | 低 | 最大 | 峰值电流高 | 中等 |

### 26.3 实际选择流程

1. 根据效率、尺寸和 EMI 初选频率。
2. 以 `20%~40% IOUT,max` 为目标计算电感。
3. 选择标准感量，并用感量容差和频率最低偏差重算最大纹波。
4. 用输入最高值重算最大纹波。
5. 用峰值负载计算 `IL,PK`。
6. 检查电感在高温和直流偏置下的实际感量。
7. 检查最小导通/关断时间。
8. 比较至少两组 L/fSW 方案的效率和温升。

## 27. 最坏情况与容差计算

### 27.1 为什么不能只算典型值

同时影响结果的变量包括：

- 输入电压容差。
- 开关频率容差。
- 电感初始公差和偏置降感。
- 输出电容直流偏压降额。
- MOS 导通电阻温升。
- 反馈基准和电阻公差。
- 环境温度。

典型样机正常，不代表批量、低温启动或高温满载正常。

### 27.2 最大电感纹波角点

通常使用：

```text
VIN      = VIN,max
L        = Lmin，在直流偏置和高温下的实际值
fSW      = fSW,min
VOUT     = 可能的最高输出值
```

然后重新计算：

```text
ΔIL,max = VOUT,max × (VIN,max - VOUT,max)
          / (VIN,max × Lmin × fSW,min)
```

### 27.3 最大峰值电流

```text
IL,PK,max = IOUT,max + ΔIL,max / 2
```

必须满足：

```text
IL,PK,max < 芯片最小保证限流值
IL,PK,max < 电感允许峰值
```

不能拿芯片限流的典型值做保证。

### 27.4 反馈最坏误差

```text
VOUT,max = VREF,max × [1 + RTOP,max / RBOTTOM,min]

VOUT,min = VREF,min × [1 + RTOP,min / RBOTTOM,max]
```

还应叠加：

- FB 偏置电流。
- 负载调整率。
- 输入调整率。
- PCB 取样压降。
- 电阻温漂。

### 27.5 输入最低角点

```text
VIN,pin,min = VIN,source,min
              - 线缆压降
              - 连接器压降
              - 保护器件压降
              - 输入纹波谷值
```

该值必须高于芯片推荐输入下限，并满足满载所需占空比。

### 27.6 建议的角点矩阵

| 测试角点 | 输入 | 负载 | 温度 | 重点检查 |
|---|---|---|---|---|
| A | 最低 | 最大 | 高温 | 掉压、占空比、限流 |
| B | 最高 | 最大 | 高温 | 电感纹波、峰值、温升 |
| C | 最低 | 启动负载 | 低温 | UVLO、启动和输入源 |
| D | 最高 | 轻载 | 低温 | PFM、过冲、EMI |
| E | 标称 | 最大阶跃 | 常温 | 动态响应和稳定性 |

## 28. 电感和电容料号判读细化

### 28.1 电感的 Isat 定义并不统一

不同厂商可能把 Isat 定义为感量下降：

- 10%。
- 20%。
- 30%。

两个都标称 `Isat=3 A` 的电感，实际曲线可能完全不同。选型时应查看 `L-I` 曲线，而不是只看表格中的一个数字。

### 28.2 温升电流也不统一

温升电流可能按：

- 温升 20°C。
- 温升 40°C。
- 温升 50°C。

测试 PCB、铜面积和自然风条件也不同。因此必须确认定义。

### 28.3 铜阻的温度变化

铜的温度系数约为 `0.393%/°C`。粗略估算：

```text
DCRhot ≈ DCR25 × [1 + 0.00393 × (Thot - 25)]
```

例如电感从 25°C 升到 100°C，DCR 大约增加 29%。

### 28.4 MLCC 需要同时考虑

- DC Bias。
- 温度特性。
- 老化。
- AC 电压幅度。
- 焊接应力和板弯裂纹。
- 封装尺寸与额定电压。

建议在 BOM 中记录“最小有效容量”，而不是只记录标称容量。

### 28.5 电解和固态电容

需要检查：

- 额定纹波电流。
- ESR 随温度和频率变化。
- 寿命与热点温度。
- 极性。
- 浪涌电压。

电解电容寿命对温度非常敏感，不能只满足容量和耐压。

### 28.6 电容耐压经验

耐压降额没有唯一比例，应遵循公司规范和器件技术。一般原则：

- 输入存在热插拔、浪涌时必须按峰值而非标称值选耐压。
- MLCC 额定电压越接近工作电压，掉容通常越严重。
- 输出电容即使电压较低，也要考虑过冲和反灌。

## 29. 控制环路与补偿进一步说明

### 29.1 先判断内部还是外部补偿

内部补偿：

- 设计简单。
- 可调整的 L/C 范围有限。
- 应尽量遵循推荐外围值。

外部补偿：

- 可针对负载和电容优化。
- 需要理解功率级传递函数。
- 最终应测量 Bode 图。

### 29.2 电压模式与电流模式差异

| 控制方式 | 功率级特征 | 补偿倾向 |
|---|---|---|
| 电压模式 | LC 双极点明显，相位下降快 | 常需要 Type III |
| 峰值电流模式 | 电感电流形成内环，外环近似单极点 | 常使用 Type II |
| COT/迟滞 | 依赖纹波和比较器行为 | 必须按厂家方法 |

### 29.3 常见频率点

```text
fLC  = 1 / [2 × π × √(L × COUT)]
fESR = 1 / (2 × π × ESR × COUT)
fPOUT ≈ 1 / (2 × π × RLOAD × COUT)
```

### 29.4 交越频率经验

交越频率通常应：

- 明显低于开关频率。
- 避开采样和调制限制。
- 不高于芯片数据手册建议。
- 在负载变化后仍保持足够相位裕量。

`fSW/10` 常被用作初步上限概念，但不能把它当成所有芯片的固定设计值。

### 29.5 负载阶跃如何辅助判断稳定性

| 阶跃波形 | 可能含义 |
|---|---|
| 快速恢复、少量过冲 | 相位裕量通常较好 |
| 多周期等幅振铃 | 接近不稳定 |
| 缓慢无振铃恢复 | 带宽偏低或电容很大 |
| 初始台阶很大 | ESR 或走线阻抗较大 |
| 斜坡跌落很大 | 有效电容量不足 |

负载阶跃只能作为间接判断，不能完全替代环路测量。

### 29.6 Bode 测试记录

量产前建议记录：

- 输入电压。
- 负载电流。
- 电感和输出电容实物料号。
- 交越频率。
- 相位裕量。
- 增益裕量。
- 测试注入位置和幅度。

## 30. 开关节点振铃与 RC Snubber 设计

### 30.1 先确认振铃是否真实

使用短地弹簧或高带宽差分探头测量。长地线产生的假振铃不能用 Snubber 解决。

### 30.2 两次测量估算寄生参数

一种常用工程方法：

1. 测量原始振铃频率 `f1`。
2. 在振铃节点并联一个已知测试电容 `Cadd`。
3. 再测新的振铃频率 `f2`。
4. 估算原始寄生电容和寄生电感。

```text
Cpar ≈ Cadd / [(f1 / f2)² - 1]

Lpar ≈ 1 / [(2 × π × f1)² × Cpar]
```

初始 Snubber 参数可取：

```text
Csnub ≈ 1 ～ 3 × Cpar

Rsnub ≈ √(Lpar / Csnub)
```

然后通过实测在振铃、温升和效率之间调整。

### 30.3 Snubber 损耗

粗略估算：

```text
Psnub ≈ Csnub × VSW² × fSW
```

实际损耗还取决于振铃幅度和连接位置。电阻封装必须能够承受脉冲功率与温升。

### 30.4 什么时候不该加 Snubber

- PCB 回路明显过大但还没有改版。
- 输入电容位置错误。
- 测量方法不正确。
- 振铃幅度没有接近器件应力或 EMI 问题并不严重。

Snubber 是优化手段，不是掩盖错误布局的首选方案。

## 31. 输入滤波器与系统稳定性

### 31.1 输入 LC 滤波器为什么会振荡

闭环 DC-DC 在一定频率范围内近似恒功率负载，输入电压下降时会增加输入电流，呈现负增量阻抗。

```text
RIN,incremental ≈ -(VIN² / PIN)
```

如果输入滤波器输出阻抗过高，就可能与变换器形成振荡。

### 31.2 设计原则

- 输入滤波器输出阻抗应显著低于变换器输入阻抗幅值。
- 控制滤波器 Q 值。
- 必要时加入串联阻尼或 RC 阻尼支路。
- 输入滤波器后仍需保留芯片本地陶瓷电容。
- 在输入电压和负载全范围验证。

### 31.3 需要测什么

- 滤波器前后输入纹波。
- 输入电压阶跃响应。
- 最大负载启动。
- 低频振荡和成组脉冲。
- 阻尼器件温升。

### 31.4 磁珠不是理想电感

磁珠阻抗随频率变化，且会受直流偏置影响。应查看：

- 阻抗-频率曲线。
- 电阻性与感性分量。
- 额定电流。
- 直流偏置下阻抗变化。
- DCR 和温升。

## 32. 热设计与效率测试细化

### 32.1 效率测量避免线损误差

推荐四线测量：

- 在板端输入焊盘测 `VIN`。
- 在板端输出焊盘测 `VOUT`。
- 电流表串入对应回路。
- 不要使用电源面板电压代替板端电压。

```text
η = VOUT × IOUT / (VIN × IIN)
```

### 32.2 损耗分解法

1. 先测整机输入和输出功率。
2. 测芯片、电感、MOS、二极管和电容温升。
3. 更换低 DCR 电感对比。
4. 改变频率对比开关损耗。
5. 在相同输出功率下改变输入电压。

判断思路：

- 损耗随电流平方增长明显：导通或 DCR 损耗为主。
- 损耗随频率近似增长：开关或磁芯损耗为主。
- 输入越高损耗越大：高压开关损耗可能占主导。

### 32.3 红外测温注意事项

- 不同材料发射率不同。
- 光亮金属表面读数可能严重偏低。
- 小封装尺寸可能低于热像仪空间分辨率。
- 可使用已知发射率的黑色胶带或涂层辅助比较。
- 精确结温应结合热电偶、器件温度传感或厂家方法。

### 32.4 温度降额

高温下需要重新考虑：

- MOS `RDS(on)` 增大。
- 电感 DCR 增大。
- 限流阈值漂移。
- 电容 ESR 和容量变化。
- PCB 允许温升和外壳内部温度。

## 33. 示波器和实验室测试细化

### 33.1 启动波形建议同时测量

- 通道 1：板端 `VIN`。
- 通道 2：`EN`。
- 通道 3：`VOUT`。
- 通道 4：电感电流或输入电流。

重点观察：

- VIN 是否跌破 UVLO。
- EN 是否抖动。
- VOUT 是否过冲或阶梯式启动。
- 是否触发限流或打嗝。

### 33.2 LX 测量安全

- 普通接地示波器探头的地夹不能接到浮动高侧节点。
- 高压或浮地系统应使用合适额定的差分探头。
- 探头环路尽可能短。
- 确认探头耐压、共模范围和带宽。

### 33.3 负载阶跃设置

测试报告应记录：

- 起始和终止电流。
- 上升/下降时间。
- 重复频率和占空比。
- 负载连接线长度。
- 输出测试点。
- 示波器带宽。

如果电子负载距离板子很远，线缆电感会显著改变阶跃波形。

### 33.4 电流探头

电流探头测到的是所在导线的电流，必须明确测量位置：

- 电感电流。
- 输入源电流。
- 输出负载电流。
- 电容支路电流。

不同位置的波形含义不同。

## 34. 量产降额、DFM 与可靠性

### 34.1 建议建立降额表

| 器件 | 需要降额的参数 |
|---|---|
| IC | 输入电压、输出电流、结温 |
| MOS | VDS、ID、SOA、结温 |
| 电感 | Isat、Irms、温升、DCR |
| MLCC | 耐压、有效容量、机械应力 |
| 电解电容 | 耐压、纹波电流、寿命、温度 |
| 电阻 | 功耗、工作电压、脉冲能力 |
| 二极管 | 反向耐压、平均电流、浪涌、温升 |

具体降额比例应遵循产品等级、公司规范和行业要求，不能用一套比例覆盖所有产品。

### 34.2 PCB 可制造性

- 小封装大容量 MLCC 是否容易板弯开裂。
- 功率器件焊盘散热是否导致立碑或虚焊。
- 裸露焊盘的锡膏开窗比例。
- 热过孔是否吸锡。
- 测试点是否可接触。
- 高电流铜箔和过孔数量是否足够。

### 34.3 BOM 替代料管理

替代料不能只匹配标称参数。至少比较：

- 电感的完整 L-I 曲线、DCR 和损耗。
- MLCC 的 DC Bias 曲线和封装。
- 电容 ESR、纹波电流和寿命。
- MOS 的开关电荷、COSS 和反向恢复。
- IC 的后缀、轻载模式和引脚兼容性。

### 34.4 生产测试建议

- 输出直流值。
- 空载输入电流。
- 指定负载下输出电压。
- EN 开关功能。
- 短路电流或受控过载测试。
- 关键板卡可抽测纹波和频率。

生产测试限值应包含仪器误差、治具线损和温度差异。

### 34.5 常见失效模式

| 失效模式 | 后果 | 设计预防 |
|---|---|---|
| 反馈上拉电阻开路 | 输出可能升高 | OVP、分压布局和可靠焊接 |
| 反馈下拉电阻开路 | 输出行为依芯片而异 | 分析单点失效 |
| 电感饱和 | 电流急升、过热 | Isat裕量和限流验证 |
| 输入 MLCC 开裂短路 | 输入电源短路 | 软端子电容、布局和保险保护 |
| EN 悬空 | 随机启停 | 明确上拉/下拉 |
| 输出反灌 | 芯片或上游受损 | 防反灌设计 |

## 36. 规格书参数如何映射到实际性能

规格书中的参数不是彼此独立的。一个参数通常对应一类实际性能：效率、带载能力、瞬态、纹波、启动、EMI、温升或可靠性。阅读时应先判断“这个参数会在波形或温升上体现什么”，再判断数值是否足够好。

### 36.1 先分清参数的性质

| 参数标注 | 含义 | 设计时怎么用 |
|---|---|---|
| Typical / Typ | 典型值，不保证每颗都达到 | 用于初步估算，不可作为量产边界 |
| Min | 最小保证值 | 计算最坏下限，通常是设计约束 |
| Max | 最大保证值 | 计算最坏上限，通常是设计约束 |
| Recommended Operating | 推荐工作范围 | 正常功能和可靠性有保证的范围 |
| Absolute Maximum | 绝对最大额定值 | 只用于应力检查，不能作为正常工作点 |
| Note / Condition | 测试条件 | 不看条件就无法比较参数 |

例如 SY8263 的高侧限流典型值约 `6.8 A`、最小值约 `4 A`。设计峰值电流时必须使用最小 `4 A` 做保护判断，而不是使用看起来更宽裕的 `6.8 A`。

### 36.2 参数到性能的总览

| 规格书参数 | 主要体现的性能 | 通常影响 |
|---|---|---|
| 输入电压范围 | 能否在整个输入范围稳定工作 | 启动、掉压、UVLO、耐压 |
| 输出电流 | 带载能力 | 负载范围、温升、限流 |
| 峰值限流 | 瞬态和短路保护能力 | 电感峰值、短路、启动 |
| 高/低侧 RDS(on) | 导通损耗 | 效率、温升、压差 |
| 开关频率 | 尺寸、纹波、EMI和开关损耗 | 电感、电容、效率 |
| 频率精度 | 频谱位置和设计一致性 | EMI、滤波、同步 |
| 最小导通/关断时间 | 极端占空比能力 | VIN/VOUT范围、掉压 |
| 反馈基准精度 | 输出 DC 精度 | 负载供电准确性 |
| 负载调整率 | 负载变化造成的 DC 变化 | 输出精度、线损 |
| 线性调整率 | 输入变化造成的 DC 变化 | 输入范围内稳定性 |
| 软启动时间 | 启动冲击和输出过冲 | 大电容、上电时序 |
| 静态电流 | 轻载效率和待机功耗 | 电池续航、空载发热 |
| UVLO | 低输入保护行为 | 棕断、启动失败、掉压 |
| 热关断温度 | 过热保护点 | 安全性，不等于允许工作温度 |
| θJA / θJC | 散热能力 | 结温、连续输出能力 |
| PSRR / 噪声 | 电源干净程度 | 模拟、射频、时钟性能 |

---

### 36.3 输入电压范围：决定能不能正常工作

SY8263 的推荐输入范围为 `4.5~30 V`，这是一个很重要但容易被误读的参数。

#### 它具体体现什么

- 输入低于最小值时，可能不能启动或不能保持调节。
- 输入接近输出时，最大占空比和最小关断时间决定是否仍能保持输出。
- 输入超过推荐范围时，虽然可能没有立即损坏，但功能、效率和寿命不再由厂家保证。

#### 什么数值算好

不能简单说输入范围越宽越好。应看它是否覆盖系统输入，并保留实际裕量：

```text
VIN,pin,min ≥ 推荐输入下限 + 线损裕量 + 纹波谷值裕量
VIN,pin,max ≤ 推荐输入上限 - 浪涌裕量
```

对 SY8263 而言，若系统“标称输入4.5 V”，但线缆、保护器件和纹波会使芯片引脚低到4.35 V，设计实际上已经不满足推荐工作条件。

#### 设计判断

| 情况 | 判断 |
|---|---|
| 输入范围覆盖需求且两端都有≥10%裕量 | 较好 |
| 只在典型电压满足，最低点接近 UVLO | 偏紧，需要实测 |
| 使用绝对最大值作为长期输入 | 不合格 |

---

### 36.4 UVLO：决定低压时是稳压还是关机

UVLO 是欠压锁定。SY8263 数据手册给出的 UVLO 开启阈值约 `4.35 V`，迟滞约 `0.2 V`。

#### 它具体体现什么

- 输入下降时何时关断。
- 输入上升时何时重新启动。
- 电源缓慢下降时是否反复启停。
- 电池或长线供电时是否出现棕断。

#### 什么数值算好

关键不是阈值绝对值高低，而是：

- 阈值容差是否明确。
- 迟滞是否足够避免抖动。
- 启动和关断是否有确定行为。
- 系统是否能在 UVLO 前保存数据或关闭负载。

测试时应慢慢改变输入电压，同时观察 `VIN`、`EN`、`VOUT` 和输入电流。

---

### 36.5 输出电流和峰值限流：决定真正的带载能力

“3 A 输出能力”并不等于任何条件下都能连续输出 3 A。真正的连续能力还受以下因素限制：

- 输入输出压差。
- 开关频率。
- 电感 DCR 和饱和。
- 芯片封装和 PCB 散热。
- 环境温度。
- 输出纹波和瞬态要求。

#### 峰值限流怎么体现性能

峰值限流决定：

- 负载阶跃时能否提供瞬时电流。
- 启动大电容时是否限流。
- 短路时的保护行为。
- 电感峰值的允许上限。

SY8263 的高侧峰值限流最小约 `4 A`、典型约 `6.8 A`。它不是建议的连续输出电流，而是内部保护边界。

#### 什么数值算好

对一个最大1 A的应用：

```text
正常电感峰值应明显低于芯片最小限流值
```

通常希望正常峰值不超过最小限流的 `60%~75%`，给输入波动、瞬态和容差留空间。若芯片标称3 A，但实际在目标温度下只能稳定输出1.5 A，不能把它称为适合3 A连续应用。

---

### 36.6 RDS(on)：主要影响效率、压差和温升

SY8263 高侧/低侧 MOS 的典型 `RDS(on)` 约为 `110/70 mΩ`。

#### 它具体体现什么

- 导通损耗。
- 满载时的芯片温升。
- 输入接近输出时的有效占空比和可调压差。
- 负载变化时的电压损失。

同步 Buck 的粗略导通损耗：

```text
PMOS,cond ≈ IOUT² × [D × RHS + (1 - D) × RLS]
```

#### 什么数值算好

不能只比较室温典型值。应同时查看：

- 规定测试电压。
- 测试温度。
- 高温下的 RDS(on) 增长曲线。
- 高侧和低侧是否分别给出保证值。

经验判断：

| MOS 导通电阻 | 低压大电流 Buck 的评价 |
|---:|---|
| <20 mΩ | 很好，但通常需要更大芯片或外置 MOS |
| 20~60 mΩ | 较好 |
| 60~150 mΩ | 常见、可用，需核算温升 |
| >150 mΩ | 低压大电流时要重点检查效率和热 |

这是系统级经验，不替代具体芯片测试条件。

---

### 36.7 开关频率：不是越高越好

SY8263 的频率可在 `500 kHz~2.5 MHz` 范围内设置。

#### 它具体体现什么

- 频率越高，电感和电容可以减小。
- 频率越高，开关损耗、磁芯损耗和 EMI 通常越大。
- 频率位置影响 EMI 滤波器、近场辐射和系统频谱。
- 频率误差影响滤波器设计和谐波位置。

#### 什么数值算好

性能好坏取决于系统目标：

- 小型化优先：较高频率有优势。
- 低噪声和高效率优先：中低频率通常更容易。
- 需要避开音频或 ADC 采样频段：应看频率和谐波，而非只看频率大小。

对 SY8263 的 `4.5 V → 3.3 V` 算例：

| 组合 | 判断 |
|---|---|
| 4.7 µH + 1 MHz | 纹波较低，开关损耗适中，适合首版 |
| 3.3 µH + 1 MHz | 尺寸与纹波均衡 |
| 2.2 µH + 1.5 MHz | 电感较小，但 EMI、开关损耗和最小关断时间更紧 |
| 2 MHz 以上 | 需重点验证最小关断时间和高温效率 |

---

### 36.8 反馈基准精度：决定输出电压的基础精度

SY8263 的反馈基准典型为 `0.6 V`，给出的范围约为 `0.591~0.609 V`，约等于 ±1.5%。

#### 它具体体现什么

它直接影响无负载和稳态下的输出 DC 电压。即使反馈电阻是理想值，参考电压本身仍会造成误差。

```text
VOUT,max = VREF,max × [1 + RTOP,max / RBOTTOM,min]
VOUT,min = VREF,min × [1 + RTOP,min / RBOTTOM,max]
```

#### 什么数值算好

| 参考精度 | 一般评价 |
|---:|---|
| ±0.5%以内 | 精密数字/模拟电源较好 |
| ±1%以内 | 常见较好水平 |
| ±1.5%~2% | 通用电源可用，需叠加电阻和负载误差 |
| >±3% | 需确认负载是否能接受 |

如果系统需要精确基准，不能只依赖普通 Buck 的反馈基准，应使用独立基准或后级精密稳压。

---

### 36.9 负载调整率和线性调整率：看输入/负载变化时稳不稳

#### 负载调整率

从轻载到满载，输出 DC 电压发生的变化。

```text
Load regulation (%) = 100 × [VOUT(no-load) - VOUT(full-load)] / VOUT(nom)
```

#### 线性调整率

在输入电压变化时，输出 DC 电压发生的变化。

```text
Line regulation (%) = 100 × ΔVOUT / [VOUT × ΔVIN]
```

#### 什么数值算好

| 指标 | 通用电源经验评价 |
|---:|---|
| <0.1% | 较好 |
| 0.1%~0.5% | 常见可用 |
| 0.5%~1% | 需看负载容差 |
| >1% | 对精密模拟电源通常偏差较大 |

必须看测试条件。某些数据手册只在固定输入、固定输出电容和室温下给出典型值。

---

### 36.10 频率精度、纹波和 EMI 的关系

频率精度本身不直接等于低噪声，但它会影响：

- EMI 峰值位置。
- 输入和输出滤波器的衰减点。
- 同步采样系统的拍频。
- 多个开关电源之间的互调。

对于 `fSW=1 MHz、±15%` 的芯片，实际频率可能大约在 `850 kHz~1.15 MHz`。滤波器不能只按一个理想 1 MHz 点计算。

---

### 36.11 最小导通/关断时间：体现极端输入输出比能力

SY8263 的典型数据为最小导通 `80 ns`、最小关断 `120 ns`。

它决定：

- 高输入低输出时能否提供足够小的占空比。
- 低输入高输出时能否提供足够大的占空比。
- 频率提高后是否会丢脉冲或失去稳压。

检查公式：

```text
tON  = D / fSW
tOFF = (1 - D) / fSW
```

什么数值算好，不是看 80 ns 或 120 ns 绝对小不小，而是看设计点距离边界有多远。建议最坏频率、最坏占空比下仍保留至少 `20%~30%` 的时间裕量。

---

### 36.12 软启动时间：体现启动冲击，而不是稳态速度

SY8263 软启动约 `1 ms`。

输出电容充电电流粗估：

```text
ICOUT,start = COUT × VOUT / tSS
```

对大电容或重负载：

- 软启动太短：输入冲击和限流风险大。
- 软启动太长：上电等待时间增加。
- 软启动不能保证一定不反灌，也不能代替输入浪涌控制。

判断启动性能时，必须同时看输出电容、启动负载、输入电源限流和 UVLO。

---

### 36.13 静态电流：体现轻载/待机性能

SY8263 静态电流典型约 `19 µA`，但必须确认测试条件：是否关闭开关、是否包含反馈分压、是否包含外部电阻电流。

#### 什么数值算好

|      静态电流 | 电池/待机系统评价   |
| --------: | ----------- |
|     <1 µA | 极低功耗        |
|   1~10 µA | 很好          |
|  10~50 µA | 常见较好        |
| 50~200 µA | 通用设备可用      |
|   >200 µA | 待机时间敏感时需要关注 |

不能只看控制器静态电流。反馈分压、使能分压、指示灯和后级负载也可能更大。

---

### 36.14 软关断、输出放电和反向电流

规格书如果提供“输出自动放电”，主要体现：

- 关断后输出下降速度。
- 多路电源时序的确定性。
- 后级芯片是否会被残余电压保持在半上电状态。

如果没有自动放电，输出电容可能长时间保持电压。若存在外部电源，还必须检查反向电流路径。

好的设计应明确回答：

- EN 拉低后输出多久降到安全电压？
- 输出被外部电源抬高时是否损坏？
- 输入掉电时输出电容是否向输入端放电？

---

### 36.15 热关断和热阻：体现保护能力，不代表可长期工作

SY8263 热关断温度约 `150°C`，热关断迟滞约 `15°C`，θJA 约 `60.2°C/W`（特定四层板）。

#### 热关断是什么

热关断是最后一道保护，不是正常温度目标。若芯片经常进入热关断，说明功率、布局或散热方案不合格。

#### 什么数值算好

- 热关断温度稳定且有迟滞，避免高频抖动。
- 正常最大负载下结温至少低于保护点 `20~40°C`。
- 对长期运行，尽量让估算结温低于 `100~125°C`，具体取决于产品等级和环境。

#### θJA 如何正确理解

θJA 不是芯片固定属性，强烈依赖：

- PCB 层数。
- 裸露焊盘。
- 铜面积。
- 热过孔。
- 自然对流和外壳。

因此必须按实际 PCB 测试温升，而不是只用数据手册 θJA 得出量产结论。

---

### 36.16 PSRR、输出噪声和纹波：决定模拟电源是否干净

对于数字负载，几 mV 的开关纹波可能完全可接受；对于 ADC、DAC、运放、PLL 或射频，指标可能严格得多。

应区分：

- DC 输出精度。
- 开关频率纹波。
- 高频尖峰。
- 轻载 Burst 包络。
- 低频输入纹波。
- 负载瞬态。
- 频域噪声密度。

### 什么数值算好

没有一个适用于所有系统的“好纹波”。可使用以下工程参考：

| 应用 | 典型关注点 |
|---|---|
| 普通数字 MCU | 稳态几 mV 到几十 mV，重点看复位和负载瞬态 |
| 高速数字/DDR | 重点看瞬态、频谱和电源平面阻抗 |
| 普通运放 | 关注输入噪声、PSRR 和输出摆幅，不只看纹波峰峰值 |
| ADC/DAC 模拟电源 | 常需要后级磁珠、LC 或低噪声 LDO |
| ADC/DAC 参考 | 通常应使用独立基准，不能把普通 Buck 直接当参考 |
| PLL/射频 | 关注开关频率及谐波是否落入敏感带宽 |

SY8263 本身是功率转换器。需要低噪声模拟电源时，常见做法是：

```text
Buck 主电源 → 磁珠/阻尼 → 低噪声 LDO → 模拟负载
```

### 36.17 一个“好参数”必须同时满足什么

单个指标很好，不代表整体方案好。一个可量产的 DC-DC 至少应同时满足：

1. 推荐输入范围有实际裕量。
2. 峰值电流低于最小限流并远离电感饱和。
3. 最大负载温升可接受。
4. 开关频率没有触发最小导通/关断时间。
5. 输出电容在有效容量和稳定范围内。
6. 反馈最坏误差满足系统电压容差。
7. 启动、关断、短路和反灌行为明确。
8. 纹波与负载瞬态满足具体负载，而非只满足宣传数字。
9. PCB 布局后 LX 振铃和 EMI 可接受。
10. 替代料和制造公差不会破坏以上条件。

## 37. 最终设计原则

1. 使用推荐工作范围，不使用绝对最大值做正常设计点。
2. 所有计算使用芯片引脚处的最坏输入，而不是电源标称值。
3. 电感、电容和保护按最大负载计算；效率和常态温升同时参考平均负载。
4. MLCC 按直流偏压后的有效容量计算。
5. 内部补偿芯片不要随意大幅改变 L、C 和 ESR。
6. 高频尖峰首先解决布局和测量方法，不要只堆电容。
7. 任何输入滤波器都要考虑与变换器负输入阻抗的相互作用。
8. LDO 接近 dropout 时，输出精度和 PSRR 都会变差。
9. 原理图正确不代表 PCB 正确；PCB 正确也不代表最坏条件已经验证。
10. 量产前保留启动、纹波、阶跃、温升、短路和 EMI 的可复现实测记录。

---

> **一句话总结：**先用公式确定数量级，再用数据手册确定边界，最后用样机证明最坏条件下仍然可靠。
