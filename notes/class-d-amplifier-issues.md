# D类功放关键问题

==输出PWM频率==：由三角波比较产生，三角波频率越高，采样率越高．输出PWM频率与音频输入频率无关，与调整出的三角波有关，输入频率变块了，脉冲差距就变大

==输出音量大小==：输出音量大小由占空比有关，占空比大，音量越大，占空比小音量越小；需要接上负载才能观察到
- **大音量**：PWM波的脉冲宽度在一个高频周期内剧烈变化，从很宽到很窄。经过低通滤波器平均后，得到的**平均电压**也在一个很宽的范围内（比如接近0V到接近电源电压）波动，这个波动的电压就是强大的音频信号。
    
- **小音量**：PWM波的脉冲宽度变化范围被压缩，比如只在45%到55%之间变化。经过低通滤波器平均后，得到的**平均电压**也只在一个很小的范围内（比如2V到3V）波动，这个微弱的波动就是小的音频信号。
    
- **静音**：PWM波的脉冲宽度**固定**在50%。经过低通滤波器平均后，得到的**平均电压**是一个稳定的直流电压（比如电源电压的一半）。由于喇叭的隔直电容（或滤波器本身）会阻挡直流，所以没有声音。

==功放供电设计==:
好的，这是一个非常核心的电路结构问题。D类功放的输出级主要有两种形式：**单电源半桥** 和 **双电源全桥**。它们之间的区别直接影响了功放的性能、成本和适用场景。

### 核心区别一览表

| 特性         | 单电源半桥              | 双电源全桥                     |
| :--------- | :----------------- | :------------------------ |
| **输出结构**   | 两个开关管，一端接输出，另一端接地。 | 两个半桥串联，输出在两个桥臂之间。         |
| **电源需求**   | 单组正电源。             | 需要正负对称电源，或单电源但内部产生“虚拟地”。  |
| **输出摆幅**   | 0V 到 +VDD          | -VDD 到 +VDD               |
| **最大输出电压** | VDD                | 2 × VDD                   |
| **输出功率**   | 较低                 | 在相同电源电压下，是半桥的**4倍**       |
| **耦合电容**   | **需要**大的直流阻断电容。    | **通常不需要**。                |
| **成本与体积**  | 较低，较小（但大电容占空间）。    | 较高，元件数多（但省去大电容）。          |
| **应用场景**   | 成本敏感的便携设备、电视、电脑音箱。 | 追求功率和音质的车载音响、家庭影院、高端有源音箱。 |

### 详细解析

#### 1. 单电源半桥

**结构：**
*   使用两个功率MOSFET（Q1和Q2）。
*   上管（Q1）连接在电源（VDD）和输出端之间。
*   下管（Q2）连接在输出端和地（GND）之间。
*   输出端通过一个**大的直流阻断电容**连接到扬声器。

**工作原理：**
*   **高电平**：Q1导通，Q2关闭。输出端被拉到接近VDD。
*   **低电平**：Q1关闭，Q2导通。输出端被拉到接近0V（GND）。
*   因此，输出PWM波的电压在**0V到+VDD**之间摆动。

**关键点与挑战：**
*   **输出电容的作用**：这个电容至关重要，有两个作用：
    1.  **隔直**：阻止输出端的直流电压（平均值为VDD/2）烧毁扬声器音圈。
    2.  **储能**：作为单端输出的能量来源。
*   **静音状态**：当占空比为50%时，输出端的平均电压是VDD/2。这个直流分量被电容阻挡，扬声器两端电压为0。
*   **缺点**：
    *   **功率限制**：输出摆幅只有VDD，根据功率公式 `P = V² / R`，输出功率有限。
    *   **电容问题**：为了通过低频信号，这个电容必须非常大（通常是几百到几千微法）。它体积大、成本高，并且是影响低频响应和音质的一个潜在因素。

#### 2. 双电源全桥

全桥结构可以看作是将两个半桥“背靠背”连接起来。

**结构：**
*   使用四个功率MOSFET（Q1-Q4），组成两个桥臂。
*   扬声器直接连接在两个桥臂的输出点（Out+和Out-）之间。
*   电源可以是**正负对称电源**（如+VDD和-VDD），也可以是单电源，但电路会以地为参考，创建一个“虚拟地”。

**工作原理：**
*   它通过**差分**方式驱动负载。
*   **状态一**：Q1和Q4导通，Q2和Q3关闭。电流路径为：VDD -> Q1 -> 扬声器 -> Q4 -> GND。此时 `Out+ ≈ VDD`, `Out- ≈ 0V`，负载两端电压为 `+VDD`。
*   **状态二**：Q2和Q3导通，Q1和Q4关闭。电流路径为：VDD -> Q3 -> 扬声器 -> Q2 -> GND。此时 `Out+ ≈ 0V`, `Out- ≈ VDD`，负载两端电压为 `-VDD`。
*   因此，加在扬声器两端的PWM电压在 **+VDD 到 -VDD** 之间摆动，总电压摆幅为 **2 × VDD**。

**关键点与优势：**
*   **无输出电容**：由于输出是差分的，静音时（占空比50%），Out+和Out-的平均电压相等（都是VDD/2），扬声器两端**没有直流电位差**，因此可以省去大的直流阻断电容。
*   **功率巨大**：根据功率公式 `P = V² / R`，电压摆幅从VDD提升到2VDD，意味着在**相同电源电压**下，输出功率是半桥结构的 **4倍**。
    *   或者说，要达到相同的功率，全桥所需的电源电压只有半桥的一半。
*   **共模噪声抑制**：差分传输能更好地抑制电源噪声和干扰。
*   **缺点**：
    *   需要两倍的开关管和更复杂的驱动电路，成本更高。
    *   如果使用对称正负电源，电源系统也更复杂。

### 如何选择？应用场景

*   **单电源半桥**：
    *   **优势**：结构简单，成本低，只需单电源。
    *   **劣势**：输出功率小，需要大的输出电容影响低频和体积。
    *   **应用**：几乎所有对成本和体积敏感的**单电源供电**设备，如手机、蓝牙音箱、平板电脑、笔记本电脑、电视等内部的功放。

*   **双电源全桥**：
    *   **优势**：功率大、效率高、省去了大输出电容、低频响应更好。
    *   **劣势**：电路复杂，成本高。
    *   **应用**：
        *   **车载音响**：汽车电瓶是单电源12V，电压低。要获得大功率，必须使用全桥结构，将电压摆幅倍增到24V。
        *   **大功率有源音箱/低音炮**：需要驱动大口径扬声器，追求高功率和强劲的低音。
        *   **高端家庭影院接收机**。

### 总结

简单来说，**全桥是单端半桥的差分升级版**。

*   你把一个**半桥**的输出，经过一个**大电容**，接到喇叭的一端，喇叭另一端接地。
*   你把两个**半桥**的输出，**直接**接到喇叭的两端，就构成了一个**全桥**。

这个结构上的根本差异，决定了它们在性能、成本和适用领域上的不同分工。
