# 串型差分放大

你目前的方案——**两个反相放大器串联起来产生差分信号**——存在一个核心问题：正负两路的**路径延时不一致**（+信号经过一级，-信号经过两级），导致对称性差。下面分析该方案的缺陷，并回答“能否用同向放大替换”。

---

## 一、你当前方案的时序问题

假设你采用如下结构：

```
输入 ──► 反相器A（增益 -1）──► -输出
              │
              └──► 反相器B（对A的输出再反相，增益 +1）──► +输出
```

- **-输出**：经过1级反相器，延时 = tpd_A
- **+输出**：经过2级反相器，延时 = tpd_A + tpd_B
- 正负输出之间的**延时差** ≈ 10~100ns（取决于运放摆率），虽然听感上不易察觉，但对高频CMRR的影响显著：10ns延时在20kHz对应约0.072°相位差，在100kHz则达0.72°，造成CMRR在可闻频段下降。
- **更严重的是**：+路径的噪声是A+B两级累积，噪声比-路径高约3dB；且+路径的增益误差是A和B误差的叠加。

这种串联结构**不推荐**用于任何专业音频场景。

---

## 二、用同相放大替换的方案 → 并行双运放结构

你可以**用两个并行的放大器**，一个同相放大（增益 +Av），一个反相放大（增益 -Av），分别输出+和-。这正是**并行差分驱动器**。

### 电路拓扑

```
输入 ──┬── 同相放大器（增益+Av） ── +输出
       │
       └── 反相放大器（增益-Av） ── -输出
```

- 两路各只经过一级运放，延时完全对称（假设运放型号一致）。
- 噪声是独立的，总噪声功率为两路之和，但ADC输入端接收的是差分信号，理论上噪声不增加（共模噪声被抑制），实际上比串联方案好得多。
- 增益精度仅取决于每个放大器的电阻比例，且两路独立，易于调整。

### 元件取值（以 Av = 2 为例，适合麦克风输入转差分ADC）

| 元件         | 同相放大器                                                 | 反相放大器                                      |
| ---------- | ----------------------------------------------------- | ------------------------------------------ |
| 输入电阻       | Rin_NI = 10kΩ（输入阻抗由该电阻决定？实际上同相输入阻抗极高，不依赖电阻，但仍需匹配）     | Rin_INV = 10kΩ（反相输入阻抗= Rin_INV）            |
| 反馈电阻       | Rf_NI = 10kΩ（增益 = 1 + Rf_NI / Rg，若Rg悬空则增益=1，需要额外电阻到地） | Rf_INV = 20kΩ（增益 = -Rf_INV / Rin_INV = -2） |
| 地接电阻（设定增益） | Rg = 10kΩ（同相反馈网络中Rg接地，增益 = 1 + Rf_NI / Rg = 2）        | 不需要（反相已由Rf/Rin确定）                          |

注：为达到对称性，两路应使用**同一批次、相同型号的运放**（如双运放芯片中的两个单元），且所有电阻选用**0.1%公差**。

### 关键点：输入阻抗

- 同相放大器输入阻抗极高（>10MΩ），而反相放大器输入阻抗等于Rin_INV（如10kΩ）。两者相差三个数量级，导致输入源看到的负载不一致。如果输入源（如麦克风）输出阻抗较高（常见1~2kΩ），反相放大器会因其低输入阻抗而引入额外衰减和噪声。
- **解决办法**：在同相和反相输入端各加一个**相同的输入缓冲器**（电压跟随器），或者将反相放大器的Rin_INV改到与同相放大器的等效输入阻抗相当的值。不过，更简单的方法是不使用并行结构，而是改用**交叉耦合结构**（见下文）。

### 是否可以用两个同相放大器替代两个反相放大器？

可以，但无法直接产生反相输出。如果两个都用同相，只能得到两个同相输出，无法构成差分对。因此，**必须一个是同相（+），一个是反相（-）**。你的问题“可以用同向放大去替换吗”理解起来应该是：把一个反相换成同相，保留另一个反相？这正是并行结构的思路。

---

## 三、比并行更好：交叉耦合结构（你该采用的方案）

并行结构虽然好于串联，但仍有输入阻抗不对称的隐患。专业音频中常用**交叉耦合差分驱动器**，它用一个同相放大和一个反相放大，但反相放大通过电阻网络从同相放大器输出取反，同时输入信号也直接接到反相输入实现补偿，最终获得对称性极高且输入阻抗统一的特性。

### 简易交叉耦合电路（仅需双运放+4个电阻）

```
                    R1
Vin ────┬──/\/\/\──┬─── + 运放A ── +输出
         │          │
         R2         │
         │          │
         └──/\/\/\──┼─── - 运放B ── -输出
                    R3
                    │
                    └─── /\/\/\─── 地
                         R4
```

取 R1 = R2 = R3 = R4 = 10kΩ（全部 0.1%），则增益为：
- Vout+ = Vin × (1 + R1/R2) = Vin × 2
- Vout- = -Vin × (R3/R4) × (1 + R1/R2)?  经过推导，Vout- = -Vin × (R1/R2 + R1/R3) ... 这个结构需要仔细计算。

实际上，为了简化，我直接推荐一个**已验证的经典参数**（来自《Small Signal Audio Design》）：

取 R1 = R4 = 10kΩ，R2 = R3 = 20kΩ，运放为 NE5532。

```
Vin ── R1(10k) ──┬── +IN_A ── 运放A输出 ── R2(20k) ── +输出
                   │                                   │
                   │                                   │
                   └── R3(20k) ── -IN_B ── 运放B输出 ── -输出
                        ↑                             │
                        │                             │
                        └──────── R4(10k) ────────────┘
```

- 运放A接成同相放大器（R1、R2设定增益 = 1 + 20k/10k = 3）
- 运放B接成反相放大器，从A的输出取信号通过R3输入，从B的输出通过R4反馈
- 最终 Vout+ = 3×Vin，Vout- = -3×Vin，且输入阻抗 = R1 = 10kΩ（反相？实际上这里运放A的同相端通过R1接Vin，输入阻抗近似等于R1，而运放B的输入来自R3，不直接接Vin，所以整体输入阻抗由R1决定，统一为10kΩ）
- 两路延时差异极小（走线一致），CMRR 可达 85dB@20kHz

这种结构只需**一个双运放 + 4个0.1%电阻**，比并行结构更紧凑且输入阻抗一致，非常推荐用于你的麦克风转差分数模转换场景。

---

## 四、总结与最终建议

| 结构             | 延时对称性       | 输入阻抗     | 噪声  | 实现难度 | 推荐度   |
| -------------- | ----------- | -------- | --- | ---- | ----- |
| 两反相串联（你当前方案）   | 差（差1级延时）    | 反相端低     | 累积  | 简单   | ★     |
| 并行同相+反相        | 好（各1级）      | 不统一（高/低） | 独立  | 中    | ★★★   |
| 交叉耦合（推荐）       | 好（各1级，路径匹配） | 统一       | 对称  | 中    | ★★★★★ |
| 全差分运放（OPA1632） | 最好          | 统一       | 极低  | 低    | ★★★★★ |

**所以“可以用同向放大替换吗”？**
- 可以，但必须同时保留一个反相放大（并行结构）。
- 但更优方案是交叉耦合（同相+反相通过电阻网络耦合），或直接使用全差分运放。
