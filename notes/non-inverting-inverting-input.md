这是一个非常经典且重要的运放基础问题，尤其是对于音频硬件设计，输入阻抗直接决定信号源负载特性、噪声匹配和频响。

---

## 一、核心结论（一句话）

| 放大器类型 | 输入阻抗（低频/直流） | 主导因素 |
|------------|------------------------|----------|
| **同相放大器** | **极高**（≈ 运放共模输入阻抗） | 由运放本身的输入阻抗决定，典型 > 10MΩ（双极性）或 > 10^12Ω（JFET/CMOS） |
| **反相放大器** | **较低**（≈ 输入串联电阻 R1） | 由外部电阻 R1 决定，典型 1kΩ ~ 100kΩ |

---

## 二、为什么会有这样的差异？（原理剖析）

### 1. 同相放大器的输入阻抗

同相端直接接输入信号 `Vin`。  
**由于负反馈，运放两个输入端保持虚短，差分电压几乎为零**，因此同相端几乎不从信号源索取电流（理想运放输入电流为0）。

- 实际运放仍有微小输入偏置电流和输入电容
- 低频输入阻抗 ≈ 运放的 **共模输入阻抗**（datasheet 中 `Rin(cmd)` 或 `Zin(cmd)`）
- 数值：TL07X（JFET）约 10^12Ω；NE5532（双极性）约 300kΩ ~ 10MΩ（取决于共模电压）

**等效电路**：

```
Vin ───┬─── 运放同相端 (+)
       │
       └── 高阻抗路径（Rin_cmd）
```

### 2. 反相放大器的输入阻抗

输入信号 `Vin` 通过电阻 `R1` 加到反相端（-）。  
**由于负反馈使反相端虚地（近似 0V）**，R1 上的压降就是 `Vin - 0V`，因此输入电流 `Iin = Vin / R1`。

- 从信号源看进去，等效电阻就是 `R1`
- 因此输入阻抗 = **R1**（忽略运放本身的输入阻抗，因为被负反馈"吞噬"了）

**等效电路**：

```
Vin ───R1─── 运放反相端 (-)   （此处是虚地，阻抗几乎为0）
```

## 三、公式对比

| 参数 | 同相放大 | 反相放大 |
|------|----------|----------|
| **输入阻抗 Zin** | ≈ Zin(cmd) 运放共模输入阻抗 | ≈ R1 |
| **增益公式** | 1 + R2/R1 | -R2/R1 |
| **R1/R2 对输入阻抗的影响** | 无直接影响 | R1 直接决定输入阻抗 |
| **例子：增益=10（同相R1=10k,R2=90k）** | Zin ≈ 10^10Ω（JFET） | Zin = R1 = 10kΩ（固定） |

## 四、音频设计中如何选择？（实战建议）

### 1. 话筒前置放大器（Preamp）
- **电容/驻极体话筒**：内部已有缓冲，但通常预期高输入阻抗（> 2kΩ），用同相或仪放更好。
- **动圈话筒**：低阻抗（200Ω~600Ω），反相放大器的10kΩ输入阻抗不会造成负载问题，但同相能提供更高输入阻抗以保留细微高频响应。
- **高阻乐器（电吉他）**：必须用同相或JFET缓冲，输入阻抗 > 1MΩ。

### 2. 线路输入（Line In）
- 专业调音台线路输入标准：输入阻抗 **10kΩ ~ 50kΩ**（平衡或非平衡）
- **平衡输入**：常使用 **差分放大器**（反相结构变体），输入阻抗由两个电阻分别决定，对称且可调。

### 3. 低噪声设计约束
- 电阻热噪声：`√(4kTRB)`，R 越大噪声越大
- 反相放大：输入阻抗 = R1，若需要高输入阻抗（> 100kΩ），R1 的热噪声会劣化 SNR
- 同相放大：允许使用很小的 R1（如 1kΩ）不牺牲输入阻抗，但增益公式中 R1 参与增益设定，需要注意

### 4. 高频与寄生电容
- 同相放大的高输入阻抗容易受到 PCB 寄生电容影响（形成低通滤波器），高频时输入阻抗迅速下降
- 反相输入的虚地端提供了更稳定的高频地阻抗，常用于射频或宽频放大器

```markdown
# 同相放大与反相放大器的输入阻抗问题

## 同相放大器
- 输入阻抗 ≈ 运放的共模输入阻抗（JFET可达10^12Ω，双极性通常 > 1MΩ）
- 原理：同相端直接接输入，负反馈保持虚短，几乎不从信号源取电流
- 优点：输入阻抗极高，适合高阻抗信号源（话筒、乐器）
- 缺点：易受PCB寄生电容影响（高频滚降）

## 反相放大器
- 输入阻抗 = R1（输入串联电阻）
- 原理：反相端虚地，输入电流 = Vin / R1
- 优点：输入阻抗可预测且稳定（适合精密增益、差分输入）
- 缺点：输入阻抗较低且固定（由R1决定）

## 音频设计选型建议
| 场景 | 推荐拓扑 | 原因 |
|------|----------|------|
| 话筒前级（高阻） | 同相/JFET缓冲 | 保持高输入阻抗 |
| 线路平衡输入 | 差分（反相变体） | 对称阻抗、共模抑制 |
| 低噪声、固定增益 | 同相（小R1） | 兼顾噪声与阻抗 |
| 高频/宽带 | 反相 | 虚地阻抗稳定 |

## 实测要点
- 同相放大用DMM测输入阻抗通常不准（运放偏置电流影响），可用分压法测
- 反相放大直接测R1阻值即可
- 音频范围内重点考虑1kHz处的输入电容效应
```
