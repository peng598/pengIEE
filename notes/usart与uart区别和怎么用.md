# USART 与 UART 的使用边界

## 外设能力与当前模式

UART 提供异步串行收发；USART 通常还支持同步时钟模式，但具体外设命名和功能以 MCU 手册为准。使用异步模式时，USART 与 UART 的工作原则相近，速度取决于外设时钟、分频器、过采样和实现，并非 USART 名称天然更快。

同步模式需检查时钟方向、极性、采样边沿与从机支持，不能因为存在 CK 引脚就把它当作完整 SPI 接口；片选、双工、帧格式和首位时序可能不同。

## 波特率和时钟误差

理想位时间 $T_b=1/baud$。接收器从起始位同步，随后依本地时钟采样，时钟误差会随帧内位数累积。8N1 在停止位附近约经历 9.5 个位时间，两端频率误差、起始检测和采样裕量必须一起核算；不能把某个通用“±2%”替代外设规定。

例如 115200 baud 的位时间约 8.68 μs，8N1 字节约 86.8 μs。选择分频寄存器时计算实际波特率及量化误差，再加晶振/内部 RC 的全温误差。

## 软件与硬件验收

配置引脚复用、电压域、时钟源、帧格式及中断/DMA，接收策略应处理 overrun、framing、noise 和 parity 标志。空闲中断常用于检测间隔，不等于协议完整帧；DMA 环形缓冲还需处理读写指针与缓存一致性。

用逻辑分析仪验证实际位宽和帧格式，示波器检查边沿与门限。覆盖最长帧、持续满速、接收任务阻塞、对端断电/重启和故意错误帧。电平 UART 与 RS-232/RS-485 的物理层不同，外部连接须先确认电压及地参考。
