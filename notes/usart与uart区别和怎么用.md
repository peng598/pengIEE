# USART 与 UART 的使用边界

## 外设能力与当前模式

UART 提供异步串行收发；USART 通常还支持同步时钟模式，但具体外设命名和功能以 MCU 手册为准。使用异步模式时，USART 与 UART 的工作原则相近，速度取决于外设时钟、分频器、过采样和实现，并非 USART 名称天然更快。

同步模式需检查时钟方向、极性、采样边沿与从机支持，不能因为存在 CK 引脚就把它当作完整 SPI 接口；片选、双工、帧格式和首位时序可能不同。

## 波特率和时钟误差

理想位时间 $T_b=1/baud$。接收器从起始位同步，随后依本地时钟采样，时钟误差会随帧内位数累积。8N1 在停止位附近约经历 9.5 个位时间，两端频率误差、起始检测和采样裕量必须一起核算；不能把某个通用“±2%”替代外设规定。

例如 115200 baud 的位时间约 8.68 μs，8N1 字节约 86.8 μs。选择分频寄存器时计算实际波特率及量化误差，再加晶振/内部 RC 的全温误差。

## 软件与硬件验收

配置引脚复用、电压域、时钟源、帧格式及中断/DMA，接收策略应处理 overrun、framing、noise 和 parity 标志。空闲中断常用于检测间隔，不等于协议完整帧；DMA 环形缓冲还需处理读写指针与缓存一致性。

用逻辑分析仪验证实际位宽和帧格式，示波器检查边沿与门限。覆盖最长帧、持续满速、接收任务阻塞、对端断电/重启和故意错误帧。电平 UART 与 RS-232/RS-485 的物理层不同，外部连接须先确认电压及地参考。

## 分频误差如何叠加到停止位

假设某外设的实际公式为 $baud=f_{clk}/(16D)$，且 D 只能取整数。48 MHz 时产生 115200 baud 的理想 D 为 26.0417，取 26 得 115384.6 baud，分频误差约 +0.1603%。有分数分频或不同过采样模式的外设应使用自身公式，不能直接照搬这个 D。

两端误差应按相反方向的最坏组合计算。若发送端 +1%、接收端 −1%，位时间相对偏差约为 2%，经过 9.5 位累积约 0.19 UI；仍需加起始位同步量化、输入边沿和采样判决占用的窗口。过采样有助定位和抗噪，不会自动消除整帧时钟漂移。

在低温、低供电下复测内部 RC 时钟的误差，尤其是长帧格式。示波器应测多个字节的真实位宽；逻辑分析仪能成功解码，只表示它自己的采样算法容忍该波形，不能证明目标 MCU 接收裕量足够。

## 接收错误与数据完成的区别

TXE 通常表示发送数据寄存器可继续写，TC 才表示最后一帧已完成离开发送器；具体标志名及清除规则以手册为准。RS-485 的 DE 若在 TXE 就撤销，可能截断停止位；应由 TC 或外设硬件控制 DE，并计收发器关断延迟。

错误帧处理要明确数据与标志的读取顺序，避免清除错误时把新字节误消费。环形 DMA 的进度用于定位字节区间，应用协议的长度/校验用于定位消息，二者不能互相替代。

例如 64 字节 8N1 帧在 115200 baud 下线缆占用约 5.56 ms，若还需 2 ms 对端处理和 1 ms 转向等待，响应超时必须覆盖这些时间及调度抖动。超时起点应写明是开始排队、首位发出还是 TC，才不会因发送队列积压产生偶发假超时。
