# Altium 设计规则与制造约束核对

## 1. 原始记录作为历史起点

原笔记保留以下信息：

| 原始内容 | 使用前必须核实 |
| --- | --- |
| 走线间距 5 mil | 对应板厂、铜厚、电压及网络类别 |
| 过孔最小 0.2 mm，正常 0.3 mm | 钻孔直径还是电镀后的成品孔径 |
| 外部焊盘“16 mil × 2 ＋＿2” | 表达不完整，不能作为可执行规则 |
| DDR“8、14、间距 5” | 线宽、间距、单位及对应叠层尚不明确 |
| 阻焊 2.5 mil | 是扩展量还是最小阻焊桥，必须确认 |
| 散热对称，防立碑 | 应落实到焊盘、铜连接、热容量和回流工艺 |

这些数值不构成通用生产规范。不同层数、铜厚、孔径纵横比与板厂能力都会改变可制造边界。

## 2. 规则输入来自哪里

先收集板厂叠层与能力表、封装推荐焊盘、贴片厂装配能力、接口 SI 要求、电气间隙与爬电要求，再建立 net class 和规则优先级。生产工艺的“极限能力”与稳定量产的推荐能力要分开。

1 mil = 0.0254 mm，5 mil = 0.127 mm。转换单位后仍要检查编辑器是否把孔径、焊盘直径和间隙写到了正确字段。

## 3. 孔、焊盘与阻焊桥

若成品孔直径为 $d$、焊盘直径为 $D$，名义孔环宽度：

$$
w_{ring}=\frac{D-d}{2}
$$

但实际最小孔环还受钻孔偏移、电镀、蚀刻及层间对准影响。不要只用名义几何差判定满足板厂能力。通孔、盲埋孔、微孔的工艺约束不同。

若两个铜焊盘间距为 $g$、两侧阻焊扩展量均为 $e$，名义阻焊桥约为 $g-2e$。假设 $g=0.20$ mm、$e=0.05$ mm，名义桥宽 0.10 mm；最终还需满足阻焊对准和板厂最小桥宽。细间距封装可能采用连窗，应与装配工艺确认。

## 4. 高速与电源约束不能只用一条全局间距

DDR、差分接口的线宽/间距由叠层、介质、铜厚与阻抗目标共同决定。长度匹配应按时序预算、引脚/封装延迟和拓扑分组，不把全部信号无区别拉成等长。蛇形线自身耦合和过孔也会影响延迟。

电源走线则要校核温升、压降、铜厚和回流；爬电与电气间隙要考虑工作电压、瞬态、污染等级及适用标准。把“5 mil 可生产”用在高压隔离网络上会混淆两个完全不同的约束。

## 5. 规则优先级与例外管理

在 Altium 中用明确作用域设置网络类、差分对类和区域规则；重叠规则要检查优先级与实际命中结果。放一个代表性对象验证规则生效，比只看规则列表可靠。

DRC 不应仅追求零数量。每个豁免保留原因、位置、评审人/版本与制造确认；禁止用宽泛排除掩盖整类违规。板框、槽孔、禁布区、测试点、丝印压焊盘、BOM 与装配方向也纳入发布检查。

## 6. 立碑与焊接一致性

小型两端器件两侧热容量、焊盘几何、锡膏量和润湿时序不一致，可能产生立碑。对称连接与合理热焊盘有助于降低风险，但大电流和散热器件不能机械追求相同热隔离；需与铜箔载流、回流曲线和装配厂共同验证。

交付时保存规则文件、叠层、DRC 报告、制造输出和已批准例外，确保修改叠层或替换板厂后重新评审。
